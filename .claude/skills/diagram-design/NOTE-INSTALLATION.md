# Installation Dig (02/10/2026)

Source : https://github.com/cathrynlavery/diagram-design (licence MIT, version 2.6 du SKILL.md), dossier `skills/diagram-design/`.

Installé ici : `SKILL.md` + `references/` (texte seul, Markdown). **Non installés** : `assets/` (177 exemples HTML, 2,8 Mo)
et `scripts/` (importateurs .drawio / Mermaid / Excalidraw, export SVG, auto-contrôle Python) — inutiles pour Dig et non relus
ligne à ligne. Si un import ou l'export PNG devient nécessaire, les reprendre du dépôt d'origine après lecture complète.

Usage Dig : schémas « comment ça marche », parcours client, frise, organigramme pour les supports et le site, en HTML/SVG
autonome, sans dépendance. Les polices (Instrument Serif, Geist) sont chargées depuis Google Fonts : pour un support hors ligne
ou un PDF, remplacer par les polices du support. Première utilisation : le SKILL.md demande de personnaliser `references/style-guide.md`
(couleurs Dig) ; profil à enregistrer selon `references/profiles.md`.
