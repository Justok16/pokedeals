Jarvis sur ton ordinateur, en français

Assistant vocal gratuit (projet libre « Jarvis », licence MIT). Il écoute « Jarvis », répond à voix haute et agit avec Claude Code. Voix française naturelle et gratuite : les voix « Natural » de Microsoft Edge (Henri, Rémy, Denise, Vivienne, Éloïse), classées de très haute qualité.

Ce qu’il faut

  1. Un ordinateur Mac ou Windows avec micro et haut-parleurs (un téléphone ne suffit pas).
  2. Le navigateur Microsoft Edge : déjà installé sur Windows, gratuit sur Mac (microsoft.com/edge). C’est lui qui contient les voix françaises les plus naturelles.
  3. Ton compte Claude habituel (le même que pour cette conversation).

Étape 1 — Installer Node.js (une seule fois)

  1. Va sur nodejs.org et télécharge la version marquée « LTS ».
  2. Ouvre le fichier téléchargé et clique sur « Suivant » jusqu’à la fin.
  3. Ensuite, ferme le Terminal (ou PowerShell) s’il était ouvert, pour qu’il reconnaisse Node.js.

Étape 2 — Installer Claude Code sur l’ordinateur (une seule fois)

  1. Ouvre le Terminal (Mac : touches Cmd + Espace, tape « Terminal ») ou PowerShell (Windows : touche Windows, tape « PowerShell »).
  2. Colle cette ligne, puis appuie sur Entrée : 
    npm install -g @anthropic-ai/claude-code
  3. Tape claude, appuie sur Entrée, et connecte-toi avec ton compte Claude quand on te le demande.

Étape 3 — Tout le reste, en un seul copier-coller

Dans Claude Code (fenêtre de l’étape 2), colle ce texte et appuie sur Entrée. Claude installe Jarvis, le passe entièrement en français (écoute, voix et réponses) et le lance.

Installe le projet https://github.com/adewaskar/jarvis dans mon dossier Documents (télécharge-le, puis lance npm install et npm run setup, et corrige ce que setup signale).
Puis passe-le entièrement en français :
1) dans src/lib/voice.ts, remplace rec.lang = 'en-GB' par rec.lang = 'fr-FR' ;
2) dans src/lib/tts.ts : fais choisir uniquement des voix françaises (lang commençant par fr au lieu de en, dans candidateVoices et dans pickVoice), classe en premier les voix dont le nom contient « Online (Natural) », avec cet ordre de préférence : Henri, Remy, Denise, Vivienne, Eloise ; remplace aussi le 'en-GB' par défaut par 'fr-FR' ;
3) dans bridge/server.mjs, ajoute au début de SYSTEM_PROMPT : « Réponds toujours en français, en deux phrases maximum. Appelle-moi Monsieur. »
Ne donne jamais l’autorisation d’écriture (ne règle pas JARVIS_ALLOW_WRITES).
Lance-le avec la variable JARVIS_MODEL réglée sur le modèle Sonnet le plus récent (par exemple claude-sonnet-5-5, plus économe que le modèle par défaut) en utilisant npm start, puis donne-moi l’adresse à ouvrir dans Microsoft Edge.

Étape 4 — Parler à Jarvis

  1. Ouvre l’adresse donnée (en général http://localhost:5173) dans une vraie fenêtre Microsoft Edge.
  2. Clique sur INITIALISE, puis autorise le micro.
  3. Dis « Jarvis » suivi de ta question.
Espaceparler sans dire « Jarvis »
Vchanger de voix : Henri, Rémy (voix d’homme), Denise, Vivienne, Éloïse (voix de femme)
Échapmettre Jarvis en veille
Ctrl + Cdans le Terminal : arrêter Jarvis

Les fois suivantes : ouvre le Terminal, tape claude puis « Relance Jarvis en français avec le modèle Sonnet le plus récent ».

Encore plus naturel (facultatif) : ElevenLabs

Jarvis sait aussi utiliser ElevenLabs, une voix de synthèse haut de gamme qui parle français. Offre gratuite : 10 000 crédits par mois (page tarifs lue le 30/09/2026). Il faut créer un compte (ta décision) et une clé : la clé se met dans les réglages de l’ordinateur (variable ELEVENLABS_API_KEY) et une voix française choisie dans leur bibliothèque (variable JARVIS_VOICE_ID). Ne colle jamais la clé dans une conversation. Demande simplement à Claude Code sur ton ordinateur : « Configure ElevenLabs pour Jarvis avec une voix française ; je vais saisir la clé moi-même. »

À savoir avant de l’utiliser

  1. Il consomme ton quota Claude (le même que pour notre travail). Garde de la réserve pour le jour où un éditeur répondra « oui ».
  2. Il fonctionne seulement quand l’ordinateur est allumé et Edge ouvert.
  3. La reconnaissance du mot « Jarvis » peut parfois rater en français : la touche Espace marche toujours.
  4. N’installe Jarvis que depuis le lien officiel du guide (des copies modifiées circulent). Comme tout programme, il s’exécute sur ton ordinateur : ne lui donne jamais l’autorisation d’écriture.
  5. Il ne voit pas les connecteurs de ton compte claude.ai (Gmail, Drive…), seulement les outils installés sur l’ordinateur.
