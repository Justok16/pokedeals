# Supprimer les virus en 2 clics 🖥️

Vidéo : https://youtu.be/SnrqDIKPMSU · durée 0:30 · résumé Gemini (gemini-3.1-flash-lite, lot de 8) du 2026-10-02

1. **Idée principale** : Utiliser l'outil de suppression de logiciels malveillants intégré nativement à Windows.
2. **Outils** :
    * Microsoft Malicious Software Removal Tool (MRT) (gratuit, intégré à Windows) : outil de détection de virus.
3. **Astuces** : Taper "MRT" dans la fenêtre "Exécuter" (Windows + R) pour lancer une analyse rapide de sécurité sans avoir besoin d'installer de logiciel tiers.
