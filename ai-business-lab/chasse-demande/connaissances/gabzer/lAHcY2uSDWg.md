1) **Idée principale** : Nettoyer l'historique DNS de Windows via PowerShell car supprimer l'historique de navigation ne suffit pas à masquer totalement les sites visités.
2) **Outils cités** : 
   - PowerShell (intégré à Windows, gratuit) : terminal de commande système.
3) **Astuces** : Utiliser la commande `Get-DnsClientCache` pour voir les sites visités et `ipconfig /flushdns` pour les supprimer du cache DNS.
