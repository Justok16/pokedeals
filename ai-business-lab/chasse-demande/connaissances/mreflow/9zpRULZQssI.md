Voici un résumé de la vidéo, structuré selon tes demandes :

### 1) Idée principale
La vidéo explique que les benchmarks (tests) utilisés pour évaluer les modèles d'intelligence artificielle (comme GPT, Claude ou Llama) sont souvent faussés, manipulés, voire contournés (« triché ») par les entreprises elles-mêmes. Les scores élevés affichés ne reflètent pas toujours la supériorité réelle d'un modèle, mais servent surtout d'argument marketing pour gonfler la valorisation boursière des entreprises.

---

### 2) Outils, sites et dépôts GitHub cités
* **Comet Browser** : Navigateur web intégrant la technologie d'IA (utilisé ici pour la recherche).
* **LMArena (ou LMSYS Chatbot Arena)** : Plateforme gratuite de test à l'aveugle où les utilisateurs votent pour le meilleur modèle entre deux propositions (servant de classement de référence).
* **OpenAI (GPT-4 / GPT-5)** : Modèles et outils d'IA (payant via API / abonnements).
* **Anthropic (Claude)** : Modèles d'IA dont Claude 3.7 / 4 (payant / freemium).
* **Meta (Llama 3 / Llama 4)** : Modèles d'IA open-source/gratuits, mais certains variants étaient modifiés pour les tests.

---

### 3) Astuces concrètes et réutilisables
* **Ne pas se fier aux scores marketing** : Ne choisissez pas un outil d'IA uniquement sur la base de ses performances affichées dans les classements publics.
* **Tester par soi-même** : Utilisez vos propres cas d'usage réels et faites des tests comparatifs (A/B testing) avec vos propres prompts sur des plateformes comme LMArena.
* **Méfiance envers le « formatage »** : Les IA sont souvent optimisées pour plaire (ton poli, emojis, belles structures), ce qui peut masquer des erreurs factuelles.
