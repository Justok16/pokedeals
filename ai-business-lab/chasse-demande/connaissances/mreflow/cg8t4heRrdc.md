# Make ANY Website with ONE Sentence! (WebSim)

Vidéo : https://youtu.be/cg8t4heRrdc · durée 14:21 · résumé Gemini (gemini-3.5-flash-lite, lot de 7) du 2026-10-18
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale :** Présentation de la plateforme WebSim (websim.ai), un navigateur web simulé propulsé par l'IA (notamment Claude 3.5 Sonnet et GPT-4o), qui permet de créer instantanément des mini-jeux, des applications ou des sites web interactifs par simple saisie de texte ou d'URL.

2) **Outils, sites ou dépôts GitHub cités :**
- **WebSim** (`websim.ai`) : Gratuit (les modèles sous-jacents comme Claude 3.5 Sonnet ou GPT-4o sont utilisés via l'API, mais le site est gratuit pour l'utilisateur sans même de don requis). Il sert à simuler et générer des applications web interactives, des jeux, des visionneuses 3D ou des générateurs de musique à la volée.

3) **Astuces concrètes et réutilisables :**
- Utiliser un prompt textuel précis pour générer une application ou un jeu sur-mesure (ex. : « Un jeu de moto où la moto avance automatiquement et où on appuie sur la barre d'espace pour sauter »).
- Utiliser directement une URL personnalisée fictive (ex. : `keyboard.music`) dans la barre d'adresse de WebSim pour forcer l'IA à concevoir l'application correspondante (ex. : un clavier virtuel musical).
- Partager une création WebSim en copiant l'URL générée pour permettre à d'autres de jouer ou d'interagir avec la même application.
- Utiliser les options de tri (par jour, par semaine, par mois) pour découvrir les applications les plus impressionnantes créées par la communauté.
- Itérer sur le code ou l'application en donnant de nouveaux prompts de correction (ex. : « Le serpent devrait s'allonger lorsqu'il passe sur un carré rouge... ») pour corriger les bugs en quelques secondes.
