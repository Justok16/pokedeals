# Créez une extension de navigateur personnalisée [SUPER facile !]

Vidéo : https://youtu.be/BDWdp_fIOHk · durée 1:01 · résumé Gemini (gemini-3.5-flash-lite, lot de 9) du 2026-10-19
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale :** Démonstration de la création rapide d'une extension Chrome personnalisée (appelée « PageBrief ») en moins de 10 minutes à l'aide d'un modèle de langage open source économique et performant (GLM 5.2).

2) **Outils, sites ou dépôts GitHub cités :**
*   **GLM 5.2 (via ZAI) :** Payant / API (modèle open weight open source). Modèle de langage puissant et économique utilisé pour générer le code source complet de l'extension Chrome.
*   **Google Chrome :** Gratuit. Navigateur web utilisé pour installer et tester l'extension créée.

3) **Astuces concrètes et réutilisables :**
*   Pour créer une extension Chrome sans compétences avancées en programmation :
    1. Rédiger un prompt très détaillé décrivant toutes les fonctionnalités attendues de l'extension (ex. : résumer la page web actuelle, extraire les actions, copier en Markdown, interface propre).
    2. Demander au modèle (comme GLM 5.2) de générer l'ensemble des fichiers nécessaires (manifest.json, popup.html, script.js, etc.).
    3. Ouvrir Chrome, aller dans les extensions, activer le « Mode développeur », cliquer sur « Charger l'extension non empaquetée » (Load unpacked) et sélectionner le dossier contenant les fichiers générés.
*   Utiliser des modèles open weight moins coûteux (comme GLM) pour le prototypage rapide de code informatique.
