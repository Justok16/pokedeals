**1) Idée principale**
Démonstration pratique de l'utilisation de Claude Code et de son navigateur web intégré pour identifier la géolocalisation exacte d'une photo sans métadonnées GPS, puis créer instantanément une application web interactive d'exploration historique.

**2) Chaque outil, site ou dépôt GitHub cité**
*   **Claude Code (Anthropic)** | Payant (via abonnement Claude / API) | Outil de développement en ligne de commande (CLI) doté de capacités d'analyse d'images, d'exécution de code et de navigation web autonome.

**3) Les astuces concrètes et réutilisables**
*   **Enquêter sur une image sans GPS :** Charger une image dans un projet Claude Code et lui ordonner d'analyser tous les indices visuels secondaires (formes des côtes, silhouettes d'îles, végétation).
*   **Recherche croisée automatique :** Demander à Claude Code d'utiliser son navigateur web intégré pour faire des recherches visuelles croisées avec des photos d'archives ou des bases de données géographiques afin de trouver le point de vue exact.
*   **Création d'application à partir des résultats :** Ordonner à Claude Code de convertir immédiatement le fruit de sa recherche en une application web interactive (Artifact) intégrant un curseur de comparaison Temporel ("Avant / Après") et des explications sur la méthode de déduction.
