# AI News: The Best Open Source Model EVER

Vidéo : https://youtu.be/ybI3Y2zsFOM · durée 33:10 · résumé Gemini (gemini-3.5-flash-lite, lot de 9) du 2026-10-19
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale :** Revue des dernières actualités de l'IA de la semaine (sortie de Meta Llama 3, nouveautés sur Meta AI, HuggingChat, Stable Diffusion 3 API, Leonardo AI, Adobe Premiere Pro/Firefly, VASA-1 de Microsoft, etc.) et présentation de l'outil **GPT-Trainer.com** pour créer facilement des chatbots multi-agents sans code.

2) **Outils, sites ou dépôts GitHub cités :**
*   **Meta Llama 3 :** Gratuit / Open source (versions 8B et 70B disponibles, avec une version 400B+ en entraînement). Modèle de langage ouvert de Meta.
*   **HuggingChat (huggingface.co/chat) :** Gratuit. Plateforme d'Hugging Face permettant d'utiliser divers modèles open source, dont Llama 3.
*   **Meta AI (meta.ai) :** Gratuit. Nouvelle interface utilisateur de Meta intégrant un chatbot web et un générateur d'images animées (« Imagine »).
*   **Stable Diffusion 3 API :** Payant / Accès API (par Stability AI). Modèle de génération d'images par IA.
*   **Leonardo AI :** Gratuit / Payant (freemium). Plateforme de génération d'images et de transfert de style par IA.
*   **VASA-1 (Microsoft) :** Non commercialisé publiquement (projet de recherche). Modèle de génération de vidéos parlantes ultra-réalistes à partir d'une simple image et d'un fichier audio.
*   **InstantMesh (dépôt GitHub open source) :** Gratuit / Open source. Modèle de génération 3D rapide à partir d'une image 2D unique (licence Apache 2.0).
*   **Spline AI (spline.design/ai-generate) :** Gratuit / Payant (environ 24 $ à 40 $/mois). Outil de génération d'objets 3D et d'images 3D par IA.
*   **Meshry.ai :** Non précisé. Autre outil de génération de modèles 3D par IA.
*   **Adobe Premiere Pro (avec Firefly / Pika / Runway / Sora) :** Payant (abonnement Adobe). Logiciel de montage vidéo intégrant de nouvelles fonctions d'IA générative (extension générative, ajout/suppression d'objets, intégration de Sora).
*   **GPT-Trainer (gpt-trainer.com) :** Payant (avec code promo « MATTWOLFE20 » pour 20 % de réduction). Plateforme sans code / faible code pour créer des chatbots multi-agents entraînés sur ses propres données (fichiers, sites web, etc.) avec capacités de « function calling » (appels d'API, prise de rendez-vous) et détection de la frustration.
*   **Grok-1.5 Vision (xAI) :** Non précisé. Modèle multimodal d'xAI doté de capacités de vision.
*   **Poe (poe.com) :** Gratuit / Payant. Plateforme de chat regroupant plusieurs bots (Multi-Bot Chat).
*   **FutureTools.io :** Gratuit. Répertoire d'outils et d'actualités sur l'IA géré par l'auteur.

3) **Astuces concrètes et réutilisables :**
*   Pour tester rapidement Llama 3 sans l'exécuter en local, se rendre sur HuggingFace (huggingface.co/chat) et sélectionner le modèle Meta-Llama-3-70B.
*   Utiliser la fonction « Imagine » sur Meta.ai pour générer des images et tester l'option d'animation pour donner vie à une image fixe en quelques secondes.
*   Sur InstantMesh, glisser-déposer une image 2D (après avoir supprimé l'arrière-plan) pour générer automatiquement un modèle 3D exportable au format OBJ ou GLB.
*   Sur les outils de type GPT-Trainer, configurer des déclencheurs de « Détection de frustration » pour mieux gérer les clients mécontents dans les chatbots de service client.
