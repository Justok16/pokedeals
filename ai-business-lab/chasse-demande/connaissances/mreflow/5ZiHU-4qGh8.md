# Nvidia, Google And Some WILD AI Video Technology

Vidéo : https://youtu.be/5ZiHU-4qGh8 · durée 22:20 · résumé Gemini (gemini-3.5-flash-lite, lot de 2) du 2026-10-12
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale :** Cette vidéo présente un tour d'horizon des actualités et lancements récents en intelligence artificielle (IA), notamment en lien avec les conférences GTC et GDC de Nvidia, ainsi que de nouveaux outils de Google, Anthropic, OpenAI, Stability AI et d'autres entreprises. L'objectif est de synthétiser les nouveautés pour les passionnés et professionnels de la tech.

2) **Outils, sites ou dépôts GitHub cités :**
- **Nvidia GTC / GDC** (Conférences sur l'IA et le calcul accéléré) : Gratuit/Payant (événements de l'industrie).
- **Google Gemini (Canvas, Deep Research, Audio Overview, Mind Maps)** : Outils d'IA conversationnelle et de recherche intégrés à l'écosystème Google.
- **NotebookLM** : Outil de notes et de recherche alimenté par l'IA (permet de générer des mind maps et des podcasts audio).
- **TxGemma** : Modèle d'IA open source de Google pour la découverte de médicaments.
- **Claude (Anthropic)** : Assistant IA qui intègre désormais la recherche web directe.
- **OpenAI GPT-4o Transcribe / Mini Transcribe / Text-to-Speech** : Modèles d'IA audio et de transcription (payant via l'API, tarifs spécifiques annoncés).
- **o1-pro** (OpenAI) : Modèle avancé pour l'écriture de code via l'API (payant, tarifs très élevés).
- **Sonar (Perplexity)** : Modèle de recherche sémantique optimisé (version custom de Meta).
- **Mistral Small 3.1** : Modèle multimodal open source d'Mistral AI.
- **Ernie X1 (Baidu)** : Modèle de raisonnement en IA (concurrence de DeepSeek).
- **Adobe Journey Optimizer Experimentation Accelerator & Experience Manager Sites Optimizer** : Outils d'IA pour l'optimisation marketing et web d'Adobe.
- **Grok (xAI)** : Modèle d'IA de xAI (intégration de la génération vidéo via Hotshot et fonctionnalités sur X).
- **Pika** : Outil de génération et manipulation vidéo par IA (programme de partenariat créatif).
- **Krea AI** : Outil de génération et d'entraînement vidéo par IA.
- **Gigapixels v8.3.0 (Topaz Labs)** : Modèle de diffusion pour la restauration d'images haute résolution.
- **Stable Virtual Camera (Stability AI)** : Modèle de génération vidéo multi-vue avec contrôle de caméra 3D (gratuit pour usage non commercial, code disponible sur GitHub et Hugging Face).
- **Hunyuan3D-2** : Modèle open source de génération 3D (Hugging Face / GitHub).
- **Roblox Cube** : Système d'IA générative pour la création d'objets 3D et 4D (open source sur GitHub et Hugging Face).
- **Bigscreen Beyond 2** : Casque VR ultra-léger.
- **FutureTools.io** : Site web listant des outils IA et proposant une newsletter gratuite et une base de données de monétisation (IA Income Database).

3) **Astuces concrètes et réutilisables :**
- Utiliser la fonction **Canvas** ou **Deep Research** de Gemini pour structurer, éditer du code ou générer des résumés audio style podcast.
- Activer la recherche web dans **Claude** pour sourcer des informations actualisées directement depuis l'interface.
- Utiliser les modèles de transcription et de synthèse vocale d'OpenAI (GPT-4o) pour automatiser la conversion audio/texte à faible coût.
- Exploiter les fonctionnalités de mind mapping interactif dans **NotebookLM** pour synthétiser des documents de recherche.
