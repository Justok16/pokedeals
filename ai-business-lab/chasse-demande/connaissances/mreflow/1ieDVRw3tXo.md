1) **Idée principale**  
Cette vidéo présente les nouveaux outils de génération vidéo et d'animation faciale, l'arrivée de la création et du partage d'applications interactives dans les chatbots (Claude Artifacts, Poe Previews), les évolutions de licences commerciales (notamment Stable Diffusion 3 Medium), ainsi que les développements légaux et matériels liés à l'IA.

2) **Outils, sites ou dépôts GitHub cités**  
* **Odyssey** : Gratuit / Payant : non précisé (en cours de développement, non accessible au public). Outil de génération visuelle de niveau cinématographique entraînant 4 modèles génératifs (géométrie, matériaux, éclairage, mouvement).  
* **LivePortrait** : Gratuit (code source sur GitHub, démo Gradio gratuite sur Hugging Face Spaces). Outil animant une image fixe de portrait à partir d'une vidéo source de guidage (*driving video*).  
* **Paints-Undo** : Gratuit (code open source sur GitHub, notebook Google Colab prévu). Outil qui prend une image terminée et génère une vidéo montrant étape par étape la déconstruction / création du dessin (croquis, encrage, colorisation).  
* **Invideo AI (sponsor)** : Gratuit (version d'essai avec filigrane) / Payant (forfait Plus à 20 $/mois, forfait Max à 48 $/mois ; code promo MW50 pour doubler les crédits vidéo le premier mois). Outil automatisant la création complète de vidéos (script, montage, voix off, médias stock) à partir d'un simple prompt.  
* **Poe (par Quora)** : Gratuit avec options payantes (abonnements). Plateforme de chat multimodèle intégrant désormais « Previews », permettant d'exécuter et d'interagir directement avec des applications web interactives créées en code dans la conversation.  
* **Claude (Anthropic) - Artifacts** : Gratuit / Payant (inclus dans l'interface Claude). Espace de prévisualisation interactif permettant de générer du code, des graphiques ou des applications légères, désormais publiables, partageables et remixables.  
* **Anthropic Developer Console (console.anthropic.com)** : Payant (à l'usage de l'API / compte développeur Anthropic). Interface développeur intégrant un outil d'évaluation et d'optimisation de prompts en masse avec gestion de variables.  
* **MobileLLM (Meta)** : Gratuit / Recherche (non précisé pour le déploiement public). Famille de petits modèles de langage hautement performants optimisés pour les appareils mobiles.  
* **Thrive AI Health** : Non précisé (en développement par OpenAI Startup Fund et Thrive Global). Application mobile et d'entreprise de coaching de santé hyper-personnalisé par IA.  
* **Stable Diffusion 3 Medium (Stability AI)** : Gratuit pour un usage non commercial et gratuit pour un usage commercial si le revenu annuel est inférieur à 1 000 000 $ USD ; licence Entreprise payante obligatoire au-delà de 1 000 000 $ de revenus annuels. Modèle de génération d'images.  
* **Stable Assistant (Stability AI)** : Payant (essai gratuit de 3 jours). Suite web intégrant les modèles de Stability AI, incluant les fonctions *Search & Replace* (remplacement d'éléments dans une image) et génération audio.  
* **Magnific AI** : Payant. Outil d'agrandissement (*upscaling*) et d'enrichissement d'images par IA, désormais disponible comme plugin directement dans Adobe Photoshop.  
* **The Next Wave Podcast** : Gratuit. Podcast animé par Matt Wolfe et Nathan Lands sur l'IA et les technologies émergentes.  
* **Samsung Galaxy AI** : Inclus avec le matériel Samsung (Galaxy Z Fold 6, Z Flip 6, Galaxy Watch 7, Galaxy Ring, Galaxy Buds 3 Pro). Suite logicielle apportant la traduction en direct, le dessin vers image (*sketch to image*) et l'analyse de santé.  
* **Google DeepMind (Gemini / VLA)** : Non commercialisé / Recherche. Système de navigation robotique autonome couplant vision, langage et action au sein des bureaux de DeepMind.  
* **FutureTools.io** : Gratuit. Site de veille sur les outils d'IA.

3) **Astuces concrètes et réutilisables**  
* **Création et prototypage d'applications sans infrastructure** : Utilisez les fonctionnalités de partage de code d'Anthropic (Claude Artifacts) ou de Poe (Previews) pour générer, tester et faire tester des mini-outils web directement via une URL sans avoir à configurer de serveur ni d'hébergement.  
* **Optimisation de prompts industriels avec l'API Claude** : Dans la console développeur d'Anthropic, utilisez la fonction d'évaluation de prompt pour tester un prompt type avec différentes variables en batch (ex. robotique, impression 3D, etc.) et comparer automatiquement les sorties.  
* **Exploitation commerciale légale de Stable Diffusion 3** : Grâce à la mise à jour de la licence communautaire de Stability AI, toute entreprise ou créateur générant moins de 1 000 000 $ de chiffre d'affaires annuel peut désormais intégrer et utiliser SD3 Medium commercialement sans verser de royalties.  
* **Sécurité juridique sur l'usage de l'IA (décision de justice GitHub Copilot / OpenAI)** : Le tribunal californien a rejeté les plaintes pour violation du DMCA tant que le code ou le contenu généré en sortie n'est pas une copie conforme exacte du matériel d'entraînement sous copyright.
