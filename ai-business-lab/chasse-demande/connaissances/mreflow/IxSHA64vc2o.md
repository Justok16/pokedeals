# ACTUALITÉS IA : La prochaine génération d’outils d’IA est arrivée

Vidéo : https://youtu.be/IxSHA64vc2o · durée 28:45 · résumé Gemini (gemini-3.5-flash-lite, lot de 5) du 2026-10-08
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1. **Idée principale** :  
   Cette vidéo dresse un panorama complet des actualités de l'IA du mois (novembre/octobre), mettant en avant l'émergence des "navigateurs IA" (comme le navigateur de ChatGPT, Comet, Dia), les avancées des modèles de génération vidéo (OpenAI Sora, Google Veo 3.1, LTX-2), les nouveaux modèles d'image (MAI-Image-1), ainsi que l'intégration d'outils de code (Claude Code) et de studios d'IA (Google AI Studio).

2. **Outils, sites et dépôts GitHub cités** :  
   - **ChatGPT Atlas** : Navigateur web d'OpenAI (gratuit/payant via les abonnements ChatGPT). Sert à naviguer avec un assistant IA intégré.
   - **Comet** : Navigateur web IA (gratuit pour sa version de base, plan Pro payant).
   - **Dia** : Navigateur web natif IA (mentionné rapidement).
   - **Microsoft Edge** : Navigateur web intégrant Copilot (gratuit).
   - **Google Chrome / Brave** : Navigateurs web intégrant des fonctionnalités IA (gratuits).
   - **OpenAI Sora** : Modèle de génération vidéo (payant/abonnements Pro). Permet de créer des vidéos à partir de prompts ou d'images.
   - **Google Veo 3.1** : Modèle de génération vidéo (intégré dans les outils Google).
   - **LTX-2 (app.ltx.studio/ltx-2-playground)** : Moteur de création vidéo IA open-source avec synchronisation audio/vidéo (gratuit pour le playground).
   - **Leonardo.ai** : Plateforme de création artistique et vidéo (freemium).
   - **Kling 2.5 Turbo Standard** : Modèle de génération vidéo (payant/freemium).
   - **MAI-Image-1** (accessible via **LMarena.ai**) : Modèle de génération d'images (gratuit sur l'arène).
   - **NotebookLM** : Outil de notes et de recherche de Google intégrant la génération de vidéos (gratuit).
   - **Adobe Max / Creative Cloud** : Suite logicielle intégrant de nouveaux assistants IA (payant).
   - **Claude Code (claude.ai)** : Outil de code en ligne de commande/web connectable aux dépôts GitHub (payant/API).
   - **Google AI Studio (aistudio.google.com)** : Plateforme de prototypage pour développeurs avec la fonctionnalité "Vibe code" (gratuit avec quotas d'API).
   - **SWE-Bench Pro / SWE-1.5 / Sonnet 4.5 / Haiku 4.5** : Modèles et benchmarks de codage (payants via les abonnements/API respectifs).
   - **GPT-OSS-Safeguard** : Modèles open-source d'OpenAI axés sur la sécurité (gratuits/Hugging Face).

3. **Astuces concrètes et réutilisables** :  
   - Utiliser la fonction de sélection de premier et dernier frame sur les générateurs vidéo pour guider l'animation de manière précise.
   - Tester les modèles open-source gratuits (comme LTX-2) sur leurs playgrounds pour expérimenter la génération vidéo sans coût initial.
   - Utiliser l'arène de test (LMarena.ai) pour accéder gratuitement à des modèles de pointe en phase de test (comme MAI-Image-1).
   - Connecter Claude Code directement à ses dépôts GitHub pour gérer et construire des applications web sans quitter l'interface web.
   - Utiliser Google AI Studio pour générer du code à partir de prompts et s'aider des templates de code (React, Angular).
