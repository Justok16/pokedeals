1) **Idée principale :**
La vidéo présente trois nouvelles façons d'utiliser Codex (l'outil de programmation/IA), notamment pour scanner le web sans API, créer et publier des applications web interactives directement depuis la plateforme sans hébergement séparé, et transformer son iPhone en booster de codage Codex via une session vocale à distance.

2) **Outils, sites et dépôt GitHub cités :**
- **Codex (application/plateforme) :** Outil d'IA et de développement (avec application de bureau et application mobile), permettant de scanner des pages web, de construire et publier des applications web (via des sites web de prévisualisation intégrés) et de servir de booster de codage piloté par la voix connectant l'iPhone à l'application de bureau.
- **ChatGPT :** Mentionné comme modèle de base pour la création de code et la discussion dans Codex.

3) **Astuces concrètes et réutilisables :**
- **Scanner le web sans API :** Demander à Codex d'ouvrir un navigateur, de cliquer sur des sites web et de résumer des publications ou des sujets directement dans l'application sans configurer d'API complexe.
- **Créer et publier des applications web instantanément :** Demander à Codex de développer un jeu de tableau de bord ou une application web en mode travail (« work mode »), puis l'envoyer directement vers des sites de prévisualisation intégrés pour obtenir un lien partageable sans nécessiter de configuration d'hébergement externe.
- **Utiliser l'iPhone comme booster de Codex :** Connecter l'application iPhone à l'application de bureau via la fonctionnalité à distance et lancer une session vocale pour dicter des instructions de mise à jour de site web, exécuter des tests ou modifier le code pendant qu'on est loin de son bureau.
