# Cloner des applications payantes pour éviter de payer

Voici le résumé de la vidéo, structuré comme demandé :

### 1) Idée principale
Utiliser l'IA (en particulier Claude et ses modes avancés) pour créer soi-même des mini-logiciels et outils sur mesure (comme un clone de Paint, un convertisseur d'images ou un transcripteur vidéo), afin d'éviter de payer des abonnements logiciels mensuels superflus et d'optimiser sa productivité.

---

### 2) Outils, sites et dépôts GitHub cités

*   **Microsoft Paint** : Payant/Inclus (outil de dessin natif Windows, non disponible sur Mac).
*   **Warp (warp.dev)** : Offre un plan gratuit (avec limites de requêtes et accès à des modèles comme Claude 4.1 Opus) et des plans payants (non précisé). C'est un terminal intelligent doté d'un "Agent Mode" pour coder et créer des applications à partir de prompts.
*   **WhisperFlow** : Payant (abonnement Pro, non précisé, mais un code promo est donné). Application/outil pour transformer la voix en texte formaté et propre rapidement dans n'importe quelle application.
*   **Convertisseur d'images en ligne (nom exact non précisé, « free convert »)** : Gratuit. Permet de convertir des fichiers image un par un (payant en masse, 13 $ / mois selon le site évoqué).
*   **Claude / Claude AI (Claude 4.1 Opus / O3 Pro)** : Gratuit (version standard) / Payant (plans Pro). Assistant IA conversationnel et outil de programmation/génération de code.
*   **GitHub (github.com)** : Gratuit. Plateforme d'hébergement de code source où tous les projets de la vidéo sont partagés en open source (lien non précisé textuellement, mentionné dans la description de la vidéo).
*   **Rev** : Payant (16 $ / mois minimum, ou 45 minutes gratuites puis 10 $ / mois). Service de transcription vidéo.
*   **AssemblyAI (assemblyai.com)** : Offre un plan gratuit (50 $ de crédits offerts, soit ~185 heures) puis un plan "Pay as you go" (27 cents par heure). API de transcription audio/vidéo speech-to-text.
*   **ChatGPT (OpenAI)** : Gratuit (version standard). Assistant IA utilisé pour générer et déboguer du code de mini-applications.

---

### 3) Astuces concrètes et réutilisables

*   **Créer ses propres mini-outils gratuits** : Utiliser le terminal de Warp avec Claude en mode "Agent" pour rédiger des applications complètes (ex. : application Python de conversion d'images) à partir d'un simple prompt textuel.
*   **Utiliser la dictée vocale textuelle (WhisperFlow)** : Dicter ses prompts au lieu de taper à l'écrit pour aller plus vite, structurer sa pensée et donner plus de contexte à l'IA pour obtenir de meilleurs résultats en codage.
*   **Créer des scripts de conversion d'images en masse en local** : Demander à Claude de coder un script Python (`pillow` + `tkinterdnd2`) pour convertir par lots et gratuitement des formats (WebP, PNG, AVIF) en JPEG directement sur son bureau sans connexion Internet.
*   **Développer un transcripteur vidéo maison avec l'API AssemblyAI** : Demander à ChatGPT ou Claude de générer un mini-serveur local combinant l'API d'AssemblyAI avec une interface de glisser-déposer (drag-and-drop) pour transcrire des vidéos pour quelques centimes par heure au lieu d'abonnements chers.
*   **Itérer sur les erreurs de code** : Copier-coller directement les messages d'erreur du terminal dans le chat de l'IA (Claude ou ChatGPT) pour qu'elle corrige automatiquement le code ligne par ligne jusqu'à ce que l'application fonctionne parfaitement.
