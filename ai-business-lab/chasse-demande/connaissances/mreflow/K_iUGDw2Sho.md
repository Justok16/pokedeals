# Ce robot peut apprendre pratiquement N'IMPORTE QUELLE tâche

Vidéo : https://youtu.be/K_iUGDw2Sho · durée 0:48 · résumé Gemini (gemini-3.5-flash-lite, lot de 5) du 2026-10-08
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1. **Idée principale** :  
   Cette vidéo présente **S1** (le nouveau modèle de fondation pour robots de **Skild AI**), capable d'apprendre et d'exécuter des tâches physiques complexes (longues de plus de 10 minutes, comme faire du café, empoter des plantes, cuisiner ou manipuler des éprouvettes) à partir d'une seule vidéo de démonstration, sans réentraînement ni réglage fin (zero-shot). Elle aborde également les dernières avancées en matière de génération vidéo (LTX-2, Leonardo.ai, Sora), d'IA pour l'image (MAI-Image-1 via LMarena), et de développement assisté par IA (Claude Code et Google AI Studio).

2. **Outils, sites et dépôts GitHub cités** :  
   - **Skild S1** : Modèle de fondation pour la robotique (développé par Skild AI). Sert à apprendre des tâches physiques complexes par démonstration vidéo.
   - **LTX-2 (app.ltx.studio/ltx-2-playground)** : Moteur de création vidéo open-source avec génération audio/vidéo synchronisée (gratuit pour le playground).
   - **Leonardo.ai** : Plateforme de génération d'images et de vidéos (freemium) intégrant les modèles Veo, Sora, Kling et ses propres outils.
   - **Sora (OpenAI)** : Modèle de génération vidéo (payant/abonnements Pro).
   - **Kling 2.5 Turbo Standard** : Modèle de génération vidéo (payant/freemium).
   - **MAI-Image-1 (sur LMarena.ai)** : Modèle de génération d'images (gratuit sur l'arène).
   - **NotebookLM** : Outil Google pour générer des revues vidéo et résumés (gratuit).
   - **Adobe Max / Creative Cloud** : Suite logicielle intégrant le nouvel "AI Assistant" dans Photoshop, Premiere, etc. (payant).
   - **Black Forest Labs (Flux 1 / Flux 2)** : Modèles de génération d'images (freemium/API).
   - **Topaz Labs (Chopaz / Vibe Labs)** : Outils d'upscaling vidéo et image haut de gamme (payant).
   - **Claude Code (claude.ai)** : Outil de code connectable aux dépôts GitHub (payant/API).
   - **Google AI Studio (aistudio.google.com)** : Plateforme de développement avec la fonctionnalité "Vibe Coding" (gratuit avec quotas).
   - **SWE-Bench Pro / SWE 1.5 / Sonnet 4.5 / Haiku 4.5** : Modèles d'IA et benchmarks de codage (payants).
   - **GPT-OSS-Safeguard** : Modèles open-source d'OpenAI pour la sécurité (gratuits via Hugging Face).
   - **Future Tools (futuretools.io)** : Site web de l'auteur répertoriant les meilleurs outils IA (gratuit).

3. **Astuces concrètes et réutilisables** :  
   - Utiliser les nouvelles fonctionnalités de "First and Last Frame" dans les générateurs vidéo pour contrôler précisément le début et la fin d'une animation.
   - Expérimenter les modèles open-source comme LTX-2 pour générer des vidéos avec audio sans contrainte de budget.
   - Utiliser l'arène LMarena pour tester gratuitement des modèles d'images émergents comme MAI-Image-1.
   - Sur Adobe Photoshop, utiliser le remplissage génératif (Generative Fill) combiné aux modèles Flux ou Firefly pour retoucher et manipuler des images avec précision.
   - Utiliser Claude Code pour cloner et interagir directement avec des dépôts GitHub depuis une interface de terminal ou web.
