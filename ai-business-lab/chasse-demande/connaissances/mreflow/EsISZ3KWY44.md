1) **Idée principale** : Utilisation de la nouvelle fonctionnalité de ChatGPT Plus permettant d'appeler directement des GPTs personnalisés au sein d'une même conversation en utilisant le symbole "@", combinée à des outils de diagramme et de génération de code HTML/vidéo.

2) **Outils, sites ou dépôts GitHub cités** :
- **ChatGPT Plus** : Service payant d'OpenAI (20 $/mois), requis pour accéder à la fonctionnalité de mention des GPTs via "@".
- **Murder Mystery Mayhem / Nvidia GPT** : Exemples de GPTs personnalisés (gratuits pour les abonnés ChatGPT Plus).
- **Diagrams: Show Me** : GPT personnalisé (gratuit via ChatGPT) utilisé pour générer des diagrammes visuels (syntaxe Mermaid).
- **Video Maker by Invideo AI** : GPT personnalisé (gratuit via ChatGPT) connecté à l'outil InVideo pour générer des vidéos explicatives à partir de scripts textuels.
- **Consensus** : GPT personnalisé (gratuit via ChatGPT) utilisé pour rechercher des documents de recherche universitaire et des papiers scientifiques.
- **Screenshot To Code GPT** : GPT personnalisé (gratuit via ChatGPT) pour convertir des captures d'écran de diagrammes en code HTML/Tailwind.
- **Miro / Code** : Outils externes (gratuits/payants) pour éditer et visualiser le code et les diagrammes générés.
- **FutureTools.io** : Site web du créateur (gratuit), répertoire d'outils IA avec une newsletter et une base de données sur les revenus de l'IA.

3) **Astuces concrètes et réutilisables** :
- Dans ChatGPT Plus, taper `@` dans la zone de texte pour invoquer instantanément un GPT spécialisé (ex: pour générer un diagramme, chercher un papier académique ou coder) sans quitter la conversation en cours.
- Enchaîner les GPTs dans un seul flux de travail : demander un résumé de texte à un GPT, utiliser `@Diagrams: Show Me` pour le transformer en schéma visuel, puis utiliser `@Video Maker by Invideo AI` pour créer une vidéo explicative à partir de ce schéma.
