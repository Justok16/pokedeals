# Le meilleur modèle de codage actuel, haut la main

1) **Idée principale :** Analyse d'une session de codage de 20 heures avec le modèle Opus 5.5 pour recréer le jeu Megabonk, et comparaison des performances des modèles rapides et professionnels (Fast vs Pro) de Google Gemini pour la génération d'images, de textes et la traduction.

2) **Outils, sites ou dépôts GitHub cités :**
- **Opus 5.5** : Modèle d'IA payant utilisé pour générer et tester le code d'un jeu vidéo sur une longue période.
- **Megabonk** : Jeu vidéo (référence du projet cloné dans le test).
- **Nano Banana 2 (Gemini)** : Modèle d'image de Google (versions Fast et Pro) utilisé pour la génération d'infographies, la retouche d'images et la traduction multilingue.
- **Quiver** : Outil web de génération de graphismes vectoriels SVG et de code associé.

3) **Astuces concrètes et réutilisables :**
- Utiliser le mode "Pro" de Nano Banana 2 pour obtenir une meilleure fidélité textuelle et des détails plus poussés dans les images complexes, au détriment de la vitesse d'exécution.
- Laisser tourner un agent de codage (comme Opus 5.5) sur de longues périodes (jusqu'à 20 heures) pour coder, tester et déboguer des applications entières de manière autonome.
