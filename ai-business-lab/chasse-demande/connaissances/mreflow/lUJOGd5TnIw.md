(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale** : Présentation et test de Flux.1 (dans ses versions *schnell*, *dev* et *pro*), un nouveau modèle de génération d'images par IA développé par Black Forest Labs (composé de créateurs de Stable Diffusion), comparé à Midjourney et DALL-E 3. Le présentateur explore ses capacités, ses licences, et comment l'utiliser via Hugging Face ou la plateforme de workflows Glif.

2) **Outils, sites et dépôts GitHub cités** :
- **Flux.1 (par Black Forest Labs)** : Modèle de génération d'images en trois versions (*schnell*, *dev*, *pro*). Gratuit/open-source pour certaines versions, payant pour la version *pro*. Sert à générer des images par IA.
- **Hugging Face** : Site web. Gratuit. Héberge les modèles Flux.1 *schnell* et *dev* pour les tester en ligne.
- **GitHub** : Dépôt de code. Gratuit. Contient le code d'inférence pour Flux.1.
- **ComfyUI** : Outil d'IA. Gratuit (intégration mentionnée).
- **Replicate** : Site web. Payant/Freemium (mentionné pour l'API de Flux.1).
- **Fal.ai** : Site web. Payant/Freemium (mentionné pour l'API de Flux.1).
- **Glif** : Site web/plateforme de workflows ("workflow builder"). Gratuit pour tester les modèles Flux. Claude et ChatGPT sont également mentionnés comme LLM intégrables pour améliorer les prompts.

3) **Astuces concrètes et réutilisables** :
- Utiliser la version *schnell* de Flux.1 sur Hugging Face pour un usage local et personnel gratuit et rapide.
- Sur Glif, créer un workflow enchaînant un LLM (comme Claude 3.5 Sonnet) pour optimiser et enrichir un prompt de base avant de l'envoyer au générateur d'images Flux Pro.
- Ajuster le ratio d'image (ex: 16:9 paysage) dans Glif pour obtenir des formats spécifiques.
- Suivre des créateurs spécialisés (comme @angrypenguinPNG sur X/Twitter) pour obtenir des conseils de prompting avancés et des retours d'expérience sur l'IA.
