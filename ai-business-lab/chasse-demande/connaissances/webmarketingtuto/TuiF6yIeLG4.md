# Créer un Site 3D Animé avec Claude Code (Guide Complet)

Voici un résumé structuré de la vidéo concernant la création et le déploiement d'un site web premium avec Claude Code.

### 1) Idée principale
La vidéo explique comment utiliser **Claude Code** pour concevoir, personnaliser et déployer des sites web au rendu « premium » (animations 3D interactives, réactivité) sans nécessiter de compétences avancées en programmation ou en design, en passant par un hébergeur (Hostinger) pour la mise en ligne.

### 2) Outils, sites et dépôts cités
*   **Claude (par Anthropic) :** [Site web] Payant (Nécessite le plan Pro ou Max pour accéder à la fonctionnalité « Claude Code »). Il sert de moteur d'IA pour générer le code et gérer le déploiement du site.
*   **Hostinger :** [Site web] Payant (environ 4 €/mois selon l'offre). Il sert d'hébergeur pour mettre le site en ligne et de gestionnaire de nom de domaine.
*   **Git :** [Logiciel] Gratuit. Il doit être installé en amont sur l'ordinateur pour permettre à Claude Code de fonctionner.
*   **Skill (Template de site) :** [Dépôt de fichier] Gratuit. Fourni par l'auteur dans la description, il sert de base (template) pour créer le site 3D avec les animations spécifiques présentées.

### 3) Astuces concrètes et réutilisables
*   **Automatisation du design :** Utiliser des fichiers de logo ou d'icônes au format **SVG** (vectoriel) pour permettre à l'IA de les transformer plus facilement en objets 3D.
*   **Gestion des dossiers :** Créer un dossier spécifique sur son ordinateur et le donner en accès à Claude Code afin qu'il puisse y stocker tout le code et les ressources générées.
*   **Réglage du modèle IA :** Utiliser le mode "Extra" pour l'effort du modèle afin de conserver une qualité de code suffisante tout en limitant la consommation de "tokens".
*   **Déploiement simplifié :** Connecter Hostinger à Claude Code via l'option **OAuth** (Open Authorization) dans le terminal pour automatiser le transfert des fichiers du site vers le serveur.
*   **Gestion des mises à jour :** Pour modifier le site après publication, il suffit de demander les changements à Claude dans le chat et de lui demander de "redéployer le site".
*   **Optimisation des coûts :** Utiliser les codes promotionnels lors de la souscription à l'hébergeur pour obtenir des réductions supplémentaires sur le tarif affiché.

### 4) Chiffres de revenus annoncés
*   **Revenu attendu :** Non précisé.
*   **Coûts annoncés :**
    *   Hébergement Hostinger : "Moins de 4 € par mois" (affirmé par l'auteur).
    *   Coût annuel après réduction avec code promo : Environ 50 € par an (affirmé par l'auteur).

*Note : L'auteur insiste sur le fait que l'IA ne génère pas directement de l'argent, mais permet de créer des sites web (pour des clients ou soi-même) de manière beaucoup plus rapide et sans compétences techniques approfondies.*
