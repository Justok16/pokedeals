# Fiche de Connaissances : Leçon d'organisation du code et d'utilisation de l'IA (Conductor)

## 1. Sujet et thèse principale
* **Sujet :** L’utilisation d'agents de code et d’intelligences artificielles (comme Conductor) pour orchestrer et automatiser les tâches de développement sur Mac.
* **Thèse principale :** L’IA (Codex, Claude, etc.) transforme le rôle du développeur qui passe de la rédaction de code (comme de la « sciure ») à la description de besoins et à la supervision d'agents autonomes. Cependant, la rigueur humaine, les limites strictes et le respect de « zones sans IA » (zones protégées) restent essentiels pour éviter la dérive du code.

---

## 2. Notions expliquées (définitions simples)
* **Conductor :** Application macOS permettant d'orchestrer plusieurs agents de code en même temps.
* **Workspace (Espace de travail) :** Environnement virtuel ou chat pour gérer une tâche de code spécifique (analogue à un arbre de travail).
* **Mode Caveman :** Mode permettant de taper directement sur son clavier physique pour modifier un fichier (solution de secours).
* **Slot-free zones (Zones sans IA) :** Parties du code de base ou de la documentation qui doivent impérativement être écrites ou relues par des humains.
* **Token maxing / Token max :** Pratique consistant à utiliser massivement des tokens (IA) pour maximiser l’efficacité et la vitesse de développement.

---

## 3. Chiffres, taux, plafonds et règles fiscales cités
* **Juillet 2025 (début de Conductor) :** Dépense maximale de **22 000 $** en tokens sur un mois (avec des modèles de génération précédents, pour plusieurs dizaines de milliers de lignes de code par mois).
* **Configuration matérielle :** Mac avec 128 Go de RAM (permettant de faire tourner des modèles locaux comme Parakeet).
* **Règle fiscale/légale :** Aucune règle fiscale ou légale spécifique n’est mentionnée (À vérifier à la source officielle si applicable à votre juridiction).

---

## 4. Conseils concrets et leurs limites ou risques
* **Conseil :** Utiliser des agents IA pour automatiser les tâches répétitives, le feedback et la revue de code.
* **Conseil :** Conserver un contrôle humain (« Human in the loop ») strict sur les zones critiques de l'infrastructure (« Slot-free zones »).
* **Limite / Risque :** Le code généré par l'IA peut s'emballer ou générer du « mauvais code en boucle » s'il n'est pas strictement encadré par des limites humaines.
* **Risque :** Risque de dépendance totale aux modèles d'IA sans une compréhension claire de l'architecture de base.
