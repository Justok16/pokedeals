# Claude Opus 5.5 m'a fait un site à 5 000 € en 20 minutes ! (Zeyneb Madi)

### 1) L'idée principale
La vidéo explique comment concevoir et déployer des sites web professionnels (type "immersion") à l'aide de l'intelligence artificielle, en particulier **Claude Code**. L'auteure, Zeyneb, démontre qu'en utilisant les bons outils IA combinés à un hébergement fiable, il est possible de créer des produits numériques de haute qualité rapidement, destinés à des clients (ex: agences immobilières), ce qui constitue un levier de revenus dans l'économie de l'IA.

### 2) Outils, sites et dépôts GitHub cités
*   **Claude Code (Anthropic) :** Outil payant (abonnement). Il sert à automatiser le développement et le déploiement de sites web via des instructions (prompts) et des fichiers de configuration.
*   **Claude Chat / Claude Co-worker :** Payant. Utilisés pour le brainstorming, le développement de code et la structuration des projets.
*   **GitHub (référentiel "at-scroll-craft") :** Gratuit. Il contient les modèles et les structures de code nécessaires pour créer les sites avec des effets de "scroll" animés.
*   **Higgsfield :** Payant. Outil IA utilisé pour générer les visuels et les animations du site. Connecté à Claude via un connecteur.
*   **Hostinger :** Payant. Service d'hébergement web et VPS (serveurs privés). Utilisé pour la mise en ligne finale des sites web.
*   **Vercel :** Mentionné comme alternative pour l'hébergement (non utilisé dans la démonstration).

### 3) Astuces concrètes et réutilisables
*   **Utiliser les "Skill" (compétences) :** Créer des dossiers réutilisables contenant les structures de code et de design pour gagner du temps sur chaque nouveau projet.
*   **Travailler avec un VPS :** Pour sécuriser les données des clients et éviter les fuites ou les anomalies, héberger les agents IA sur un serveur privé virtuel (VPS) dédié.
*   **Utiliser le "MCP" (Model Context Protocol) :** Agit comme un câble USB reliant les applications entre elles. Cela permet de piloter des outils tiers (comme Higgsfield ou Hostinger) directement depuis l'interface de Claude.
*   **Optimiser la consommation de jetons :** Utiliser des fichiers texte (.md) clairs et structurés pour donner des instructions aux IA afin d'éviter les répétitions coûteuses.
*   **Déploiement automatisé :** Utiliser le plugin Hostinger pour Claude Code afin de déployer les sites en un clic, sans avoir à effectuer les manipulations manuelles complexes via FTP.
