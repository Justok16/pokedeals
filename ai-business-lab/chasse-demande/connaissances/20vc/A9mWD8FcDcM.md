**1) Sujet et thèse principale**  
Les limites du « vibe coding » (développement de code généré par IA) pour créer la logique métier complexe des petites entreprises.

**2) Notions expliquées (définitions simples)**  
* **Vibe coding / Claude Code :** Utilisation d'assistants IA pour générer du code informatique à partir d'instructions en langage naturel.  
* **Logique métier (Business logic) :** L'ensemble des règles de fonctionnement spécifiques à une activité (ex. gestion de rendez-vous pour un coiffeur, livraison pour une pizzeria).

**3) Chiffres, taux, plafonds et règles fiscales cités**  
* **Durée du test :** Expérimentation menée sur 2 semaines chez Wix.  
* **Horizon temporel :** Possibilité envisagée d'ici « quelques années », mais jugée très éloignée aujourd'hui.  
* *(À vérifier à la source officielle : aucune règle fiscale ou légale citée).*

**4) Conseils concrets et leurs limites ou risques**  
* **Prudence avec le code généré par IA :** Pour des applications métiers complexes comprenant de nombreux cas particuliers, l'IA ne remplace pas encore le développement structuré.  
* **Limites :** Même des équipes de développeurs chevronnés n'ont pas réussi à créer une logique métier complète et totalement fonctionnelle uniquement avec des générateurs de code IA actuels.
