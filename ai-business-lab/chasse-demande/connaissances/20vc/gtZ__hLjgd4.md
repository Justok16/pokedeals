# D'ici deux ans, __% du code sera écrit par l'IA

Vidéo : https://youtu.be/gtZ__hLjgd4 · durée 0:25 · résumé Gemini (gemini-3.6-flash, lot de 8) du 2026-10-29
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

**1) Sujet et thèse principale**
* **Sujet :** L'automatisation de la création de code informatique par les modèles d'intelligence artificielle.
* **Thèse principale :** L'écriture de code logiciel sera quasi-intégralement prise en charge par des agents d'IA d'ici deux ans, déplaçant le travail des développeurs vers la formulation d'instructions (*prompting*).

**2) Notions expliquées**
* **Prompting agents :** Utilisation de consignes textuelles pour piloter des agents d'IA afin qu'ils conçoivent et corrigent du code informatique.
* **Dépôt de code structuré pour LLM (*LLM-friendly repository*) :** Organisation des fichiers source d'un logiciel optimisée pour qu'un modèle de langage puisse y naviguer et y coder facilement.

**3) Chiffres, taux, plafonds et règles fiscales cités**
* **50 % :** Part estimée du code actuellement rédigé par IA chez Robinhood et Salesforce.
* **90 % :** Part du code aujourd'hui écrit par IA chez la startup Base44.
* **95 % à 100 % :** Proportion de code qui sera générée par IA d'ici 2 ans selon l'intervenant.
* **Règles fiscales :** Non précisé.

**4) Conseils concrets et leurs limites ou risques**
* **Conseil :** Structurer la base de code des nouveaux projets informatiques pour permettre une interaction directe et fluide avec les agents d'IA.
* **Limites / Risques :** Dépendance forte aux performances des LLMs ; nécessité de contrôler la qualité et la sécurité du code généré automatiquement.

**5) Produits, applications ou entreprises cités**
* **Base44 :** Société cofondée par l'intervenant Maor Shlomo (produit de l'auteur invité).
* **Robinhood, Salesforce :** Cités à titre d'exemples d'entreprises utilisant l'IA pour le dev (pas de publicité).
