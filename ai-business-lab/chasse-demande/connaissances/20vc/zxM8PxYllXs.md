# La revue de code est plus importante que le codage par IA

Vidéo : https://youtu.be/zxM8PxYllXs · durée 1:00 · résumé Gemini (gemini-3.5-flash, lot de 8) du 2026-10-26
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

**1) Sujet et thèse principale**
Discussion entre investisseurs sur le développement logiciel assisté par IA. La thèse est que la revue de code (*code review*) est aujourd'hui une catégorie bien plus cruciale que la simple génération de code, car transformer du code généré par IA en code prêt pour la production prend 10 fois plus de temps que sa création.

**2) Notions expliquées**
* **Revue de code (*Code review*)** : Analyse et vérification rigoureuse du code informatique afin d'en assurer la sécurité, la maintenabilité et la qualité.
* **Code prêt pour la production (*Production intent*)** : Code répondant à l'ensemble des critères de fiabilité et de sécurité requis pour fonctionner sur des systèmes en direct.
* **Vibe coding** : Pratique consistant à générer du code rapidement via l'IA sans effectuer les vérifications d'architecture approfondies.

**3) Chiffres, taux, plafonds et règles fiscales cités**
* **10, 12, 14 heures par jour** : Temps passé par certains développeurs à générer du code sur des assistants IA.
* **Un ordre de grandeur (x10)** : Facteur de temps supplémentaire nécessaire pour réviser et valider du code par rapport au temps qu'il faut pour le générer.
* **600 milliards de dollars** : Chiffre cité à titre d'illustration de la valorisation potentielle du secteur.
* Règles fiscales : non précisé.

**4) Conseils concrets et leurs limites ou risques**
* **Conseil** : Financer et utiliser en priorité des outils spécialisés dans la revue et le contrôle du code pour acheminer les développements vers la production.
* **Limites / Risques** : Risque que les jeunes entreprises de revue de code se fassent dépasser ou absorber par de grands acteurs comme Anthropic.
