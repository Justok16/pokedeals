# Utiliser les ratios de valorisation

1. Sujet et thèse principale :
- Sujet : Le calcul et l'utilisation des ratios de valorisation (multiples) pour comparer les entreprises entre elles.
- Thèse : Valoriser une entreprise est complexe ; face à l'impossibilité de calculer précisément la valeur intrinsèque (DCF, actif net), on utilise la valeur relative via des multiples (PER, EV/EBITDA, etc.), à condition de respecter certaines règles de cohérence sectorielle et financière.

2. Notions expliquées :
- Valeur intrinsèque : Valeur fondamentale d'une entreprise calculée indépendamment du marché (ex. par actualisation des flux de trésorerie - DCF).
- Valeur relative : Comparaison de la valorisation d'une entreprise par rapport à ses concurrents, son secteur ou son historique.
- Multiple (ratio de valorisation) : Rapport entre le prix payé pour l'actif et ce que l'on reçoit en retour (résultat, chiffre d'affaires, etc.).
- Capitalisation boursière (Equity / Capi) : Valeur de marché des actions de l'entreprise.
- Valeur d'entreprise (Enterprise Value / EV) : Capitalisation boursière + dettes financières nettes (dettes moins cash).
- PER (Price Earning Ratio) : Cours de l'action divisé par le bénéfice net par action.
- EV/EBITDA : Valeur d'entreprise divisée par l'excédent brut d'exploitation.
- Price to Sales (P/S) : Cours sur chiffre d'affaires.
- Price to Book (P/B) : Cours sur actif net (capitaux propres).
- PEG : PER divisé par le taux de croissance des bénéfices.

4. Conseils concrets, limites et risques :
- Choisir le bon ratio selon le contexte :
  1. Si les entreprises ont le même levier (endettement) : utiliser les ratios basés sur la capitalisation (ex. PER, Cours/CA).
  2. Si les leviers sont différents : utiliser les ratios basés sur la Valeur d'Entreprise (EV) pour neutraliser la dette.
  3. En cas de fortes différences de croissance : utiliser le PEG.
  4. Pour les secteurs très capitalistiques : regarder le Cours/Actif Net (P/B) ou la proximité de liquidation.
  5. Pour les entreprises sans bénéfices (start-ups) : utiliser le Cours/Chiffre d'Affaires (P/S) ou EV/CA.
- Attention : Ne jamais mélanger le numérateur (valeur de marché de l'action seule) et le dénominateur (résultat distribuable global incluant les créanciers) pour rester cohérent.
- Limite : Les marchés financiers sont arbitrés et les ratios ne suffisent pas seuls ; ils doivent être replacés dans leur secteur et comparés entre pairs comparables.
