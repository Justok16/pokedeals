1) **Idée principale :** Présentation de 5 extensions indispensables pour VS Code (Error Lens, VSCode React Refactor, Thunder Client, SVG Preview, GitLens) destinées à améliorer la productivité des développeurs en 2023.

2) **Outils, sites ou dépôts GitHub cités :**
- *Error Lens* (Extension VS Code) : Gratuit. Affiche les erreurs et avertissements de l'éditeur directement sur la ligne de code correspondante.
- *VSCode React Refactor* (Extension VS Code) : Gratuit. Permet de transformer rapidement des fonctions React (ex: convertir une arrow function en fonction classique, wrapper dans un useMemo ou React.forwardRef).
- *Thunder Client* (Extension VS Code) : Gratuit. Alternative légère à Postman pour tester des API REST directement dans l'éditeur, gérer des collections, des requêtes et des variables d'authentification.
- *SVG Preview* (Extension VS Code) : Gratuit. Permet de prévisualiser, modifier et optimiser (minifier) des fichiers SVG en un clic.
- *GitLens* (Extension VS Code) : Gratuit / payant (fonctionnalités avancées). Améliore l'intégration Git avec l'historique des commits par ligne (git blame), le graphe de commits et la visualisation de l'historique des fichiers.
- *Notion* (Application de productivité) : Gratuit / payant. Utilisé pour répertorier la configuration VS Code et les extensions de l'auteur.

3) **Astuces concrètes et réutilisables :**
- Utiliser *Error Lens* pour repérer immédiatement les erreurs de code sans avoir à survoler la zone ou ouvrir le panneau des problèmes.
- Gagner du temps lors du test d'API avec *Thunder Client* en créant des collections de requêtes réutilisables (GET, POST avec corps JSON, en-têtes d'authentification Bearer Token).
- Organiser et prévisualiser les icônes SVG directement dans l'éditeur grâce à *SVG Preview* pour éviter des allers-retours avec un navigateur.
- Utiliser *GitLens* pour afficher la ligne de commit (Heure/Auteur) directement dans le code et comprendre rapidement l'historique d'une modification.
