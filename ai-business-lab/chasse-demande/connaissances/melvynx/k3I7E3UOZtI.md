1. **Idée principale** : Comparaison entre Cursor et Windsurf, deux environnements de développement propulsés par l'intelligence artificielle, pour déterminer lequel offre la meilleure autocomplétion, le meilleur support de contexte et les fonctionnalités les plus avancées pour le codage.

2. **Outils, sites ou dépôts GitHub cités** :
   - **Cursor** : Éditeur de code (et/ou extension/outil d'IA pour le code), payant (modèle tarifaire abordable comparé à Windsurf). Sert à l'autocomplétion rapide, la lecture de fichiers via le shadow workspace, la génération de code et le commit assisté par IA.
   - **Windsurf** : IDE/assistant IA pour le code, payant (plus cher que Cursor). Sert à l'autocomplétion, au chat inline et aux fonctionnalités d'IA (Cascade).
   - **Lucide-react** : Bibliothèque d'icônes mentionnée dans un exemple de code.
   - **Next.js** : Framework web mentionné via des imports et dans les documents/configurations de test.
   - **Prisma** : Outil ORM mentionné dans les exemples de code.

3. **Astuces concrètes et réutilisables** :
   - Utiliser des fichiers de configuration globaux ou par espace de travail (`.cursor/rules` ou règles Windsurf) pour guider le comportement de l'IA.
   - Profiter de l'autocomplétion « Tab to jump » pour accepter rapidement les suggestions de code.
   - Utiliser les raccourcis de commit assisté par IA (disponible dans Cursor) pour automatiser la rédaction des messages de commit.
   - Configurer des règles spécifiques dans les dossiers de projet pour que l'IA comprenne la structure et les conventions du code.
