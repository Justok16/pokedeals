1) **Idée principale :** Tout ce qu'il faut savoir sur TypeScript en 5 minutes : son origine, son fonctionnement (transpilation en JavaScript), son typage et ses fonctionnalités avancées (Utility Types).
2) **Outils, sites ou dépôts cités :**
   - **TypeScript :** Langage open source développé par Microsoft (gratuit).
   - **JavaScript :** Langage de base (gratuit).
   - **VS Code :** Éditeur de code (gratuit).
3) **Astuces concrètes et réutilisables :**
   - Comprendre que le navigateur ne comprend que le JavaScript, donc le code TypeScript doit être transpilé en JS avant l'exécution.
   - Utiliser le typage explicite (`string`, `number`, etc.) pour éviter les erreurs à l'exécution (runtime).
   - Utiliser des types union (`|`) pour autoriser plusieurs types ou `undefined`.
   - Utiliser les Utility Types de TypeScript (`Pick`, `Omit`, `Record`, etc.) pour manipuler et simplifier les types existants.
