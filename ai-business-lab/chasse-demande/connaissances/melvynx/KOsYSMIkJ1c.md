# TUTO : OpenClaw + Docker + VPS, setup ton agent IA sur ton VPS (sécurisé)

Vidéo : https://youtu.be/KOsYSMIkJ1c · durée 33:09 · résumé Gemini (gemini-3.5-flash-lite, lot de 4) du 2026-10-08
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale :** Tutoriel pour configurer et lancer **OpenClaw** (un agent IA polyvalent) sur un VPS (serveur virtuel privé) en moins de 20 minutes, en connectant des outils comme Telegram, Docker et l'API d'OpenAI/Claude.
2) **Outils, sites et dépôts cités :**
- OpenClaw (dépôt GitHub/application, gratuit, agent IA polyvalent)
- Hetzner (site d'hébergement VPS, payant, fournisseur de serveurs pas chers)
- Docker / Docker Compose (logiciel de conteneurisation, gratuit, exécution de services)
- Coolify (outil de déploiement, gratuit, gestion de VPS)
- SSH / Terminal (outils système, gratuits, gestion de serveur)
- mlv.sh/fo (URL, gratuit, lien de documentation OpenClaw)
- OpenAI / Codex (API, payant, modèles de langage)
- Telegram (application de messagerie, gratuite, interface de bot)
- Claude Code / Anthropic (outil CLI/API, payant, assistant de code)
3) **Astuces concrètes et réutilisables :**
- Utiliser un VPS (comme Hetzner, jugé économique et optimisé) pour faire tourner des agents IA 24h/24 en arrière-plan.
- Configurer un serveur distant via Docker et un fichier `docker-compose.yml` pour isoler et exécuter OpenClaw proprement.
- Associer OpenClaw à un bot Telegram et appairer l'appareil avec une commande `pairing` pour interagir directement avec l'agent depuis son téléphone.
4) **Chiffres de revenus annoncés :** Non précisé (l'auteur mentionne un cours/formation payant autour de 1000€ ou des abonnements d'API à quelques centaines de dollars, mais aucun chiffre de *revenu personnel* n'est affirmé par l'auteur).
