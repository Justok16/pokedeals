# TUTO React Server Component de A à Z

Vidéo : https://youtu.be/u4wV0-31oI0 · durée 42:46 · résumé Gemini (gemini-flash-lite-latest, lot de 8) du 2026-10-18

1) **Idée principale :** Comprendre le fonctionnement des Server Components (RSC) et des Client Components dans React (avec Next.js), leurs différences de rendu, d'hydratation et d'impact sur les performances, ainsi que la manière de les composer.
2) **Outils, sites ou dépôts GitHub cités :**
   - **React** (gratuit, bibliothèque front-end)
   - **Next.js** (gratuit, framework React supportant les Server Components)
   - **React Markdown** (gratuit, bibliothèque pour le rendu Markdown)
   - **Prisma** (gratuit/open source, ORM pour interagir avec les bases de données)
   - **OpenAI** (API payante, services d'IA)
3) **Astuces concrètes et réutilisables :**
   - Utiliser par défaut les Server Components pour éviter d'envoyer du code JavaScript lourd au client et exécuter les requêtes de données côté serveur.
   - Ajouter la directive `"use client"` uniquement sur les composants qui nécessitent de l'interactivité (gestion d'état, écouteurs d'événements, hooks comme `useState`).
   - Tirer parti de la composition en passant des Server Components ou du HTML en tant que `children` (via `props.children`) dans des Client Components pour éviter de transformer toute l'arborescence en composants clients.
   - Utiliser le streaming pour charger progressivement des parties de la page avec `Suspense`.
