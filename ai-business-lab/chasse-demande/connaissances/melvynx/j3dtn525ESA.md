# 7 Raccourcis VSCode INDISPENSABLES

- **Idée principale :** Présentation des 7 meilleurs raccourcis et astuces indispensables pour optimiser sa productivité sur l'éditeur VS Code.
- **Outils, sites ou dépôts GitHub cités :**
  - **Visual Studio Code (VS Code) :** Éditeur de code gratuit.
  - **Tailwind CSS :** Framework CSS open-source gratuit.
  - **OpenAI API :** API payante (mentionnée dans un exemple de code).
  - **Git / GitHub :** Outils de gestion de version gratuits.
- **Astuces concrètes et réutilisables :**
  - **Raccourci 1 (Trigger Suggest / Auto-complétion) :** Utiliser `Ctrl + Espace` (ou `Option + Échap` sur macOS) pour ouvrir l'autocomplétion. Utiliser aussi `Ctrl + Échap` pour ouvrir la page de suggestions.
  - **Raccourci 2 (Renommer un symbole) :** Faire clic droit > *Rename Symbol* (ou renommer une variable/composant) pour propager automatiquement le changement dans tout le projet.
  - **Raccourci 3 (Déplacer du code) :** Utiliser des raccourcis de déplacement de lignes (option + flèches) pour réorganiser le code facilement.
  - **Raccourci 4 (Palette de commandes) :** Utiliser `Cmd + P` (ou `Ctrl + P`) pour rechercher et ouvrir n'importe quel fichier rapidement sans utiliser la souris.
  - **Raccourci 5 (Command + Shift + P) :** Ouvrir la palette de commandes globale pour exécuter des actions comme *Reload Window*, changer le thème de couleurs, ou accéder aux paramètres.
  - **Raccourci 6 (Open Keyboard Shortcuts & configuration des imports automatiques) :** Configurer des raccourcis personnalisés pour l'organisation et l'importation automatique des modules (`editor.action.sourceAction` avec `source.addMissingImports` et `organizeImports`).
  - **Raccourci 7 (Commenter des lignes) :** Utiliser le raccourci de commentaires (sur Windows/Mac via les réglages de raccourcis clavier pour "Toggle Line Comment", par exemple `Shift + Cmd + 7`) pour commenter du code rapidement, y compris en JSX/TSX.
