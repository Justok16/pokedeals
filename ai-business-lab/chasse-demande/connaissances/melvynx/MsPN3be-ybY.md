# 4 Heures pour Créer une App 3D DE MA CASQUETTE

Vidéo : https://youtu.be/MsPN3be-ybY · durée 7:32 · résumé Gemini (gemini-flash-lite-latest, lot de 9) du 2026-10-18
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale :** L'auteur se lance le défi de recréer en moins de 4 heures le logo d'un ami (un design en forme d'atome avec une casquette) sur un site web interactif en 3D en utilisant React, Three.js et Blender, puis de créer et déployer un sticker associé.
2) **Outils, sites ou dépôts GitHub cités :**
- **React** (non précisé) : Framework JavaScript pour construire l'application web.
- **Three.js / ThreeJS** (non précisé) : Bibliothèque JavaScript pour la 3D.
- **Blender** (non précisé) : Logiciel de modélisation 3D pour créer le modèle de la casquette.
- **Excalidraw** (non précisé) : Outil de dessin et de maquettage pour concevoir le logo.
- **Three.js Journey** (non précisé) : Cours de Bruno Simon sur Three.js (lien en description).
- **ChatGPT** (non précisé) : IA utilisée pour générer et décrire le code du module 3D.
- **Redbubble** (non précisé) : Site web pour créer, mettre en vente et acheter le sticker (ou autres goodies).
- **Porkbun** (non précisé) : Service d'enregistrement de nom de domaine (porkbun.com).
- **Vercel** (non précisé) : Plateforme de déploiement pour héberger le site web.
3) **Astuces concrètes et réutilisables :**
- Décomposer le projet en étapes claires : créer le site Three.js, créer le logo React, créer le modèle 3D de la casquette, l'ajouter au site, et ajouter un shop avec un bouton d'achat.
- Utiliser la trigonométrie (sinus, cosinus, calculs mathématiques avec `Math.PI` et la division par 2) pour positionner correctement les éléments 3D (les anneaux et les sphères/« coulasses ») autour d'une sphère centrale.
- Ne pas s'appuyer uniquement sur les LLM (comme ChatGPT) pour des technologies 3D complexes non documentées, car ils peuvent induire en erreur ; préférer la documentation officielle ou des cours spécialisés.
- Acheter un domaine via un registrar simple et déployer rapidement ses projets sur Vercel pour tester en production.
