1) **Idée principale** : TypeScript est une surcouche de JavaScript ; pour bien l'utiliser et éviter les pièges, il est indispensable de maîtriser d'abord les bases de JavaScript.
2) **Outils, sites ou dépôts GitHub cités** :
   - TypeScript : nom exact, gratuit, surcouche de JavaScript avec typage.
   - JavaScript : nom exact, gratuit, langage de programmation.
3) **Astuces concrètes et réutilisables** :
   - Apprendre JavaScript en premier avant de passer à TypeScript, car ce dernier est une extension de JavaScript.
   - Ne pas utiliser TypeScript directement sans comprendre le JavaScript sous-jacent, sous peine de rencontrer des erreurs de compilation ou de compréhension difficiles à résoudre.
