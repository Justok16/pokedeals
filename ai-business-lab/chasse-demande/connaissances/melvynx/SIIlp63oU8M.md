# BMAD est déjà inutile... Opus 4.5 l'a tuée

Vidéo : https://youtu.be/SIIlp63oU8M · durée 31:08 · résumé Gemini (gemini-3.5-flash-lite, lot de 8) du 2026-10-08
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1. **Idée principale :** L'auteur présente en détail le projet open-source **BMAD-Method**, un framework d'agents IA autonomes pour le développement agile, analyse sa complexité, ses flux de travail (workflows) et teste son installation ainsi que son exécution via la ligne de commande.
2. **Outils et dépôts GitHub :**
   * **BMAD-Method** (`bmad-code/bmad-method` sur GitHub) : Dépôt public open-source (gratuit) d'agents IA pour le développement agile.
   * **Claude Code** : Utilisé pour exécuter et tester les commandes du dépôt.
   * **Plateforme de formation de l'auteur** (`mlv.sh/ai`) : Masterclass gratuite sur Claude Code.
3. **Astuces concrètes :**
   * Installer BMAD-Method via la commande `npx bmad-method@alpha install`.
   * Initialiser un projet avec `workflow-init` pour configurer les agents et les phases de développement.
   * Utiliser les différents modules de workflows (Discovery, PRD, Solutioning, Implementation) pour structurer le code par agents IA.
4. **Chiffres affirmés par l'auteur :**
   * 21 spécialisés IA agents.
   * 4 modules principaux et plus de 50 workflows guidés.
   * Coût de l'API indiqué pour l'utilisation : 237 $ par jour (mentionné comme équivalent de consommation d'API sans BMAD).
