### 1) Idée principale
Il est possible de devenir « vibe codeur » et de créer des applications complexes (même sur iOS et WatchOS) sans savoir coder, en s'appuyant sur l'IA (notamment Claude Code) et une roadmap structurée autour d'outils adaptés, d'une pile technologique, de workflows et de boilerplates.

### 2) Outils, sites et dépôts GitHub cités

*   **GitHub**
    *   *Modèle :* Gratuit (avec des offres payantes).
    *   *Rôle :* Interface pour publier, déployer et versionner son code.
*   **Claude Code**
    *   *Modèle :* Payant / abonnement lié aux API (ou usage via l'outil de l'auteur ; l'auteur mentionne un coût d'usage personnel d'environ 70 $ dans sa démo).
    *   *Rôle :* Agent IA en ligne de commande pour coder de A à Z.
*   **Terminal**
    *   *Modèle :* Intégré au système d'exploitation (gratuit).
    *   *Rôle :* Interface de commandes pour piloter l'ordinateur.
*   **IDE VS Code (Visual Studio Code)**
    *   *Modèle :* Gratuit.
    *   *Rôle :* Environnement de développement et éditeur de code.
*   **Vercel**
    *   *Modèle :* Freemium (gratuit pour démarrer).
    *   *Rôle :* Plateforme de déploiement simple.
*   **Shadcn/UI**
    *   *Modèle :* Gratuit (open source).
    *   *Rôle :* Librairie de composants graphiques UI pour des applications de qualité.
*   **Upstash**
    *   *Modèle :* Freemium.
    *   *Rôle :* Outil d'écosystème (base de données / gestion de cache / services serverless).
*   **Ingest (Injest)**
    *   *Modèle :* Freemium.
    *   *Rôle :* Agent orchestrateur pour fiabiliser et gérer les flux de code/tâches.
*   **Fichiers R2 / Blob**
    *   *Modèle :* Payant à l'usage (fournisseurs cloud type Cloudflare, etc.).
    *   *Rôle :* Stockage de fichiers.
*   **Claude Code / Codex**
    *   *Modèle :* Payant / API.
    *   *Rôle :* Outils d'IA pour gérer skills, PRD, tâches, commandes, prompts et automatismes (MCP).
*   **WSL (Windows Subsystem for Linux)**
    *   *Modèle :* Gratuit.
    *   *Rôle :* Environnement Linux pour Windows facilitant l'installation des outils de dev.
*   **NodeJS**
    *   *Modèle :* Gratuit.
    *   *Rôle :* Environnement d'exécution JavaScript.
*   **Lovable (lovable.dev)**
    *   *Modèle :* Freemium (credits gratuits puis payant).
    *   *Rôle :* Générateur d'applications no-code/IA rapide (cité en exemple d'outil d'écosystème).
*   **NowTS (nowts.app)**
    *   *Modèle :* Payant (boilerplate de l'auteur).
    *   *Rôle :* Boilerplate SaaS avec authentification, sécurité, organisation et base prête à l'emploi.
*   **Next.js SaaS Starter (dépôt GitHub)**
    *   *Modèle :* Gratuit (open source).
    *   *Rôle :* Boilerplate communautaire Next.js pour démarrer un SaaS.
*   **Vercel Boilerplate / Templates**
    *   *Modèle :* Gratuit / Intégré à Vercel.
    *   *Rôle :* Templates d'authentification et de démarrage SaaS.
*   **Better Auth (better-auth / better-auth.com)**
    *   *Modèle :* Gratuit / Open source.
    *   *Rôle :* Outil puissant de gestion de l'authentification.
*   **React Native Boilerplate**
    *   *Modèle :* Variable (certains gratuits, certains payants).
    *   *Rôle :* Boilerplate pour créer des applications mobiles natives.

### 3) Astuces concrètes et réutilisables

*   **Utiliser un environnement de travail propre :** Sous Windows, installer WSL, NodeJS, Git et VS Code ; sous MacOS, installer NodeJS, Git et VS Code pour éviter des heures de bugs d'installation.
*   **Maîtriser les commandes de base du terminal :** Apprendre à utiliser `cd`, `ls`, `mkdir`, la gestion des chemins, et les commandes de lancement (ex: `pnpm dev` pour lancer un serveur local sur `localhost:3000`).
*   **S'appuyer sur des Boilerplates (kits de démarrage) :** Ne pas coder une application de zéro, mais utiliser un template SaaS déjà configuré (avec authentification, base de données et sécurité intégrées) pour gagner un temps précieux.
*   **Déléguer la syntaxe à l'IA :** Ne pas perdre de temps à apprendre le HTML, CSS, JS/React ou l'algorithmique pure ; se concentrer sur la *compréhension* de l'architecture (front-end vs back-end, gestion du cache, rôles de l'IA).
*   **Vérifier le code généré via des structures claires :** Utiliser des outils d'orchestration (comme Ingest) et des agents pour structurer les processus de développement (PRD, architecture, tâches).
