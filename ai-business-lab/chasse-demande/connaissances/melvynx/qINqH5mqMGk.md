# Bientôt plus de développeurs, que des managers : pourquoi l'IA change tout ?

Vidéo : https://youtu.be/qINqH5mqMGk · durée 17:18 · résumé Gemini (gemini-flash-lite-latest, lot de 6) du 2026-10-11
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale :** Cette vidéo explore le débat sur le fait de savoir si coder avec l'IA (comme Claude Code ou Cursor) est toujours un plaisir pour les développeurs, en confrontant le point de vue de créateurs (comme DHH) qui craignent de perdre le contact direct avec le code, à la réalité d'un changement de paradigme où le développeur devient un "manager d'agents" capable de multiplier sa productivité.

2) **Outils, sites ou dépôts GitHub cités :**
* **Claude Code** (outil CLI d'Anthropic) : Payant/abonnement, assistant de code en terminal.
* **Cursor** (éditeur de code IA) : Payant (abonnement Pro), éditeur de code.
* **Windsurf** (éditeur de code IA) : Payant/freemium, éditeur de code intelligent.
* **GitHub Copilot** (assistant IA) : Payant, assistant de code.
* **Xcode** (IDE d'Apple) : Gratuit, utilisé pour le développement Swift/iOS.
* **Excalidraw** (outil de schéma) : Gratuit/freemium, utilisé pour dessiner des diagrammes explicatifs.
* **YouTube** (plateforme vidéo) : Gratuit, source des podcasts et interviews analysées.

3) **Astuces concrètes et réutilisables :**
* **Gérer la transition de "codeur" à "manager d'agents" :** Accepter que plus les modèles d'IA deviennent puissants, plus le travail du développeur se déplace de l'écriture manuelle de chaque ligne vers la revue de code, l'orchestration d'agents et la conception architecturale.
* **Maintenir un équilibre entre passion et automatisation :** Continuer à coder manuellement pour le plaisir personnel sur certains projets ou parties de code, tout en déléguant les tâches répétitives ou lourdes à l'IA pour gagner en efficacité.
* **Utiliser le multi-tasking d'agents :** Lancer plusieurs agents ou sessions de code en parallèle (ex. avec Claude Code ou des outils similaires) pour gérer plusieurs tâches de refactoring ou de correction de bugs simultanément.
* **Développer des applications mobiles en Swift avec l'IA :** Utiliser l'IA pour générer rapidement des structures de code complexes (ex. vues SwiftUI pour Apple Watch) tout en gardant la main sur le style et la logique métier.
