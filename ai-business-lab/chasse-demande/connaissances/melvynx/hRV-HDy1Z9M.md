1) **Idée principale** : Présentation de la version 0.43 de l'IDE Cursor, qui introduit une interface Composer améliorée avec diffs en ligne, l'agent IA en mode "Agent Mode", des suggestions automatiques avec `@Recommended`, et la génération automatique de messages de commit.
2) **Outils, sites ou dépôts GitHub cités** :
- **Cursor** (IDE de programmation assisté par IA, version 0.43).
- **Claude 3.5 Sonnet** (modèle de langage utilisé comme agent).
- **Prisma** (ORM pour bases de données).
- **Supermaven** (extension VS Code de complétion de code par IA).
- **MailerLite** / **Mailchimp** (services d'emailing cités comme cas d'usage d'application cible).
3) **Astuces concrètes et réutilisables** :
- Utiliser le nouveau mode "Agent" de Cursor dans l'interface Composer pour permettre à l'IA d'accéder au terminal, d'exécuter des commandes d'installation de dépendances (ex: `pnpm add`), de créer des schémas Prisma et de migrer les bases de données de manière autonome.
- Structurer ses prompts en donnant des instructions claires et en taggant les fichiers nécessaires (`@`) pour guider l'agent IA dans la création de composants complexes (comme un éditeur de texte riche avec Tiptap/Novel).
- Combiner les agents IA avec une bonne relecture humaine pour corriger les erreurs de routage ou de relations de bases de données générées automatiquement.
