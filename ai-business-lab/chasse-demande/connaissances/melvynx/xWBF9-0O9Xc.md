# Le design d'Airbnb dans Claude Code en 3 étapes

Vidéo : https://youtu.be/xWBF9-0O9Xc · durée 0:37 · résumé Gemini (gemini-3-flash-preview, lot de 8) du 2026-10-22
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

**1) Idée principale :**
Réutiliser les systèmes de design (couleurs, polices, composants) des plus grandes marques (Airbnb, Notion, Apple) pour créer des sites web de haute qualité instantanément avec Claude.

**2) Outils, sites ou dépôts cités :**
*   **Shadcn.io/design** (Gratuit) : Site regroupant les fichiers "DESIGN.md" de plus de 500 marques.
*   **Claude Code** (Non précisé) : Outil pour générer le code du site.
*   **Codex** (Non précisé) : Outil mentionné pour générer des images cohérentes avec le design.

**3) Astuces concrètes et réutilisables :**
*   Télécharger le fichier "DESIGN.md" d'une marque (ex: Airbnb) sur Shadcn.io.
*   Copier-coller ce fichier dans Claude Code pour lui donner les règles esthétiques strictes.
*   Demander à Claude de générer une section spécifique (ex: "Hero section") ; il appliquera automatiquement les styles de la marque choisie.
