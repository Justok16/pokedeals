1) **Idée principale** : Présenter l'application **Conductor** (alternative pour macOS permettant de lancer plusieurs instances de Claude Code en parallèle) et démontrer un workflow complet de développement multi-agents sur GitHub pour corriger des issues (ex : problème d'affichage d'images OG).

3) **Astuces concrètes et réutilisables** :
* Travailler en parallèle avec plusieurs fenêtres/workspaces de Claude Code pour traiter différentes issues GitHub simultanément sans impacter la branche principale.
* Créer un fichier de tâches structuré (`run-tasks.md`) avec des étapes claires (Explorer, Plan, Code, Test, Write/Commit) pour guider l'agent IA pas à pas et éviter les erreurs de contexte.
* Utiliser des commandes de raccourci personnalisées dans VS Code (ex : `CCC` pour lancer `claude-code --continue`) pour automatiser le lancement des sessions de code.
* Forcer l'IA à utiliser les outils de test et de linter (ex : TypeScript, Playwright) pour valider le code avant de soumettre une Pull Request.
