L'annonce et la présentation de la version **2.0.0 de Claude Code**, qui introduit une interface interactive complète, une mascotte, une IA agentique surpuissante, de nouvelles commandes de contrôle de version (`/rewind`), et le nouveau modèle **Claude Sonnet 4.5**, positionné comme supérieur aux autres modèles du marché pour le développement.

3) **Astuces concrètes et réutilisables** :
* Utiliser la commande `/rewind` dans Claude Code pour restaurer l'état d'une conversation et annuler des modifications de code non souhaitées (gestion des points de contrôle / checkpoints).
* Activer ou désactiver le mode "Thinking" (`/thinking on` / `/thinking off`) selon le niveau de raisonnement et de consommation de tokens souhaité pour les requêtes complexes.
* Utiliser le fichier de configuration `AGENTS.md` à la racine du projet pour injecter des instructions, des règles de style, des conventions de nommage et des instructions de test directement luttant avec l'IA.
* Lancer des tâches de débogage automatisées via `/debug` pour identifier et corriger les erreurs de compilation ou les bugs de code de manière autonome.
