# Pourquoi j'ai QUITTÉ VsCode pour Cursor (Mon avis ainsi qu'un tuto pour débuter)

(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale :** 
Pourquoi l'auteur est passé de VS Code à Cursor (un IDE dopé à l'IA basé sur VS Code) pour devenir un développeur ultra-productif, les avantages, les fonctionnalités clés (Composer, Agent, Cursor Tab, Rules) et les points négatifs (gestion de la RAM).

2) **Outils, sites ou dépôts GitHub cités :**
- **Cursor (cursor.com) :** Éditeur de code (IDE) fork de VS Code intégrant des fonctionnalités IA avancées. Propose des versions gratuites et payantes.
- **VS Code (Visual Studio Code) :** Éditeur open-source de référence sur lequel est basé Cursor. (Gratuit)
- **GitHub Copilot :** Outil d'assistance au code concurrent (mentionné pour comparaison). (Payant / abonnement)
- **Next.js, React, TypeScript, TailwindCSS, etc. :** Technologies et frameworks cités pour les exemples de code.
- **Ressources / Masterclass de l'auteur :** mlv.sh/ai (mentionné pour approfondir l'utilisation de l'IA).

3) **Astuces concrètes et réutilisables :**
- **Utiliser Cursor Tab et Tab-to-Jump :** Cursor analyse les erreurs de code et propose des suggestions automatiques. Appuyer sur "Tab" permet de naviguer rapidement vers l'erreur suivante ou d'accepter les suggestions de code.
- **Activer le mode "Agent" (dans Composer) :** Permet à l'IA de chercher d'elle-même dans la codebase, de trouver les fichiers pertinents, de modifier le code, d'importer les badges/composants et de proposer des commits de manière autonome.
- **Configurer les `.cursorrules` (Cursor Rules) :** Créer un dossier `.cursorrules` (ou des fichiers de règles Markdown/notepads) pour définir les conventions de code du projet, les types, les librairies utilisées (ex: Next.js, Tailwind), et guider l'IA pour qu'elle respecte scrupuleusement la structure du projet.
- **Utiliser l'outil "Bug Finder" et le chat contextuel :** Sélectionner du texte pour l'ajouter au contexte du chat et demander des modifications ciblées ou du refactoring propre.
- **Créer des fichiers de prompts spécifiques (`prompts/*.md`) :** Stocker des instructions réutilisables et des "prompts" de refactoring pour guider l'IA sur des tâches répétitives (ex: actions serveur, mutations).
