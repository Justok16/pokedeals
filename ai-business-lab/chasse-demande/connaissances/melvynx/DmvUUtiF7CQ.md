1) **Idée principale :** Présentation du composant `TanStack Form` via l'application `nowts.app` pour simplifier et nettoyer la création de formulaires en React, en évitant le code répétitif (boilerplate).
2) **Outils, sites ou dépôts GitHub :**
- **React Hook Form :** outil de formulaire React (considéré comme lourd et peu pratique par l'auteur).
- **TanStack Form (avec Zod) :** solution de formulaire React avec validation (gratuite/open source, présentée comme l'avenir).
- **nowts.app :** application créée par l'auteur (gratuite), répertoriant des composants prêts à l'emploi (dont `TanStack Form`).
3) **Astuces concrètes et réutilisables :**
- Utiliser `nowts.app` pour récupérer rapidement le code de composants pré-intégrés (comme `TanStack Form` avec `Field` et `Field API`) afin de réduire la quantité de code.
- Migrer progressivement ses applications vers TanStack Form pour simplifier la base de code et la rendre plus propre.
