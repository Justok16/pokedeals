# Je supprime Cursor : Zed devient une vraie alternative !

Vidéo : https://youtu.be/JHbFJ5nEERM · durée 15:30 · résumé Gemini (gemini-flash-lite-latest, lot de 6) du 2026-10-10
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale**
Présentation de l'éditeur de code **Zed** (alternative ultra-rapide à VS Code écrite en Rust) et de son intégration native avec **Claude Code**.

2) **Outils, sites ou dépôts GitHub cités**
* **Zed** (`zed.dev`) : Éditeur de code open source gratuit, ultra-rapide, écrit en Rust.
* **Claude Code** : Intégré nativement dans Zed en tant qu'assistant IA.
* **GitHub Copilot** : Également intégrable et géré par défaut dans Zed.
* **Gemini (Gemini 2.0 Flash / Pro)** et **GPT-5 / OpenAI** : Modèles de langage configurables dans Zed.

3) **Astuces concrètes et réutilisables**
* Télécharger et installer Zed depuis le site officiel pour bénéficier d'un éditeur nettement plus rapide que les forks basés sur VS Code (grâce au moteur en Rust).
* Utiliser les raccourcis clavier de Zed pour naviguer, rechercher (`project search`) ou changer de mode.
* Configurer des clés API (OpenAI, Google Gemini, GitHub Copilot) directement dans le menu de configuration des "LLM Providers" de Zed.
* Utiliser l'intégration de Claude Code dans Zed pour lui demander d'analyser le projet (`explain my project briefly`), modifier des fichiers ou lancer des commandes de correction (`/auto-fix`).
* Configurer les paramètres de formatage automatique (`format_on_save`) et les intégrations ESLint ou Prettier dans le fichier `settings.json` de Zed.
