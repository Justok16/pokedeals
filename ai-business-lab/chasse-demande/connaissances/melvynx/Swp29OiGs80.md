### 1. Idée principale
La vidéo explique qu'il n'est plus nécessaire de payer pour des outils payants comme Lovable (proposé à 25 $/mois) pour créer et déployer des landing pages ou des sites SaaS, car l'utilisation combinée de **Claude Code** et d'autres outils gratuits permet de réaliser les mêmes tâches plus efficacement et à moindre coût.

---

### 2. Outils, sites et dépôts GitHub cités

*   **Lovable** : Site web payant (forfait Pro à 25 $/mois, mentionné), servant à créer des applications et landing pages. L'auteur le juge inutile face à Claude Code.
*   **Claude AI / Claude Code / Claude for Mac** : Outil d'IA (abonnement Pro mentionné à 20 $/mois ou 200 $/an). Il permet de coder, d'interagir avec l'application, et de générer du code sans écrire une seule ligne soi-même.
*   **GitHub** (`github.com`) : Site web gratuit servant à héberger le code source des projets (rôle de "clé USB pour stocker le code").
*   **Netlify** (`netlify.com`) : Site web gratuit permettant d'héberger, de déployer et de gérer des sites internet (avec ou sans domaine personnalisé) de manière automatisée.
*   **Dépôt GitHub "ailbuilder-landing"** (créé par l'auteur dans la vidéo) : Dépôt public gratuit utilisé pour stocker et déployer le code de l'application.

### 3. Astuces concrètes et réutilisables

*   **Connexion des intégrations (MCP / Connectors) dans Claude Code :** Connecter Netlify et GitHub directement dans l'interface de Claude Code pour lui permettre de créer et déployer des sites web de manière autonome.
*   **Activer le « Bypass Permissions » :** Dans les paramètres de Claude Code Desktop, activer le mode *Bypass permissions* permet à l'IA d'exécuter toutes les tâches (création de fichiers, modifications, etc.) sans demander de confirmation à chaque étape.
*   **Utiliser le modèle adapté (Sonnet 4.6 / Opus 4.6) :** Choisir le modèle d'IA adapté selon son abonnement et sa complexité (Opus recommandé pour les projets ambitieux si l'on a les crédits nécessaires).
*   **Configuration du prompt de départ :** Rédiger un prompt structuré en indiquant la stack technique (Vite, React, TailwindCSS, Shadcn/UI), le style visuel, les règles de clean code, et les actions automatisées (comme "quand tu termines, publie sur un repo GitHub public puis publie le repo sur Netlify").
*   **Liaison automatique GitHub-Netlify (Auto-deploy) :** Configurer les paramètres du projet sur Netlify pour le lier au dépôt GitHub, ce qui permet à chaque commit effectué par l'IA sur le code de mettre à jour le site en direct de manière instantanée.
