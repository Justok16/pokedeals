# Le plus HYPE de JavaScript en 2024 (c'est pas React !)

Vidéo : https://youtu.be/2T0nQTesfwQ · durée 13:18 · résumé Gemini (gemini-flash-lite-latest, lot de 8) du 2026-10-13
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1. **Idée principale :** Analyse des projets JavaScript les plus populaires sur GitHub en 2024 (selon "JavaScript Rising Stars"), mise en avant de la librairie UI **shadcn/ui** et présentation d'autres outils et frameworks phares de l'écosystème.
2. **Outils, sites ou dépôts GitHub cités :**
   - **shadcn/ui :** Gratuit (open source), collection de composants UI copiables.
   - **Best of JS / 2024 JavaScript Rising Stars :** Gratuit, site référençant les tendances et projets GitHub de l'année.
   - **Next.js / Next Safe Routes :** Gratuits, framework React et routage.
   - **Motion-Primitives :** Librairie d'animations UI.
   - **Excalidraw :** Gratuit (open source), outil de dessin de schémas.
   - **AFFiNE :** Gratuit (open source), alternative à Notion/Miro.
   - **Bruno :** Gratuit (open source), alternative à Postman pour tester les API.
   - **n8n :** Outil d'automatisation de workflows (version open source gratuite et versions cloud payantes).
   - **Vite / Vitest / Rolldown / Oxc :** Outils de build et test rapides.
   - **Tauri :** Framework pour applications desktop cross-platform.
   - **Supabase :** Backend as a service open source.
   - **Hono :** Framework web ultra-rapide.
   - **Astro / NestJS :** Frameworks web.
   - **Magic UI :** Librairie de composants UI (freemium/payant pour certains templates).
   - **Vue.js / Nuxt / PrimeVue / Slidev :** Écosystème Vue.
   - **Biome / ESLint :** Outils de formatage et lintage.
   - **Payload :** CMS headless et framework full-stack Next.js.
   - **Tailwind CSS / DaisyUI / Pico CSS / Bootstrap :** Frameworks et librairies CSS.
   - **Storybook / Micro Agent / Stagehand / Vercel AI SDK :** Outils de test, composants et IA.
   - **Zustand / Redux / Jotai / XState :** Gestionnaires d'état.
   - **N-Design / Ant Design :** Librairies de composants.
   - **Turbo / TurboRepo / SWC :** Outils d'optimisation et build.
3. **Astuces concrètes et réutilisables :**
   - Utiliser la CLI de shadcn/ui (`npx shadcn@latest add ...`) pour intégrer facilement des composants accessibles et personnalisables dans un projet Tailwind/React.
   - S'appuyer sur des outils modernes et performants comme Vite ou Bun pour accélérer le développement frontend.
   - Explorer les tendances GitHub via le site Best of JS pour identifier les librairies montantes et adapter sa stack technique.
