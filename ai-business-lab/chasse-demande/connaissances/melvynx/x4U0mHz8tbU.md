# Maîtriser le JSX en 120 SECONDES - React JSX

1) **Idée principale :** L'auteur explique le fonctionnement du JSX avec React en deux minutes, en le comparant au HTML et en montrant comment écrire du JavaScript à l'intérieur du JSX.
2) **Outils, sites ou dépôts GitHub cités :**
- **Babel** (gratuit, outil/moulinette de transpilation pour transformer le JSX en JS simple) ;
- **BeginReact** (cours gratuit mentionné par l'auteur pour créer son propre mini-React, lien en description).
3) **Astuces concrètes et réutilisables :**
- Toujours fermer ses balises en JSX (contrairement au HTML).
- Utiliser la casse adaptée (*camelCase*) pour les attributs comme `onClick` (avec un "C" majuscule).
- Envelopper les blocs de code JSX dans un élément parent (comme une `div`) ou un fragment (`<></>`) si l'on retourne plusieurs éléments, car React n'accepte qu'un seul élément racine retourné par une expression JSX.
- Utiliser des accolades `{}` pour intégrer des expressions JavaScript valides (et non des *statements* comme `if` ou `for`) à l'intérieur du JSX.
- Utiliser les accolades pour ajouter dynamiquement des styles ou des attributs (ex: `style={{ color: color }}`).
