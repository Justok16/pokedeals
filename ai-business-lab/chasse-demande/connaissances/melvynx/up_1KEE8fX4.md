### 1) Idée principale
La vidéo propose un tutoriel complet pour débutants sur l'utilisation de **Codex** (l'application de code liée à l'abonnement ChatGPT Pro/Plus à 20$/mois) et de **Claude Code**. Elle montre comment installer ces outils, relier des applications (GitHub, Netlify), automatiser la création et le déploiement d'un site web (comme un portfolio personnel moderne), et configurer des compétences (« skills ») pour que l'IA gère le code efficacement.

---

### 2) Outils, sites et dépôts GitHub cités
* **ChatGPT (OpenAI) / Codex App** : Payant (inclus dans l'abonnement ChatGPT Pro/Plus à 20$/mois). Application pour coder, utiliser l'IA sur son ordinateur et gérer des projets.
* **Node.js & npm** (`nodejs.org`) : Gratuit. Environnement d'exécution JavaScript et gestionnaire de paquets pour installer des bibliothèques et lancer des projets.
* **GitHub** (`github.com`) : Gratuit (avec options payantes). Plateforme de gestion de code et de stockage de dépôts (repos).
* **Netlify** (`netlify.com`) : Gratuit (avec offres payantes). Plateforme de déploiement et d'hébergement de sites web.
* **Skills OS** (`skills.sh`) : Gratuit. Écosystème de compétences (« skills ») pour agents IA (dépôt GitHub mentionné : `github.com/wshobson/agents` pour le skill `mobile-ios-design`).
* **Configuration Claude Code de l'auteur** (`mlv.sh/fc`) : Gratuit (ou accès partiel/gratuit selon inscription). Plateforme/tutoriel de configuration pour Claude Code.

---

### 3) Astuces concrètes et réutilisables
* **Téléchargement et connexion** : Télécharger Codex App pour macOS, se connecter via son compte ChatGPT (sans nécessiter de clé API coûteuse).
* **Création de projets** : Créer un dossier dédié sur son ordinateur (ex. pour un portfolio) et l'ouvrir comme projet dans Codex pour démarrer un nouveau « thread » (fil de discussion).
* **Utilisation des Skills (Compétences)** : Utiliser le caractère `$` dans le chat de Codex/Claude Code pour appeler des skills spécifiques (ex. `$frontend-design`) afin d'améliorer la qualité du code et du design généré.
* **Permissions maximales** : Activer le « full access » (accès complet) dans Codex pour lui permettre d'exécuter des commandes terminales et de manipuler les fichiers sans restrictions.
* **Commandes clés dans le terminal / CLI** :
  * `npm install -g @openai/codex` (ou installation via CLI)
  * `codex --yolo` (pour lancer Codex en mode autonome/bypass des permissions)
  * Commandes d'initialisation et de gestion : `/init`, `/status`, `/approvals`, `/model`, `/review`.
