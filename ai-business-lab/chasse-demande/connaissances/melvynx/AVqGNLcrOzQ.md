# 5 Nouveautés Tailwind Que tu Dois Connaître !

Vidéo : https://youtu.be/AVqGNLcrOzQ · durée 6:50 · résumé Gemini (gemini-flash-lite-latest, lot de 8) du 2026-10-18
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

- **Idée principale :** Analyse des 5 nouveautés majeures de Tailwind CSS dans sa version 2023 (Tailwind Connect / v4), incluant le sélecteur `:has()`, les Container Queries, l'outil Oxide, la configuration native du thème en CSS et la bibliothèque Catalyst.
- **Outils, sites ou dépôts GitHub cités :**
  - **Tailwind CSS :** Framework CSS open-source gratuit.
  - **Emotion / @emotion/css / @mui/base / Bootstrap / Styled-components / Material UI :** Bibliothèques et frameworks CSS concurrents (gratuits).
  - **Oxide :** Nouvelle toolchain ultra-rapide pour Tailwind (intégrée).
  - **Lightning CSS :** Compresseur/transformateur CSS en Rust (open-source gratuit).
  - **Catalyst :** Kit de composants UI officiel payant/réservé (créé par l'équipe de Tailwind pour React).
  - **npm :** Gestionnaire de paquets gratuit.
- **Astuces concrètes et réutilisables :**
  - **Nouveauté 1 (As Selector) :** Utiliser le sélecteur basé sur `:has()` (ex: `has-[:checked]`) pour appliquer des styles conditionnels à un élément parent en fonction de l'état de ses enfants.
  - **Nouveauté 2 (Container Queries) :** Utiliser les requêtes de conteneur (`@lg`, `@container`) pour appliquer des styles CSS en fonction de la taille du conteneur parent et non de la fenêtre du navigateur.
  - **Nouveauté 3 (Oxide & Lightning CSS) :** Profiter des performances de la nouvelle toolchain *Oxide* (basée sur Rust) qui fusionne et remplace PostCSS, Autoprefixer et les imports multiples pour un build ultra-rapide.
  - **Nouveauté 4 (Configuration du thème en CSS) :** Configurer les couleurs et les thèmes directement dans le fichier CSS via des variables ou la syntaxe native, éliminant le besoin d'un fichier de configuration JS externe complexe.
  - **Nouveauté 5 (Catalyst UI Kit) :** Utiliser le kit de composants Catalyst pour React afin d'intégrer des composants accessibles et modifiables directement dans le code source sans dépendre d'un package npm externe figé.
