1) **Idée principale** : Présentation de **shadcn/ui**, une bibliothèque de composants moderne et révolutionnaire pour le développement web front-end.
2) **Outils / sites / dépôts GitHub** :
   - shadcn/ui : Gratuit / Open Source (bibliothèque de composants).
   - Tailwind CSS : Gratuit (framework CSS).
   - Next.js : Gratuit (framework React).
   - DaisyUI : Gratuit (bibliothèque de composants).
   - Radix UI : Gratuit (bibliothèque de composants primitives).
   - Lucide React (pour les icônes) : Gratuit.
   - GitHub : Gratuit.
   - PNPM : Gratuit (gestionnaire de paquets).
3) **Astuces concrètes et réutilisables** :
   - Utiliser shadcn/ui pour copier-coller directement le code source des composants dans son propre projet (via la CLI `npx shadcn@latest init` ou `npx shadcn@latest add`), ce qui permet de les modifier et de les customiser entièrement, contrairement aux bibliothèques traditionnelles installées via npm qui bloquent l'accès au code interne.
   - Configurer les alias de chemins (`components/ui`, `lib/utils`) dans `tsconfig.json` pour faciliter l'importation des composants.
   - Modifier les variables CSS globales (`app/globals.css`) et le fichier de configuration Tailwind (`tailwind.config.js`) pour personnaliser facilement les thèmes, les couleurs (primary, success, destructive, etc.) et les arrondis de bordures (`radius`).
   - Installer uniquement les composants nécessaires (boutons, accordéons, inputs, etc.) pour garder un code propre et éviter d'alourdir l'application.
