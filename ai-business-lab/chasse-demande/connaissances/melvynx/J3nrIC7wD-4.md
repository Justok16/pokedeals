# Mise à jour Shadcn/UI : Voici ce qui change !

Vidéo : https://youtu.be/J3nrIC7wD-4 · durée 9:58 · résumé Gemini (gemini-flash-lite-latest, lot de 7) du 2026-10-15
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale :** Présentation du nouveau CLI de *shadcn/ui* (`npx shadcn@latest init`), qui permet d'installer et de mettre à jour très facilement des composants, thèmes et hooks dans une application React/Next.js.

2) **Outils, sites ou dépôts GitHub cités :**
* *shadcn/ui* (gratuit, ui.shadcn.com) : bibliothèque de composants réutilisables.
* *Next.js* (gratuit, nextjs.org) : framework React utilisé pour la démonstration.
* *Tailwind CSS* (gratuit, tailwindcss.com) : framework CSS utilisé par shadcn/ui.
* *v0.dev* (gratuit/payant, v0.dev) : outil d'IA pour générer des composants UI compatibles shadcn.

3) **Astuces concrètes et réutilisables :**
* Utiliser la nouvelle commande `npx shadcn@latest init` pour initialiser shadcn et mettre à jour automatiquement `tailwind.config.js` et les fichiers de configuration sans écraser l'existant.
* Ajouter des composants spécifiques avec la commande `pnpm dlx shadcn@latest add <nom-du-composant>` (par exemple, `accordion` ou `authentication-04`).
* Configurer des instructions personnalisées pour GitHub Copilot afin qu'il génère du code respectant la syntaxe des composants shadcn.
