1) **Idée principale** : Présentation du setup de télétravail d'un nomade numérique (matériel, accessoires et organisation).
2) **Outils / sites / dépôts GitHub** :
   - MacBook M1 Pro : Payant (ordinateur portable).
   - Raycast : Gratuit / Payant (outil de remplacement de Spotlight).
   - Arc : Gratuit (navigateur web).
   - A loft (Le stand / support) : Payant (support pour MacBook).
   - Nextstand : Payant (support pour ordinateur portable ultra-petit).
   - Clavier Apple : Payant.
   - Souris Logitech MX Master 3 (nom exact non confirmé, mais mentionné MX Master S3 / Logitech) : Payant.
   - iPad Pro : Payant.
   - Application Raycast / Arc / Figma (mentionné pour la souris) : Payant/Gratuit selon les cas.
   - Enregistreur Sony (dictaphone) : Payant.
   - Lunettes anti-lumière bleue de la marque Gunnar : Payant.
3) **Astuces concrètes et réutilisables** :
   - Utiliser un support ergonomique (Nexstand, Aloft) pour rehausser l'écran et éviter les douleurs cervicales et dorsales.
   - Utiliser une souris avec scroll horizontal pour naviguer plus facilement dans les fichiers de design (Figma) et de code.
   - Utiliser un second écran (comme un iPad avec Sidecar) pour afficher les retours de vidéo ou les notes sans surcharger l'écran principal.
   - Utiliser un dictaphone de poche pour enregistrer l'audio de la voix avec une haute qualité lors de déplacements.
   - Utiliser des lunettes anti-lumière bleue pour réduire la fatigue oculaire lors de longues sessions de travail sur écran.
