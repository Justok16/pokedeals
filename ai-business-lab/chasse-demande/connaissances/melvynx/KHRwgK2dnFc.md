1. L'idée principale de cette vidéo est d'expliquer le fonctionnement du Server-Side Rendering (SSR) et du Client-Side Rendering (CSR), en montrant comment les pages et le code JavaScript sont chargés et exécutés, illustré avec des exemples théoriques et pratiques.

2. Outils, sites ou dépôts GitHub cités :

- React-Query (librairie, gratuit) : mentionné dans le cours gratuit.
- Dépôt GitHub / site de code personnel (mentionné sous le nom de CodeLynx, avec un cours gratuit d'accès aux composants et requêtes).

3. Astuces concrètes et réutilisables :
- Comprendre la différence entre CSR (le client télécharge un HTML vide puis récupère et exécute le JS pour afficher la page) et SSR (le serveur génère directement la page HTML complète avec les données avant de l'envoyer au client).
- Utiliser l'onglet "Network" des outils de développement du navigateur pour analyser le chargement séquentiel des fichiers HTML, CSS et JavaScript et identifier les étapes d'hydratation.
