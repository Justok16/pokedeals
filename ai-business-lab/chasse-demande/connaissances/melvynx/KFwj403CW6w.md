# On JUGE vos Portfolios de DEV (grosse erreur) avec @Johan Code

Vidéo : https://youtu.be/KFwj403CW6w · durée 36:07 · résumé Gemini (gemini-flash-lite-latest, lot de 5) du 2026-10-11
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale** : Évaluation et analyse critique de portfolios de développeurs juniors pour les rendre plus attractifs auprès des recruteurs et maximiser leurs chances de décrocher un emploi ou une mission freelance.

2) **Outils, sites et dépôts GitHub cités** :
- **FastAPI** (gratuit, framework web Python).
- **Django** (gratuit, framework web Python).
- **Flask** (gratuit, framework micro-web Python).
- **TypeScript** (gratuit, langage de programmation typé).
- **React** (gratuit, bibliothèque JavaScript).
- **Next.js** (gratuit, framework React).
- **Tailwind CSS** (gratuit, framework CSS).
- **SQL** (gratuit, langage de requête de base de données).
- **PostgreSQL** (gratuit, système de base de données relationnelle).
- **GitHub** (gratuit, plateforme de gestion de code source).
- **GitHub Actions** (gratuit, outil d'intégration et de déploiement continus).
- **Pytest** (gratuit, framework de test Python).
- **OpenAI API** (payant, API d'intelligence artificielle).
- **Prisma** (gratuit, ORM Node.js et TypeScript).
- **Matomo** (gratuit, outil d'analyse web open source).
- **Vercel** (gratuit/payant, plateforme de déploiement et d'hébergement).
- **Trello** (gratuit/payant, outil de gestion de projet).

3) **Astuces concrètes et réutilisables** :
- Utiliser un design sombre, épuré et professionnel avec des contrastes suffisants pour le texte.
- Mettre en avant les compétences de manière claire, sans alourdir la page avec des logos de frameworks superflus si le texte suffit.
- Éviter d'afficher des pourcentages arbitraires (ex. 70% back-end / 30% front-end) qui n'ont pas de sens technique réel ; privilégier l'indication du rôle de développeur full-stack.
- Inclure des liens fonctionnels vers des dépôts GitHub et des sites déployés pour chaque projet présenté.
- Simplifier l'affichage des compétences et des technologies en évitant les redondances entre les sections.
- Structurer le portfolio autour d'une cible précise (ex. recruteurs CDI ou clients freelance) pour adapter le positionnement, les tarifs et les services proposés.
- Limiter les animations excessives ou les temps de chargement trop longs sur les portfolios pour ne pas nuire à l'expérience utilisateur.
