1) **Idée principale** : Cette vidéo présente **find-skills**, une bibliothèque de plus d'un million de compétences pour **Claude Code**, permettant de trouver et d'installer automatiquement le meilleur skill adapté à la tâche technique que vous souhaitez réaliser (vidéo, montage, sous-titres, etc.).

2) **Outils, sites ou dépôts GitHub cités** :
   - **find-skills (par Vercel Labs / `vercel-labs/skills`)** : Gratuit, dépôt GitHub et registre de compétences (skills) pour Claude.
   - **Claude Code** : Payant (outil de développement d'Anthropic), l'environnement dans lequel les skills sont exécutés.
   - **GitHub** : Gratuit, plateforme de code source.

3) **Astuces concrètes et réutilisables** :
   - Installer `find-skills` en ligne de commande dans Claude Code via la commande `npx skills add https://github.com/vercel-labs/skills --skill find-skills`.
   - Décrire simplement son besoin à Claude (par exemple : monter des vidéos, écrire des emails, générer des sous-titres) pour que l'outil sélectionne et installe automatiquement le meilleur skill disponible parmi une bibliothèque de plus d'un million de références.
   - Permet d'automatiser l'intégration de compétences spécialisées sans avoir à chercher manuellement le code ou la configuration adéquate.
