1) **Idée principale :** Présentation des nouveautés majeures de GitHub Copilot (mises à jour de décembre), notamment l'intégration directe avec le terminal, la correction d'erreurs de commandes, l'extension VS Code Speech pour dicter son code, et les commandes améliorées au sein du workspace.
2) **Outils, sites ou dépôt GitHub cités :**
- **GitHub Copilot** : assistant de code par IA (payant / abonnement).
- **Visual Studio Code (VS Code)** : éditeur de code (gratuit).
- **Extension VS Code Speech** : extension gratuite de Microsoft pour la transcription de la voix en texte dans VS Code.
- **pnpm** : gestionnaire de paquets (gratuit).
3) **Astuces concrètes et réutilisables :**
- Utiliser la fonctionnalité **Terminal Copilot** en tapant `@terminal` suivi d'une requête (ex: `@terminal comment savoir quel processus ouvre le port 3000 ?`) directement dans le chat de Copilot pour obtenir des commandes shell adaptées.
- Utiliser la commande **Terminal Selection** en sélectionnant du texte d'erreur dans le terminal pour demander à Copilot d'expliquer ou de résoudre un problème (ex: trouver la commande `kill` pour libérer un port).
- Utiliser la commande **Terminal Last Command** (`@terminal #TerminalLastCommand`) pour analyser la dernière commande exécutée dans le terminal et son résultat afin de corriger une erreur (ex: échec de `pnpm start`).
- Installer l'extension **VS Code Speech** pour dicter directement des instructions à Copilot (ex: "Add 10 skeleton instead of five") au lieu de les taper au clavier.
- Utiliser `@workspace` dans le chat Copilot pour poser des questions globales sur la structure du projet (ex: `@workspace quels sont les étapes à suivre pour rajouter un "login with google" ?`), permettant à l'IA d'analyser les fichiers locaux (package.json, fichiers de configuration auth, etc.) et de fournir un guide pas à pas.
