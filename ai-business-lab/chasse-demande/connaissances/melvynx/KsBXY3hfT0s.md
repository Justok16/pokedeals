1. **Idée principale :** Présentation de trois bonnes pratiques de code en JavaScript pour obtenir un code propre ("clean code").
2. **Outils, sites ou dépôts GitHub cités :**
   - Environnement de code JavaScript (éditeur de code avec Quokka et Prettier, outils gratuits).
3. **Astuces concrètes et réutilisables :**
   - **Règle 1 :** Ne jamais créer de fonctions avec des flags (paramètres booléen modifiant le comportement) ; privilégier deux fonctions bien séparées.
   - **Règle 2 :** Faire des fonctions pures qui ne modifient pas des variables en dehors de leur scope (éviter les effets de bord), en retournant par exemple une variable calculée.
   - **Règle 3 :** Éviter les conditions négatives (ex. `if (!shouldNotSendEmail)`) et préférer des fonctions aux noms positifs (ex. `shouldSendEmail`).
