Pratiquer la rétro-ingénierie sur n'importe quelle application (logiciel) pour comprendre son fonctionnement interne et créer sa propre version améliorée ou adaptée.

*   **Claude Code** (Non précisé) : Agent IA pour analyser l'application.
*   **Presentify** (Payant) : Exemple d'application analysée.
*   **Photoshop** (Payant) : Citée comme exemple d'app décortiquable.

**3) Astuces concrètes et réutilisables :**
*   Brancher Claude Code sur le skill "Reverse Engineer Anything".
*   Demander l'analyse d'un binaire (fichier d'application) sur son ordinateur.
*   Claude fournit l'inventaire des fonctionnalités et le code Swift (ou autre) logique pour permettre de créer un clone (ex: "PresentLol").
