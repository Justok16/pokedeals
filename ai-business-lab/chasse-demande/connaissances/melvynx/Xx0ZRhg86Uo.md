# Claude Haiku 4.5 : le modèles le plus RENTABLE ? (+ les SKILLS)

Vidéo : https://youtu.be/Xx0ZRhg86Uo · durée 16:52 · résumé Gemini (gemini-3.5-flash, lot de 6) du 2026-10-10
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

**1) L'idée principale**
Évaluation comparative du nouveau modèle `Claude Haiku 4.5` d'Anthropic, qui s'avère 3,3 fois moins cher et quasiment deux fois plus rapide que Sonnet 4.5, ainsi que des nouveautés "Explore" et "Claude Skills" pour les agents IA.

**2) Chaque outil, site ou dépôt GitHub cité**
*   **Claude Haiku 4.5** : Modèle d'IA rapide d'Anthropic. *Payant via API (1 $/1M tokens entrée, 5 $/1M tokens sortie).*
*   **Claude Sonnet 4.5 / Sonnet 4** : Modèles d'IA d'Anthropic. *Payant via API (3 $/1M tokens entrée, 15 $/1M tokens sortie pour Sonnet 4.5).*
*   **Claude Code** : Outil CLI d'agent de codage en terminal par Anthropic. *Payant à l'usage API.*
*   **Claude Skills / Agent Skills** (`github.com/anthropics/courses/agent-skills`) : Standard de compétences procédurales sous forme de fichiers `SKILL.md` et scripts Python. *Gratuit / Open-source.*
*   **SWE-bench Verified** : Benchmark de mesure de compétences en génie logiciel pour IA. *Gratuit.*
*   **mlv.sh/ai** : Formation et masterclass Claude Code de l'auteur. *Gratuit.*
*   **shadcn/ui** : Composants UI pour React. *Gratuit / Open-source.*
*   **SaveIt.now** : Application codebase d'exemple de l'auteur. *Non précisé.*

**3) Les astuces concrètes et réutilisables**
*   Utiliser `Claude Haiku 4.5` pour l'analyse, la recherche et la cartographie rapide de codebases complexes (45s contre 81s pour Sonnet).
*   Conserver `Claude Sonnet 4.5` pour l'écriture de code critique et l'installation de dépendances, car Haiku peut faire des erreurs de syntaxe ou de duplication de paquets.
*   Forcer le modèle dans la CLI Claude Code (`ANTHROPIC_MODEL=claude-haiku-4.5...` ou `/model`) selon le niveau de difficulté de la tâche pour optimiser sa facture API.
*   Créer des "Agent Skills" avec un fichier `SKILL.md` regroupant les instructions et des scripts Python pour exécuter des tâches métier spécialisées.

**4) Les chiffres de revenus annoncés**
*   Tarifs API Claude Haiku 4.5 : 1 $ / million de tokens en entrée, 5 $ / million de tokens en sortie *(affirmé par l'auteur)*.
*   Tarifs API Claude Sonnet 4.5 : 3 $ / million de tokens en entrée, 15 $ / million de tokens en sortie *(affirmé par l'auteur)*.
*   Coût de la session d'exploration : 0,12 $ avec Haiku 4.5 contre 0,40 $ avec Sonnet 4.5 *(affirmé par l'auteur)*.
*   Gains personnels de l'auteur : non précisé.
