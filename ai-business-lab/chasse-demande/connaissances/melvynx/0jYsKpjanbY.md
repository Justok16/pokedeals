# 5 Tips Cursor à utiliser MAINTENANT (ou supprime-le !)

(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale :** 
Exploiter toutes les fonctionnalités avancées et cachées de Cursor (associé à l'IA) pour coder beaucoup plus vite et proprement, notamment grâce au mode Agent, aux Cursor Rules, aux fichiers de prompts Markdown, aux symboles web et aux messages de commit automatisés.

2) **Outils, sites ou dépôts GitHub cités :**
- **Cursor :** IDE dopé à l'IA (mentionné comme l'outil principal utilisant l'IA). (Gratuit / Payant)
- **GitHub Copilot :** Outil concurrent comparé dans la vidéo. (Payant)
- **Next.js / TypeScript / React / TailwindCSS :** Frameworks et langages manipulés dans les démonstrations.
- **Chat GPT / Excalidraw / etc. :** Outils mentionnés rapidement dans l'écosystème de développement de l'auteur.

3) **Astuces concrètes et réutilisables :**
- **Mode Agent dans Composer :** Demander à l'agent de résoudre un problème complexe (ex: filtrage de tags avec badges) ; l'agent fouille la codebase, trouve les fichiers, applique les modifications et propose un récapitulatif des changements.
- **Utiliser les Cursor Rules (`.cursorrules`) :** Centraliser les règles du projet (conventions de nommage, types, structure des dossiers) pour que l'IA génère du code parfaitement aligné avec les standards du projet.
- **Créer des fichiers de "Prompts" (`.md` ou Notepads) :** Sauvegarder des instructions de refactoring réutilisables (ex: `refactor use-mutation.md`) dans un dossier de prompts pour les appliquer rapidement d'un simple glisser-déposer ou appel dans l'IA.
- **Utiliser le symbole `@Web` :** Permet à l'IA d'aller chercher de la documentation officielle à jour sur le web (ex: documentation de Next.js 15 ou Svelte) avant d'écrire le code.
- **Générer des commits automatiques :** Utiliser les raccourcis et règles de Cursor pour rédiger des messages de commit propres et conformes aux conventions du projet.
