# Tutoriel Tailwind CSS pour les débutants : Tout ce qu'il faut savoir

1) **Idée principale :** Pourquoi les plus grandes entreprises (OpenAI, Shopify, Netflix, Microsoft) utilisent Tailwind CSS, ses avantages par rapport à CSS traditionnel et Bootstrap, et comment l'intégrer efficacement.

2) **Outils, sites ou dépôts GitHub cités :**
* *Tailwind CSS* (gratuit, tailwindcss.com) : framework CSS utility-first.
* *Bootstrap* (gratuit, getbootstrap.com) : framework CSS traditionnel (comparé dans la vidéo).
* *Node.js* (gratuit, nodejs.org) : environnement d'exécution pour installer Tailwind.
* *Vite* (gratuit, vitejs.dev) : bundler pour le projet de démo.
* *VS Code* (gratuit) : éditeur de code.
* *Tailwind CSS IntelliSense* (gratuit, extension VS Code) : autocomplétion des classes.
* *Prettier plugin Tailwind* (gratuit, npm) : plugin pour trier les classes automatiquement.

3) **Astuces concrètes et réutilisables :**
* Le workflow est simplifié car tout s'écrit directement dans le HTML sans changer de fichier CSS.
* Tailwind optimise la taille du bundle en ne générant que les classes réellement utilisées dans le projet.
* Utiliser `@layer components` dans le CSS pour créer des composants réutilisables basés sur Tailwind sans abuser de `@apply`.
* Configurer le fichier `tailwind.config.js` pour personnaliser les couleurs, la typographie et les espacements (Design System).
