1) **Idée principale :** Présentation de trois extensions indispensables pour VS Code (ES7+ React/Redux/React-Native snippets, JavaScript Booster, et VS Code React Refactor) pour booster la productivité lors du développement React.
2) **Outils, sites ou dépôts GitHub cités :**
   - **Visual Studio Code (VS Code) :** Éditeur de code (gratuit).
   - **ES7+ React/Redux/React-Native snippets :** Extension VS Code pour insérer rapidement des snippets React (gratuite).
   - **JavaScript Booster :** Extension VS Code pour refactoriser et optimiser le code JS/TS (gratuite).
   - **VS Code React Refactor :** Extension VS Code pour extraire facilement du JSX en composants (gratuite).
   - **GitHub Copilot / GitHub Copilot X / GitHub Copilot Labs :** Outils d'IA mentionnés pour l'aide au code (payants / abonnements).
3) **Astuces concrètes et réutilisables :**
   - Utiliser le raccourci `rafc` (grâce aux snippets ES7+) pour générer instantanément la structure de base d'une fonction fléchée React nommée d'après le nom du fichier.
   - Utiliser JavaScript Booster pour convertir des structures répétitives, transformer des fonctions, ou gérer des templates de chaînes de caractères (`template strings`).
   - Utiliser VS Code React Refactor pour sélectionner un bloc de JSX et l'extraire automatiquement dans un nouveau composant (fonctionnel ou à classe) en créant les props nécessaires.
