# Pourquoi Claude écrit mal tes scripts (et le skill qui règle ça)

Vidéo : https://youtu.be/sXxMQdkwUpA · durée 1:01 · résumé Gemini (gemini-3.5-flash-lite, lot de 7) du 2026-10-26
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) L'idée principale : Pourquoi les IA (comme Claude ou ChatGPT) écrivent de mauvais scripts pour les réseaux sociaux (en copiant bêtement les étapes sans la réflexion sous-jacente) et comment corriger cela en utilisant un skill spécifique basé sur l'analyse de milliers de reels.
2) Outils, sites ou dépôts GitHub cités :
   - ChatGPT / Claude / Gemini : non précisés.
   - Skill « Studio Script » (par Melvyn) : non précisé (gratuit via le lien), skill pour Claude Code/Claude qui intègre les règles de rédaction de scripts basées sur l'analyse de plus de 16 000 reels.
   - mlv.sh/script : URL citée, gratuite, pour obtenir le skill Studio Script.
3) Astuces concrètes et réutilisables :
   - Ne pas donner à l'IA de simples étapes figées, mais lui fournir des « étapes de réflexion » (une seule promesse, du hook au CTA, du concret plutôt de l'abstrait, des relances au milieu).
   - Utiliser le skill « studio-script » pour rédiger ou auditer ses scripts de vidéos courtes (Reels/TikTok/YouTube Shorts).
