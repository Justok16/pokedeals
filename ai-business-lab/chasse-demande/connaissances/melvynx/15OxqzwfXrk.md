# STOP : Voici le seul Portfolio à faire si tu n’es pas bon en design

Vidéo : https://youtu.be/15OxqzwfXrk · durée 22:36 · résumé Gemini (gemini-flash-lite-latest, lot de 8) du 2026-10-13
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1. **Idée principale :** Analyser les critères d'un portfolio de développeur efficace et minimaliste (tendance 2025) et le coder rapidement avec Next.js et Tailwind CSS pour valoriser ses compétences sans erreurs de design.
2. **Outils, sites ou dépôts GitHub cités :**
   - **Next.js :** Gratuit, framework React.
   - **Tailwind CSS :** Gratuit, framework CSS utilitaire.
   - **pnpm :** Gratuit, gestionnaire de paquets.
   - **Eslint / Prettier :** Gratuit, outils de lintage et formatage.
   - **Google Fonts (Geist / Geist Mono) :** Gratuit, typographies.
   - **clsx / tailwind-merge :** Gratuit, utilitaires pour classes CSS.
   - **GitHub / LinkedIn / X (Twitter) / YouTube :** Gratuits (plateformes de réseaux/portfolio).
   - **Excalidraw :** Gratuit, outil de dessin pour schémas.
3. **Astuces concrètes et réutilisables :**
   - Définir l'objectif d'un portfolio (freelance, CV en ligne ou showcase de style) et éviter les animations trop complexes si on n'est pas designer.
   - Suivre une tendance minimaliste (style 2025) avec des polices propres (Geist), une structure claire (Header, Main, Footer en Flexbox) et des liens directs vers ses expériences et projets.
   - Initialiser un projet Next.js avec `pnpm dlx create-next-app@latest` et configurer Tailwind CSS.
   - Utiliser des variables CSS pour les polices et configurer le layout global pour un design responsive et propre.
4. **Chiffres de revenus annoncés :**
   - « Création de site : 2 000 € » (exemple d'offre freelance affiché dans le schéma explicatif, présenté comme exemple hypothétique).
