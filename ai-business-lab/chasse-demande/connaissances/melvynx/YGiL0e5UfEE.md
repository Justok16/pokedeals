1) **Idée principale :** Présentation de l'événement « Advent of Code » (édition 2022) et tutoriel pas-à-pas pour résoudre le premier exercice en JavaScript, afin de progresser en développement.
2) **Outils, sites ou dépôts GitHub cités :**

- **Node.js :** Gratuit. Environnement d'exécution JavaScript (mentionné pour exécuter le code en local).
- **TypeScript / JavaScript :** Langages de programmation.

3) **Astuces concrètes et réutilisables :**
- Copier-coller l'input de l'exercice dans un fichier texte local (ex: `1.txt`) pour travailler en local.
- Commencer toujours par tester le code sur les données d'exemple fournies par l'énoncé avant d'utiliser le vrai fichier d'input.
- Utiliser la fonction `fs.readFileSync` (de Node.js) pour lire le fichier d'input, puis `toString()` et `split()` pour manipuler les données par ligne.
- Utiliser `.map()` pour transformer les données et `.reduce()` pour sommer les valeurs (par exemple, calculer le total des calories par Elfe).
- Utiliser `.sort()` avec une fonction de comparaison (`(a, b) => b - a`) pour trier les résultats par ordre décroissant et trouver rapidement les plus grandes valeurs.
