1) **Idée principale** : Présentation de **shadcn/ui**, une librairie de composants React moderne et révolutionnaire qui permet de copier-coller directement le code des composants dans son projet au lieu d'installer un package entier, ce qui facilite leur personnalisation.
2) **Outils, sites ou dépôts cités** :
   - **shadcn/ui** : Librairie de composants React open source (gratuit), basée sur Radix UI et Tailwind CSS.
   - **Radix UI** : Librairie de composants accessibles (utilisée sous le capot par shadcn/ui).
   - **Tailwind CSS** : Framework CSS (utilisé pour les styles).
3) **Astuces concrètes et réutilisables** :
   - Copier et coller le code source des composants nécessaires directement dans son code (par exemple, le composant Switch) au lieu d'utiliser `npm install` d'une grosse librairie tierce.
   - Personnaliser facilement les styles et les couleurs via les variables CSS et l'écosystème de Tailwind CSS.
