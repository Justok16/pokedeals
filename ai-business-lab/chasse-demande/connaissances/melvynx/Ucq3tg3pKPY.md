# Claude Code 2.1.0: Nouveautés et améliorations

Vidéo : https://youtu.be/Ucq3tg3pKPY · durée 1:27 · résumé Gemini (gemini-flash-lite-latest, lot de 10) du 2026-10-19
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale** :
Le créateur présente la version 2.1.0 de « Claude Code » et le nouveau kit SDK open-source de « TanStack AI », qui permet d'intégrer uniformément n'importe quelle API d'IA (OpenAI, Anthropic, etc.) dans une application TypeScript, quel que soit le framework utilisé.

2) **Outils, sites ou dépôts GitHub cités** :
- **TanStack AI (SDK / `@tanstack/ai-client`)** : outil open-source (gratuit), sert de SDK unifié pour intégrer des API d'IA multi-fournisseurs (OpenAI, Anthropic, Gemini, etc.).
- **Claude Code 2.1.0** : outil / application de développement (payant via abonnement), sert à coder, gérer des hooks, des skills et exécuter des agents.
- **GitHub (`github.com/anthropics/claude-...`)** : plateforme de code (gratuite), sert à héberger les dépôts et documentations.
- **code.claude.com/docs/en/setup** : site web (gratuit), sert à consulter la documentation d'installation.

3) **Astuces concrètes et réutilisables** :
- Utiliser le raccourci `Shift + Enter` pour créer des retours à la ligne au lieu de soumettre directement le prompt dans Claude Code.
- Utiliser des wildcards dans les configurations de permissions pour simplifier l'accès aux outils par l'IA (ex. `bash-*`).
- Utiliser TanStack AI pour uniformiser l'appel à différentes IA avec un seul adaptateur de code dans un projet TypeScript (Next.js, Express, etc.).
