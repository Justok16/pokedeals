1) **Idée principale :** Présentation de l'extension VS Code « Tailwind CSS Switch », un outil très pratique pour modifier et faire défiler rapidement les valeurs des classes Tailwind directement dans son éditeur de code à l'aide de raccourcis clavier.
2) **Outils, sites ou dépôt GitHub cités :**
- **Tailwind CSS Switch** : extension pour Visual Studio Code (gratuit).
- **Visual Studio Code (VS Code)** : éditeur de code (gratuit).
3) **Astuces concrètes et réutilisables :**
- Installer l'extension **Tailwind CSS Switch** depuis la marketplace de VS Code.
- Utiliser le raccourci clavier `Cmd + Shift + Flèche gauche / Flèche droite` pour modifier rapidement une classe Tailwind (comme la marge ou le padding) en incrémentant/décrémentant sa valeur.
- Utiliser le raccourci `Flèche haut / Flèche bas` sur une propriété (ex: `mb` pour margin-bottom) pour faire défiler les variantes de tailles disponibles (ex: `mb-2`, `mb-4`, `mb-x`, etc.) sans avoir à les taper manuellement.
