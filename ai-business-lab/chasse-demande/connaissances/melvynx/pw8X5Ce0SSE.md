# Voici Ma STACK ULTIME Pour Coder Avec l'AI

Vidéo : https://youtu.be/pw8X5Ce0SSE · durée 11:21 · résumé Gemini (gemini-flash-lite-latest, lot de 9) du 2026-10-15
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale** : Le vidéaste partage sa "stack AI" personnelle pour le développement, en expliquant pourquoi il n'utilise pas les outils les plus courants (comme ChatGPT ou GitHub Copilot) mais préfère des éditeurs et assistants spécialisés comme **Cursor**, **Supermaven** et **Phind**, pour optimiser sa vitesse, son contexte et son efficacité à moindre coût.

2) **Outils, sites ou dépôts GitHub cités** :
- **Cursor** (cursor.com) : Éditeur de code basé sur l'IA, fork de VS Code (gratuit avec options payantes).
- **VS Code** : Éditeur de code (mentionné comme outil de base, gratuit).
- **Supermaven** : Extension d'autocomplétion et assistant IA pour le code (payant, environ 10 $ à 40 $/mois selon les plans).
- **GitHub Copilot** : Assistant IA (mentionné, payant).
- **ChatGPT** (OpenAI) : Assistant IA (mentionné, gratuit/payant).
- **Gemini** (Google) : Assistant IA (mentionné).
- **Phind** (phind.com) : Moteur de recherche et assistant IA orienté développeurs (gratuit/payant).
- **TypingMind** : Interface utilisateur pour interagir avec plusieurs modèles d'IA (Claude, GPT-4, etc.) avec un modèle de tarification par abonnement ou usage (payant).
- **Mistral AI** : Modèle d'IA (mentionné).
- **Claude 3.5 Sonnet** (Anthropic) : Modèle d'IA (mentionné, payant).

3) **Astuces concrètes et réutilisables** :
- Utiliser un IDE dédié à l'IA comme **Cursor** pour poser des questions directement sur l'ensemble de la documentation ou de la codebase (via `@codebase`).
- Préférer des outils d'autocomplétion ultra-rapides et dotés d'un grand contexte comme **Supermaven** pour gagner du temps en codant.
- Utiliser **Phind** pour chercher des réponses techniques en lien avec le code ou des documentations de bibliothèques.
- Centraliser plusieurs modèles de langage via une interface comme **TypingMind** pour ne payer qu'à l'usage via les clés API.
