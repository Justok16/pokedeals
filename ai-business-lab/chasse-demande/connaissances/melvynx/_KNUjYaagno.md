1. **Idée principale :** Tutoriel pour récupérer des données d'une API externe via `fetch` et les afficher dynamiquement dans un fichier HTML avec JavaScript.
2. **Outils, sites ou dépôts GitHub cités :**
   - **JSONPlaceholder** (jsonplaceholder.typicode.com) : API factice gratuite pour tests et prototypage.
3. **Astuces concrètes et réutilisables :**
   - Utiliser `fetch(url)` pour appeler une API.
   - Utiliser `.then(response => response.json())` pour parser la réponse en JSON.
   - Parcourir les données reçues avec une boucle (ex. `for...of`) et créer des éléments du DOM (`document.createElement`) pour les insérer dans une liste (`<ul>`/`<li>`).
