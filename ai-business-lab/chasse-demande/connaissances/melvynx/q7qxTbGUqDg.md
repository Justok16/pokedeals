# ZED Le meilleur IDE (je ne peux plus retourner sur VSCode)

Vidéo : https://youtu.be/q7qxTbGUqDg · durée 15:39 · résumé Gemini (gemini-3-flash-preview, lot de 4) du 2026-10-09
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale** : Comparaison et retour d'expérience après deux mois d'utilisation de l'éditeur de code **Zed** face à **Cursor**, en mettant l'accent sur le minimalisme, la vitesse d'exécution et l'intégration des modèles d'IA pour maximiser la productivité des développeurs.

2) **Outils, sites ou dépôts cités** :
*   **Zed** (Open-source, gratuit) : Éditeur de texte ultra-rapide écrit en Rust, privilégié par l'auteur pour sa légèreté.
*   **Cursor** (Gratuit/Payant) : IDE basé sur VS Code avec IA intégrée.
*   **Claude Code** (Payant) : Interface en ligne de commande pour interagir avec l'agent IA de Anthropic.
*   **Gemini 2.0 Flash / Gemini 1.5 Pro** (Payant via API) : Modèles d'IA de Google intégrés dans Zed.
*   **Claude 3.5 Sonnet / Opus** (Payant via API/Abonnement) : Modèles d'Anthropic utilisés pour le code.
*   **GitHub Copilot** (Payant) : Assistant de complétion de code (jugé décevant par l'auteur par rapport à ses concurrents).
*   **Notion** (Gratuit/Payant) : Utilisé pour partager sa configuration Zed optimisée.

3) **Astuces concrètes et réutilisables** :
*   **Productivité par les raccourcis** : Utiliser un éditeur minimaliste (Zed) qui force l'apprentissage des raccourcis clavier plutôt que de cliquer sur des boutons, ce qui accélère radicalement le flux de travail.
*   **Multi-modèles** : Ne pas se limiter à une seule IA ; utiliser Gemini 2.0 Flash pour les tâches rapides et Claude 3.5 pour la réflexion complexe.
*   **Environnement de développement (DevEnv)** : Séparer les terminaux pour lancer les serveurs d'un côté et les agents IA (Claude Code) de l'autre pour un multitâche fluide.

4) **Chiffres de revenus annoncés** : L'auteur affirme dépenser environ **58,64 $ par jour** en consommation d'API pour ses outils IA (affirmé par l'auteur). Pas de revenus annoncés.
