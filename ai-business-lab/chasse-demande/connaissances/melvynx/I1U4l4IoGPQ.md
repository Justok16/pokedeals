# 7 ERREURS que font les devs web (je les ai aussi faites)

Vidéo : https://youtu.be/I1U4l4IoGPQ · durée 14:13 · résumé Gemini (gemini-flash-lite-latest, lot de 8) du 2026-10-13
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1. **Idée principale :** Présentation des 7 erreurs majeures commises par les développeurs juniors (sauter les bases, rester bloqué dans les tutoriels, absence de projets concrets, méconnaissance de Git/GitHub, incompréhension du web/HTTP, se comparer aux confirmés, ne pas demander d'aide ou sous-utiliser les outils) et des solutions pour progresser.
2. **Outils, sites ou dépôts GitHub cités :**
   - **HTML / CSS / JavaScript / Node.js :** Gratuits, technologies web fondamentales.
   - **React / Next.js / TypeScript :** Gratuits, frameworks et langages modernes.
   - **Git / GitHub :** Gratuits, outils de versioning de code.
   - **Jira / Scrum :** Outils de gestion de projet (version gratuite/payante).
   - **Google / StackOverflow :** Gratuits, plateformes de recherche et questions/réponses.
   - **ChatGPT / Claude / Cursor :** Outils d'IA (versions gratuites/payantes) pour assister le développement.
   - **mlv.sh/web :** Plateforme de formation de l'auteur (payante/ressources associées).
3. **Astuces concrètes et réutilisables :**
   - Ne pas passer directement aux frameworks (React) sans maîtriser les bases de JavaScript (manipulation du DOM, tableaux, fetch).
   - Pratiquer activement en créant de vrais projets (ex: application de quiz après un tuto JS) plutôt que de s'enfermer dans le "tutoriel hell".
   - Apprendre impérativement Git, GitHub et TypeScript car ils sont exigés en entreprise.
   - Comprendre le fonctionnement du protocole HTTP (requêtes, réponses, méthodes, headers, body) et des serveurs.
   - Ne pas se comparer aux développeurs seniors et progresser à son rythme.
   - Utiliser une hiérarchie d'aide : 1. Documentation/Google/StackOverflow -> 2. IA (ChatGPT, Claude, Cursor) -> 3. Mentor / Communauté humaine.
