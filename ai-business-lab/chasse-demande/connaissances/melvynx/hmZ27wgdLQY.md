# Configure ZED comme ça ou juste supprime-le !

Vidéo : https://youtu.be/hmZ27wgdLQY · durée 18:22 · résumé Gemini (gemini-flash-lite-latest, lot de 7) du 2026-10-10
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale** : Le vidéaste explique comment configurer et exploiter au maximum l'éditeur de code **Zed**, en important ses réglages depuis VS Code/Cursor, en connectant des fournisseurs d'IA (Anthropic, OpenAI, GitHub Copilot) via leurs clés API, et en configurant les "mods", "hooks" et "skills" pour transformer l'IA en un développeur senior.

2) **Outils, sites et dépôts GitHub cités** :
- **Zed** : Éditeur de code ultra-rapide (gratuit / open-source).
- **VS Code** : Éditeur de code (gratuit).
- **Cursor** : Éditeur de code (freemium).
- **GitHub Copilot** : Assistant de code (payant).
- **Anthropic / Claude** : Fournisseur d'IA (payant).
- **OpenAI** : Fournisseur d'IA (payant).
- **Google AI / Gemini** : Fournisseur d'IA (payant).
- **Ollama** : Outil pour exécuter des modèles en local (gratuit).
- **Material Icon Theme** : Extension d'icônes pour Zed (gratuit).
- **mlv.sh/fc** : Lien de formation/configuration du créateur (payant/non précisé).

3) **Astuces concrètes et réutilisables** :
- Importer automatiquement ses réglages et raccourcis clavier depuis VS Code ou Cursor lors du premier lancement de Zed (via la commande `Command+Shift+P` -> `Open Settings` / `Import Settings`).
- Connecter plusieurs fournisseurs de LLM (Claude, OpenAI, Gemini, Copilot) en récupérant leurs clés API respectives (ex. sur platform.openai.ai ou console.anthropic.com) et les coller dans Zed pour bénéficier de l'autocomplétion et du chat IA.
- Configurer des "mods" (code JS/TS s'exécutant dans Zed), des "hooks" (scripts lancés sur un événement) et des "skills" pour automatiser des tâches complexes directement dans l'éditeur.
- Utiliser des raccourcis clavier personnalisés pour la recherche, le renommage (`cmd+R`) et la gestion des fichiers.
