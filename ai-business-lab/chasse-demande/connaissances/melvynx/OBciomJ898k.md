# Apprendre TAILWIND en juste 5 MINUTES

Vidéo : https://youtu.be/OBciomJ898k · durée 4:53 · résumé Gemini (gemini-flash-lite-latest, lot de 5) du 2026-10-16
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1. **Idée principale :**
   Cette vidéo est un tutoriel complet pour apprendre et comprendre **Tailwind CSS** (un framework CSS utility-first) en 5 minutes, suivi de la construction pratique d'un portfolio complet de développeur avec Next.js, shadcn/ui, et l'intégration de **Cal.com** pour la prise de rendez-vous.

2. **Outils, sites ou dépôts GitHub cités :**
   * **Tailwind CSS** (Gratuit, framework CSS utility-first) : Outil principal pour appliquer les styles directement dans le balisage HTML/JSX.
   * **Next.js** (Gratuit, framework React) : Utilisé pour structurer l'application web.
   * **shadcn/ui** (Gratuit, bibliothèque de composants UI) : Utilisé pour installer des composants de base (Avatar, Badge, Button, Card, Input, Label, Skeleton, Sonner, etc.).
   * **Iconduck** (Gratuit) : Utilisé pour récupérer des icônes SVG (YouTube, Twitter, etc.).
   * **Cal.com** (Gratuit / Plans payants) : Utilisé pour intégrer un widget de réservation de rendez-vous/appels (via `@cal.com/embed-react`).
   * **ui.jln.dev** (Gratuit, site de thèmes/styles) : Utilisé pour piocher des thèmes et des configurations CSS.

3. **Astuces concrètes et réutilisables :**
   * Utiliser l'approche **utility-first** de Tailwind pour écrire le CSS directement dans les classes du balisage (ex: `bg-red-500`, `p-4`), évitant ainsi d'avoir à maintenir de gros fichiers CSS séparés.
   * Utiliser les modificateurs de Tailwind (`hover:`, `md:`, etc.) pour gérer le responsive design et les états interactifs sans écrire de media queries complexes.
   * Installer shadcn/ui via sa CLI (`pnpm dlx shadcn-ui@latest init` puis `pnpm dlx shadcn-ui@latest add [composant]`) pour configurer rapidement un design system propre avec des variables CSS et des composants accessibles.
