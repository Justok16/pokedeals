# 3 Features Copilot pour faire Exploser ta productivité

Vidéo : https://youtu.be/Z3CMH8di0pA · durée 7:35 · résumé Gemini (gemini-flash-lite-latest, lot de 9) du 2026-10-18
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale :** Démonstration de trois fonctionnalités majeures de GitHub Copilot pour booster sa productivité en tant que développeur (commandes inline, chat contextuel, et génération de commits automatisés).
2) **Outils, sites ou dépôt GitHub cités :**
- **GitHub Copilot** : outil d'assistance au code par IA (payant / abonnement) intégré dans VS Code.
- **VS Code** : éditeur de code (gratuit).
3) **Astuces concrètes et réutilisables :**
- Utiliser le raccourci `Cmd + I` (ou `Ctrl + I`) sur une ligne de code pour ouvrir le panneau Copilot Inline, formuler une requête en langage naturel (ex: "create a separate type for the course card props") et accepter ou rejeter la modification en direct.
- Utiliser le chat Copilot avec la syntaxe `@workspace` pour interroger l'IA sur l'ensemble de la codebase (ex: "@workspace what is the framework used?"), lui permettant d'analyser tous les fichiers de configuration (package.json, tailwind.config.ts, etc.) et de répondre précisément.
- Poser des questions ciblées dans le chat Copilot sur un fichier ou une fonction spécifique (ex: `@workspace, how does this hook work?` en sélectionnant un composant) pour obtenir une explication détaillée du code.
- Demander à Copilot de générer des tests unitaires pour une fonction en sélectionnant le code et en tapant `/tests` dans le chat.
- Générer automatiquement des messages de commit significatifs en cliquant sur l'icône dédiée de Git dans VS Code grâce à l'intégration de Copilot.
