# JE NE CROIS PAS AU VIBE CODING : Voici la solution

Vidéo : https://youtu.be/HtfvRrzAB8o · durée 13:45 · résumé Gemini (gemini-flash-lite-latest, lot de 6) du 2026-10-11
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale** : Redéfinir ce qu'est réellement le « Vibe Coding » (coder avec l'IA sans regarder le code, en se focalisant uniquement sur les résultats et en guidant l'IA par le dialogue) par opposition à l'« AI Coding » (où le développeur review, guide et modifie activement le code généré).

2) **Outils, sites et dépôts GitHub cités** :
* **Cursor** : Éditeur de code assisté par IA (non précisé si gratuit ou payant).
* **Claude Desktop / Claude Code** : Applications et outils d'Anthropic (non précisé si gratuit ou payant).
* **ChatGPT** : Modèle d'OpenAI (non précisé si gratuit ou payant).
* **SaveIt.now** : Application web / projet de l'auteur (non précisé si gratuit ou payant).
* **Lovable.dev** : Plateforme de création d'applications par IA (non précisé si gratuit ou payant).
* **GitHub Copilot** : Assistant de code (non précisé si gratuit ou payant).
* **VS Code** : Éditeur de code (gratuit).

3) **Astuces concrètes et réutilisables** :
* Ne pas essayer de lire ou de corriger soi-même le code généré en mode « Vibe Coding » : se focaliser uniquement sur le comportement de l'application et demander à l'IA de corriger le problème si le résultat ne fonctionne pas.
* En mode « AI Coding » (recommandé pour les développeurs), donner des instructions précises en langage naturel dans les fichiers de tâches (ex : `run-tasks.md`), en ciblant le fichier exact, le type de données, et les comportements attendus.
* Utiliser la commande de build / test (ex : `run-task`) pour laisser l'agent de code (comme Claude Code) détecter et corriger ses propres erreurs de typage ou de compilation.
* Pour les outils comme Cursor, activer l'indexation de la codebase pour optimiser les recherches de fichiers et la pertinence du contexte fourni à l'IA.
