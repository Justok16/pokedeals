1) **Idée principale** : Guide d'introduction pour démarrer un projet avec Next.js 13 en partant de zéro, en comprenant l'architecture de l'App Router, les Server Components et l'organisation des dossiers et fichiers de configuration.

2) **Outils, sites ou dépôts GitHub cités** :
   - **Next.js 13** : Gratuit (open source), framework React.
   - **PNPM / NPM** : Gratuit, gestionnaires de paquets.
   - **VS Code** : Gratuit, éditeur de code.
   - **Vercel** : Gratuit (avec offres payantes), plateforme d'hébergement.
   - **Git** : Gratuit, outil de gestion de versions.

3) **Astuces concrètes et réutilisables** :
   - Créer un nouveau projet Next.js via la commande `npx create-next-app@latest --experimental-app`.
   - Utiliser l'alias `@/` pour simplifier les chemins d'importation dans le code.
   - Comprendre la distinction entre les Server Components (exécutés côté serveur par défaut dans l'App Router) et l'utilisation ponctuelle de `'use client'` pour les composants interactifs.
   - Organiser les fichiers CSS modules (`page.module.css`) pour appliquer des styles scopés à des pages ou composants spécifiques.
   - Créer des routes API personnalisées via le dossier `app/api/.../route.ts` pour gérer des requêtes HTTP (GET, POST).
