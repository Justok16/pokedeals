# Claude Desktop : l'erreur que font tous les débutants avec Claude Code

Vidéo : https://youtu.be/xWuLotc8zjE · durée 18:39 · résumé Gemini (gemini-flash-lite-latest, lot de 7) du 2026-10-10
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale** : Le vidéaste s'adresse aux utilisateurs non techniques ou entrepreneurs utilisant Claude Code ou Codex pour optimiser leur quotidien et leur métier, en listant 5 énormes erreurs à éviter pour tirer le meilleur parti de l'IA.

2) **Outils, sites et dépôts GitHub cités** :
- **Claude Code** : Outil de développement en ligne de commande (payant/abonnement).
- **Codex** : Outil similaire (non précisé).
- **Visual Studio Code (VS Code)** : Éditeur de code (gratuit).
- **GitHub** : Plateforme de code (gratuit).
- **mlv.sh/one-one** (ou mlv.sh/fc) : Lien personnel du créateur pour des services 1-1 ou formations (payant/non précisé).

3) **Astuces concrètes et réutilisables** :
- **Erreur n°1 (Le terminal)** : Ne pas utiliser systématiquement le terminal en mode full-screen avec VS Code ouvert partout si l'on est un profil non technique ; utiliser plutôt l'interface graphique de Claude Desktop, qui est beaucoup plus digeste et logique.
- **Erreur n°2 (Le "Second Brain" et l'excès de règles)** : Éviter de créer des centaines de fichiers `.md`, de dossiers imbriqués et de règles complexes dans un "second brain" (comme Obsidian ou Claude.md), car cela surcharge l'IA en tokens, augmente le temps de réponse et provoque des hallucinations. Préférer le minimalisme.
- **Erreur n°3 (La contradiction des styles)** : Ne pas donner des instructions contradictoires à l'IA d'un jour sur l'autre (ex. changer de style ou de couleur préférée sans nettoyer l'historique), ce qui perturbe ses décisions.
- **Erreur n°4 (Le stockage inutile de Markdown)** : Ne pas stocker des tonnes de fichiers texte partout ; chercher plutôt la source directement là où elle existe.
- **Erreur n°5 (L'encombrement des connecteurs)** : Ne pas surcharger l'agent IA de dossiers et de notes inutiles ; séparer proprement les projets (ex. un dossier par projet) et nettoyer régulièrement les fichiers obsolètes.
