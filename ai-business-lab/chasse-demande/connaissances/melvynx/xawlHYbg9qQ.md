1) **Idée principale** : Comparaison entre GitHub Copilot et un outil alternatif nommé Supermaven, présenté comme beaucoup plus rapide et doté d'une plus grande capacité de contexte (*token context window*).

2) **Outils, sites ou dépôts GitHub cités** :
- **GitHub Copilot** : Payant, assistant de codage par IA.
- **Supermaven** (supermaven.com) : Freemium (version gratuite et version Pro à 99 $ / mois ou 100 $ / an), assistant de codage par IA ultra-rapide avec une grande fenêtre de contexte (300 000 tokens).
- **Prisma** : Gratuit, ORM TypeScript/Node.js.

3) **Astuces concrètes et réutilisables** :
- Utiliser un assistant doté d'une grande fenêtre de contexte (comme les 300 000 tokens de Supermaven) pour lui permettre de comprendre l'ensemble d'une base de code et de proposer des suggestions plus pertinentes sur plusieurs fichiers.
- Profiter de l'intégration native avec les environnements de développement (via des extensions pour VS Code ou l'utilisation avec Cursor) pour accélérer l'écriture de mutations et d'actions (par exemple avec Next.js et Prisma).

4) **Chiffres de revenus annoncés** : 
- 99 $ par mois ou 100 $ par an (abonnement Pro de Supermaven, affirmé par l'auteur).
