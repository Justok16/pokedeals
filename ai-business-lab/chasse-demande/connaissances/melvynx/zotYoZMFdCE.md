# Pourquoi je code sur MacBook en tant que DEV

Vidéo : https://youtu.be/zotYoZMFdCE · durée 13:51 · résumé Gemini (gemini-flash-lite-latest, lot de 10) du 2026-10-16
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale :** L'auteur compare macOS, Windows et Linux pour les développeurs, et argumente en faveur de macOS (sur puces Apple Silicon) en expliquant pourquoi c'est le meilleur système d'exploitation pour coder, grâce à sa stabilité, son écosystème d'applications et ses performances matérielles.

2) **Outils, sites ou dépôts GitHub cités :**
- **macOS / Windows / Linux :** Systèmes d'exploitation comparés.
- **Raycast :** Lanceur d'applications et outil de productivité pour macOS (gratuit/payant).
- **CleanMyMac :** Application de nettoyage et de gestion pour macOS (payante).
- **Visual Studio Code (VS Code) :** Éditeur de code multiplateforme (gratuit).
- **WSL (Windows Subsystem for Linux) :** Couche de compatibilité pour exécuter Linux sur Windows (gratuit).
- **Homebrew / APT :** Gestionnaires de paquets pour macOS et Linux.
- **Figma / Adobe / Chrome :** Logiciels et navigateurs mentionnés.

3) **Astuces concrètes et réutilisables :**
- **Profiter de l'écosystème Unix natif sur macOS :** macOS partage des bases communes avec les environnements de serveur (via le terminal ZSH et les outils Unix), ce qui simplifie le développement et l'utilisation de la ligne de commande.
- **Utiliser des outils de productivité exclusifs ou optimisés :** Des logiciels comme Raycast ou CleanMyMac permettent d'optimiser le flux de travail et de garder la machine propre.
- **Bénéficier des performances de l'architecture ARM (puces M1, M2, M3) :** Les ordinateurs portables Apple offrent une excellente autonomie, un fonctionnement silencieux (absence de surchauffe excessive) et des performances de compilation élevées pour le développement.
