# Les PLUGINS sur Claude Code : ça devient incontrôlable !!

Vidéo : https://youtu.be/hvfNIi8jqPg · durée 16:54 · résumé Gemini (gemini-flash-lite-latest, lot de 7) du 2026-10-10
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale** : Le vidéaste présente l'introduction des **Marketplaces de plugins pour Claude Code**, qui transforme l'outil en un véritable OS pour coder avec des commandes slash, des agents, des serveurs MCP et des plugins partageables.

2) **Outils, sites et dépôts GitHub cités** :
- **Claude Code** : Outil de développement d'Anthropic (payant).
- **GitHub** : Hébergeur de dépôts de plugins/marketplaces (gratuit/payant).
- **iTerm** : Terminal macOS (gratuit).
- **VS Code** : Éditeur de code (gratuit).
- **Cursor** : Éditeur de code (freemium).
- **Claude Code Templates** (dépôt GitHub `davila7/claude-code-templates` / `wohobson/agents`) : Dépôts de plugins et templates (gratuit).

3) **Astuces concrètes et réutilisables** :
- Installer des plugins via la commande `/plugin` dans Claude Code pour étendre les fonctionnalités (ex. gestion de la sécurité, flux de travail DevOps, templates de code).
- Ajouter des marketplaces tierces en tapant `/plugin marketplace add <owner/repo>` ou via une URL GitHub.
- Gérer, activer (`enable`) ou désactiver (`disable`) des plugins à la volée pour personnaliser son environnement de développement.
- Partager ses propres configurations et plugins sous forme de paquets contenant des commandes slash, des sub-agents et des serveurs MCP.
