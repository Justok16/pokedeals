# secret : la roadmap SIMPLE pour devenir Développeur Web pour 2025 en 6 mois

(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale** : Présentation d'une roadmap complète pour devenir développeur web (HTML/CSS, JavaScript, NodeJS, Git/GitHub, SQL/PostgreSQL, React et Next.js) et créer des SaaS, des sites en freelance ou des applications IA afin de trouver un emploi ou monétiser ses compétences.
2) **Outils, sites ou dépôts GitHub cités** :
- **Roadmap.sh** (gratuit, site de visualisations de parcours de développement web).
- **Codelynx.dev** (site personnel de l'auteur pour les exemples/formations).
- **Calendly** (service externe de calendrier).
- **Frontend Mentor** (gratuit, plateforme de défis et projets front-end réalistes).
- **Mailchimp** (non détaillé, mentionné comme exemple de service).
- **Git** et **GitHub** (gratuits, outils de gestion de code et de versioning).
- **Express** (gratuit, framework NodeJS pour créer des serveurs backend).
- **PostgreSQL / SQL** (systèmes de gestion de bases de données).
- **React** (gratuit, bibliothèque front-end).
- **SWR** (bibliothèque de requêtes de données).
- **Zustand** (gestion d'état).
- **Elevation Generator** (site de test/génération d'images : `elevation-generator.vercel.app`).
- **Apple Timer Clone** (site de timer : `apple-timer.vercel.app`).
- **Next.js** (gratuit, meta-framework React).
- **Prisma** (ORM SQL pour faciliter les requêtes de base de données).
- **Tailwind** (librairie de style CSS).
- **AuthJS** (système d'authentification).
- **Tortuga** (site/application mobile d'un abonné de l'auteur pour partager des aventures de montagne : `tortuga.ovh`).
- **MailerLite** (outil d'email marketing).
- **Trello** / **Jira** (outils de gestion de projets/tableaux).
- **Podia** (création de sites/boutiques en ligne).
- **Canny** (outil de recueils de feedbacks/feature requests).
- **Typefully** (éditeur de threads Twitter/LinkedIn).
3) **Astuces concrètes et réutilisables** :
- Pratiquer à chaque étape en créant de petits projets concrets (calculatrice, générateur de mots de passe, todo-list avec backend, applications avec React/Next.js) plutôt que de s'arrêter à la théorie.
- Décomposer son apprentissage en blocs logiques successifs (HTML/CSS -> JS -> NodeJS/Git -> SQL -> React -> Next.js) pour éviter la surcharge d'informations.
- Faire des recherches Google et utiliser la documentation des outils plutôt que d'apprendre par cœur.
- Créer un portfolio de projets (SaaS, applications IA, sites freelance) pour prouver ses compétences lors de la recherche d'un emploi ou de missions.
