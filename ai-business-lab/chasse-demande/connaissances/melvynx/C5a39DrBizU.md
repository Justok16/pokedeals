# Formation Zed : IDE parfait pour les développeurs (R.I.P Cursor)

Vidéo : https://youtu.be/C5a39DrBizU · durée 16:39 · résumé Gemini (gemini-3.5-flash-lite, lot de 6) du 2026-10-08
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale** : La vidéo propose un tutoriel complet sur l'éditeur de code **Zed**, présenté comme une alternative ultra-rapide, écrite en Rust et optimisée pour la collaboration et l'IA, par opposition aux IDE lourds basés sur VS Code (comme Cursor ou Windsurf).

3) **Astuces concrètes et réutilisables** :
- Installer et configurer **Zed** (disponible sur macOS, Linux, Windows) en important ses préférences et en l'utilisant comme éditeur principal pour réduire l'utilisation de RAM par rapport à VS Code.
- Utiliser les raccourcis clavier natifs de Zed (ex: `Ctrl+Shift+G` pour Git, `Ctrl+Shift+E` pour l'éditeur, etc.) ou configurer des raccourcis personnalisés.
- Configurer les intégrations d'IA (LLM Providers comme Anthropic, OpenAI, Google Gemini, Ollama) via le menu de configuration pour profiter d'un assistant de code intégré sans dépendre d'extensions tierces lourdes.
- Activer l'autocomplétion contextuelle et fractionner l'interface en plusieurs terminaux/onglets pour le multitâche.

2) **Outils, sites et dépôts GitHub cités** :
- **Zed (zed.dev)** : Éditeur de code open source (écrit en Rust), gratuit, ultra-rapide, axé sur la performance et l'IA.
- **VS Code** : Éditeur de référence (open source), comparé à Zed.
- **Cursor** : IDE payant/freemium basé sur VS Code.
- **Windsurf** : IDE basé sur VS Code.
- **GitHub Copilot** : Assistant de code payant.
- **Google Gemini / OpenAI / Anthropic** : Modèles d'IA intégrables dans Zed.
