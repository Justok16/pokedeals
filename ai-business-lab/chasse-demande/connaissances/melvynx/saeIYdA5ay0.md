# Ma Stack Technique : J'explique TOUS mes choix (j'ai changé...)

Vidéo : https://youtu.be/saeIYdA5ay0 · durée 28:12 · résumé Gemini (gemini-flash-lite-latest, lot de 8) du 2026-10-12
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale :**
L'auteur présente sa stack technique personnelle pour le développement web front-end et back-end, en expliquant les choix des outils utilisés (comme React, Zustand, Shadcn/UI, Tailwind, TanStack Query, Zod, React Hook Form, etc.) et les critères de sélection (popularité, communauté, flexibilité, écosystème).

2) **Outils, sites, dépôts GitHub et services cités :**
* **React** (gratuit/open source) : Bibliothèque front-end JavaScript (choisie pour sa popularité, son écosystème et sa flexibilité).
* **GitHub** (gratuit/open source) : Mentionné comme source principale des bibliothèques et IA.
* **Angular** (gratuit/open source) : Framework front-end (mentionné en comparaison).
* **Zustand** (gratuit/open source) : Bibliothèque de gestion d'état simple et flexible (choisie pour éviter les `useContext` globaux et injecter le server-state).
* **Redux** (gratuit/open source) : Bibliothèque de gestion d'état (jugée trop complexe pour les besoins décrits).
* **Shadcn/UI** (gratuit/open source) : Bibliothèque de composants UI (décrite comme un nouveau standard de l'IA, beau et flexible).
* **21st.dev** (gratuit/open source) : Site web proposant des composants Shadcn/UI (mentionné pour rechercher des composants de design).
* **Grok** (mentionné comme IA/outil, non précisé si payant) : Modèle d'IA (évoqué pour son interface/code).
* **TwixCN** (gratuit/open source) : Outil/plateforme de personnalisation de thèmes pour Shadcn/UI.
* **Tailwind CSS** (gratuit/open source) : Framework CSS utilitaire (décrit comme le standard de l'IA, simple et personnalisable).
* **Emotion (Emotion/React)** (gratuit/open source) : Bibliothèque CSS-in-JS (mentionnée dans les graphiques NPM trends).
* **TanStack Query** (gratuit/open source) : Bibliothèque de gestion des requêtes asynchrones et du cache (choisie pour son système de cache et ses mutations).
* **Use SWR / SWR** (gratuit/open source) : Bibliothèque de requêtes de données (mentionnée en comparaison).
* **Zod** (gratuit/open source) : Bibliothèque de validation de schémas TypeScript (très populaire et stable).
* **Yup** (gratuit/open source) : Bibliothèque de validation (mentionnée en comparaison).
* **Valibot** (gratuit/open source) : Bibliothèque de validation (mentionnée en comparaison).
* **React Hook Form** (gratuit/open source) : Bibliothèque de gestion de formulaires (mentionnée en comparaison).
* **TanStack Form** (gratuit/open source) : Bibliothèque de formulaires (mentionnée en comparaison).
* **Remix** (gratuit/open source) : Framework web (mentionné en comparaison avec Next.js).
* **Prisma** (gratuit/open source) : ORM (mentionné dans la formation full-stack).
* **Better Auth** (gratuit/open source) : Outil d'authentification (mentionné dans la formation full-stack).
* **Lien de formation payant de l'auteur :** `mlv.sh/fullstack`.

3) **Astuces concrètes et réutilisables :**
* Choisir des outils populaires pour s'assurer qu'ils disposent de ressources financières (gafas), d'une grande communauté sur GitHub et de mises à jour régulières.
* Utiliser Zustand pour la gestion d'état locale/globale légère et pour injecter l'état serveur dans les client-hooks sans complexité superflue.
* Utiliser Shadcn/UI pour accélérer le design d'interface grâce à des composants prêts à l'emploi et personnalisables.
* Utiliser TanStack Query pour automatiser la gestion du cache et éviter les codes de gestion de requêtes complexes (comme le "A5 spaghetti code").
