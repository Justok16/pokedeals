3) **Astuces concrètes et réutilisables** :
* Pour tester un agent de code (comme Codex ou Claude Code), lui donner des tâches concrètes et utiles (ex : ajouter une API route, gérer la pagination avec curseur, créer des balises) plutôt que de générer des jeux 3D abstraits.

* Utiliser la commande de build (ex : `npm run build`) pour forcer l'agent à corriger ses propres erreurs de typage ou de compilation.
* Connaître les limites des agents : certains modèles (comme Codex) peuvent oublier de lire la documentation fournie si le prompt n'est pas assez directif, ou consommer beaucoup de tokens en "thinking".
