- **Claude Sonnet / Claude 4 Sonnet** (modèle d'IA, payant, tarifs indiqués : input 3$, output 15$, puis 0,2$ / 1,5$) : modèle d'IA comparé pour le code.
- **GPT-5** (modèle d'IA, payant/non précisé) : modèle d'IA comparé à Groq Code pour les tâches de code.
- **Codex** (modèle d'IA, payant/non précisé) : modèle d'IA testé pour comparer ses performances d'édition de code (jugé meilleur que Groq Code et GPT-5 sur ces tests).
- **site/base de données** (non précisé, gratuit/payant : non précisé) : l'application web testée gère l'upload de photos de profil, les routes, et la base de données.
