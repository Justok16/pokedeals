1) **Idée principale :** Conseils pour améliorer la qualité du code React ("clean code") en évitant trois erreurs fréquentes de débutant.
2) **Outils/Sites :** 
*   TLDR (outil de dessin) : non précisé, utilisé pour schématiser.
*   React.js : gratuit, framework de développement.
3) **Astuces concrètes :** 
*   Séparer les composants, la logique (state, hooks) et le code métier (JS functions).
*   Utiliser des "custom hooks" pour isoler la logique.
*   Éviter de trop utiliser le "double ternaire" dans le rendu, préférer la création de composants dédiés pour plus de lisibilité.
*   Éviter les `fetch` directement dans les `useEffect`.
