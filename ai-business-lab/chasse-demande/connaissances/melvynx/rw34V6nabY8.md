# 5 TIPS Tailwind que j'aurais dû suivre plus tôt...

1) **Idée principale :** Bilan de 3 ans d'utilisation de Tailwind CSS et 5 points essentiels à connaître pour bien l'utiliser et éviter les pièges, notamment l'importance de l'accepter pleinement.

2) **Outils, sites ou dépôts GitHub cités :**
* *Tailwind CSS* (gratuit, tailwindcss.com) : framework CSS utility-first.
* *eslint-plugin-tailwindcss* (gratuit, npm) : plugin ESLint pour forcer les bonnes pratiques Tailwind.
* *Flowbite* (gratuit, flowbite.com) : bibliothèque de composants et cheat sheet pour Tailwind.
* *Creative Tim* (gratuit/payant, creative-tim.com) : ressources et cheat sheet Tailwind.

3) **Astuces concrètes et réutilisables :**
* Utiliser `eslint-plugin-tailwindcss` pour maintenir la consistance et ordonner automatiquement les classes.
* Éviter d'utiliser la directive `@apply` pour ne pas créer de mauvaise architecture CSS.
* Utiliser le système de thème (`theme()`) dans le CSS ou les fichiers de configuration plutôt que de dupliquer des valeurs arbitraires.
* Profiter des utilitaires de spacing (`space-y-*`, `space-x-*`) pour espacer les éléments proprement.
* Accepter la philosophie de Tailwind (Utility-First) au lieu d'essayer de recréer du CSS traditionnel.
