# L'ERREUR que les Débutants font avec Tailwind !

Vidéo : https://youtu.be/qP7zxLsuSuo · durée 4:18 · résumé Gemini (gemini-flash-lite-latest, lot de 9) du 2026-10-18
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale :** L'intervenant compare Tailwind CSS à Bootstrap et au CSS traditionnel, démontrant pourquoi Tailwind surpasse les autres approches grâce à son style system rigoureux, ses couleurs bien choisies, ses ombres préréglées et sa cohésion directe dans le HTML/JSX, tout en rappelant qu'il est indispensable de savoir faire du CSS pur.
2) **Outils, sites ou dépôt GitHub cités :**
- **Tailwind CSS** : framework CSS utility-first (gratuit).
- **Bootstrap** : framework CSS (gratuit).
- **HyperUI** / **HyperUI / Tailwind UI** : bibliothèques de composants (gratuit/payant).
- **Tailwind Play** : playground en ligne pour tester Tailwind (gratuit).
3) **Astuces concrètes et réutilisables :**
- Utiliser Tailwind CSS pour écrire les classes utilitaires directement dans les balises HTML/JSX (ex: `bg-indigo-600 px-12 py-3 text-sm`), évitant ainsi d'avoir à basculer constamment entre des fichiers CSS séparés.
- S'appuyer sur le **Style System** de Tailwind (échelles de tailles cohérentes basées sur des multiples et des incréments exponentiels) pour garantir un design propre et harmonieux sans deviner les valeurs de padding ou de margin.
- Utiliser des bibliothèques de composants prêtes à l'emploi compatibles Tailwind (comme HyperUI) pour accélérer le développement d'interfaces.
