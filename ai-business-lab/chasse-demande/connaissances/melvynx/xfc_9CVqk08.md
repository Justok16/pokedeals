# Pourquoi j'utilise MacOS pour programmer ?

1) **Idée principale** : Pourquoi macOS est présenté comme le meilleur système d'exploitation pour les développeurs, grâce à 5 fonctionnalités clés (Terminal ZSH, Plein écran, Fenêtrage/Bureau, Explorateur de fichiers Finder, et Raycast).

2) **Outils, sites ou dépôts GitHub cités** :
- **macOS** : Payant (intégré aux ordinateurs Apple), système d'exploitation.
- **Linux** : Gratuit, système d'exploitation.
- **Windows** : Payant, système d'exploitation.
- **Oh My ZSH (OMZSH)** : Gratuit, framework de configuration pour ZSH.
- **Vim / Neovim** : Gratuit, éditeur de texte en ligne de commande.
- **VS Code (Visual Studio Code)** : Gratuit, éditeur de code source.
- **Visual Studio Code (IDE)** : Gratuit.
- **Arc** : Gratuit, navigateur web.
- **Supermaven** : Freemium, assistant IA de codage.
- **Figma** : Gratuit/Payant, outil de design.
- **Raycast** : Gratuit (avec options Pro), lanceur d'applications et outil de productivité pour macOS.
- **GitHub** : Gratuit, plateforme de gestion de code.

3) **Astuces concrètes et réutilisables** :
- Configurer un terminal performant avec ZSH, Oh My ZSH et des plugins de coloration syntaxique et de gestion Git pour un retour visuel instantané.
- Utiliser le mode plein écran et la gestion des fenêtres de macOS (avec des raccourcis clavier ou des outils dédiés) pour isoler l'environnement de développement et éviter les distractions.
- Maîtriser l'explorateur Finder en mode « colonne » pour naviguer rapidement dans les dossiers de code et les projets.
- Utiliser **Raycast** pour remplacer le Spotlight natif : gérer l'historique du presse-papier, lancer des scripts AppleScript personnalisés, rechercher des couleurs, gérer les fenêtres et interagir rapidement avec des extensions (comme GitHub ou des sélecteurs d'emojis).
