# Le SECRET de Cursor : pourquoi les réponses sont différentes de Claude ?

Vidéo : https://youtu.be/l3dNS4wsw6I · durée 13:53 · résumé Gemini (gemini-3.5-flash-lite, lot de 8) du 2026-10-08
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1. **Idée principale :** L'auteur compare en détail deux assistants de code par IA, **Cursor** et **Claude Code**, en analysant leur philosophie, leurs fichiers de configuration (system prompts), leurs outils disponibles et leurs approches ergonomiques (CLI vs IDE).
2. **Outils et dépôts GitHub :**
   * **Cursor** : Éditeur de code (IDE) basé sur VS Code avec IA intégrée.
   * **Claude Code** : Outil en ligne de commande (CLI) développé par Anthropic.
   * **Formation de l'auteur** (`mlv.sh/ai`) : Masterclass gratuite sur Claude Code.
3. **Astuces concrètes :**
   * Demander à l’IA de générer un fichier HTML ou un fichier de configuration listant tous les prompts, modèles et outils utilisés par l’assistant pour comparer leurs comportements.
   * Configurer des instructions système (« system prompts ») spécifiques pour affiner le style de code et les règles de sécurité dans l'environnement de développement.
4. **Chiffres affirmés par l'auteur :**
   * Nombre d'outils disponibles (selon la documentation comparée) : 28 outils pour Claude Code contre 18 outils pour Cursor.
