1) **Idée principale :** Utiliser les serveurs MCP (Model Context Protocol) dans Cursor pour donner accès à la documentation de bibliothèques tierces et permettre à l'IA d'interagir et d'écrire du code correct basé sur ces librairies.
2) **Outils, sites ou dépôts cités :**
- **Cursor** : Éditeur de code (ou fonctionnalité d'IA) intégrant les serveurs MCP.
- **Next-zod-route** : Bibliothèque pour Next.js (indexée via MCP).
- **Up-fetch** : Bibliothèque de fetch typée (indexée via MCP).
3) **Astuces concrètes et réutilisables :**
- Configurer un serveur MCP contextuel (comme `context7`) pour poser des questions sur des bibliothèques méconnues de l'IA.
- Indexer ses propres bibliothèques (comme `up-fetch`) pour que l'IA puisse générer des exemples précis et corrects de code.
