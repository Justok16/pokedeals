# Commit, push, branche : GitHub enfin expliqué simplement

Vidéo : https://youtu.be/WdaOQNihtOY · durée 6:51 · résumé Gemini (gemini-3-flash-preview, lot de 8) du 2026-10-22
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

**1) Idée principale :**
Comprendre le fonctionnement de GitHub pour les "vibe codeurs" (personnes codant avec l'aide d'IA), en utilisant GitHub comme un système de sauvegarde intelligent et un connecteur pour divers outils de développement.

**2) Outils, sites ou dépôts cités :**
*   **GitHub** (Gratuit) : Plateforme de stockage de code ("repo") et de versioning.
*   **Claude** (Gratuit/Payant selon usage) : Agent IA utilisé pour coder.
*   **Lovable** (Gratuit/Payant) : Outil pour créer des applications avec l'IA.
*   **Bolt** (Gratuit/Payant) : Plateforme de démarrage de projets avec l'IA.
*   **Vercel** (Gratuit/Payant) : Service pour mettre des applications en ligne.
*   **Claude Code** (Non précisé) : Interface de commande pour coder avec Claude.

**3) Astuces concrètes et réutilisables :**
*   **Le "Commit" :** Faire une sauvegarde (photo du projet) à chaque étape qui fonctionne avant de lancer un gros prompt risqué.
*   **Le "Push" :** Envoyer ses sauvegardes locales vers GitHub pour les sécuriser en ligne.
*   **La "Pull Request" (PR) :** Créer une branche séparée pour que l'IA teste une modification sans casser le site principal, puis tester la "preview" avant de fusionner ("merge").
