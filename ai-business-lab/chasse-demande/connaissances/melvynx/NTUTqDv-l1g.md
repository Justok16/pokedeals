1) **Idée principale** : Reproduire une animation de bordure en gradient conique (effet similaire au site de Turbo) en CSS en 30 minutes dans le cadre d'un défi technique chronométré.
2) **Outils, sites ou dépôts GitHub cités** :
   - Turbo (turbo.build) : gratuit, site de référence pour le framework et ses outils (TurboPack, TurboRepo).
   - ColorGradient (colorgredient.dev) : gratuit, outil générateur de gradients CSS (radial, conic, etc.).
   - Designstripe (designstripe.com) : gratuit/freemium, site d'illustrations.
   - Dépot GitHub personnel / site « Begin React » (codelynx.dev/beginreact) : gratuit, portfolio/blog de l'auteur.
3) **Astuces concrètes et réutilisables** :
   - Utiliser un `conic-gradient` en CSS pour obtenir une bordure tournante fluide.
   - Utiliser un conteneur avec `position: relative` et un élément enfant en `position: absolute` avec un dépassement (`inset` / dimensions élargies) et un `overflow: hidden` pour masquer le débordement de la bordure animée.
   - Ajuster les propriétés d'animation avec des keyframes en rotation linéaire infinie (`linear infinite`) pour créer l'effet de bordure animée.
