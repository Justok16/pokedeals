# React est un framework ou une librairie ?

Vidéo : https://youtu.be/F9LEcEpSH1U · durée 10:30 · résumé Gemini (gemini-flash-lite-latest, lot de 10) du 2026-10-19
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale :** Il existe une confusion fréquente entre les notions de **librairie** (bibliothèque effectuant des opérations spécifiques et bien définies) et de **framework** (cadre/squelette définissant la structure d'une application). L'auteur clarifie ces concepts et catégorise plusieurs technologies populaires.
2) **Outils, sites ou dépôts GitHub cités :**
   - **Next.js :** Gratuit, framework (basé sur React).
   - **React :** Gratuit, librairie.
   - **Angular :** Gratuit, framework.
   - **Remix :** Gratuit, framework.
   - **Axios :** Gratuit, librairie.
   - **VueJS :** Gratuit, framework.
   - **React Query :** Gratuit, librairie.
3) **Astuces concrètes et réutilisables :**
   - Retenir qu'une librairie s'utilise dans son code (ton code appelle la librairie), tandis qu'un framework fournit le squelette et appelle ton code (tu utilises un framework).
   - Comprendre que React n'inclut aucun outil par défaut (routage, state management, fetch data), ce qui oblige à choisir des outils externes, contrairement à des frameworks plus complets.
