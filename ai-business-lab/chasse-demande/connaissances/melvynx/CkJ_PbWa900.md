# N'UTILISE PAS TAILWIND SANS ESLINT

Vidéo : https://youtu.be/CkJ_PbWa900 · durée 0:43 · résumé Gemini (gemini-flash-lite-latest, lot de 10) du 2026-10-19

1) **Idée principale :** L'importance d'installer le plugin ESLint dédié à Tailwind CSS pour automatiser le tri, la correction et l'ordre des classes CSS dans le code.
2) **Outils, sites ou dépôts GitHub cités :**
- **ESLint-plugin-tailwindcss** : plugin ESLint (gratuit, open-source), servant à appliquer les bonnes pratiques et à ordonner les classes Tailwind CSS.
- **NPM** : gestionnaire de paquets (gratuit), servant à installer le plugin.
3) **Astuces concrètes et réutilisables :**
- Installer le plugin via la commande terminal `npm install eslint-plugin-tailwindcss`.
- Ajouter le plugin dans la configuration `eslintrc` sous la section `extends` (`plugin:tailwindcss/recommended`).
- Utiliser la commande de sauvegarde (`save`) pour que le plugin ordonne automatiquement les classes Tailwind selon un ordre défini et cohérent.
