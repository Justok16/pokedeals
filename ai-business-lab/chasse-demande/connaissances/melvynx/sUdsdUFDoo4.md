# Tailwind : Les meilleurs Extensions VS et Chrome !

Vidéo : https://youtu.be/sUdsdUFDoo4 · durée 5:57 · résumé Gemini (gemini-flash-lite-latest, lot de 7) du 2026-10-11
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale** : L'auteur présente trois extensions indispensables pour VS Code (et une pour Google Chrome) destinées aux développeurs qui utilisent **Tailwind CSS** : **Gimli Tailwind** (pour modifier les classes visuellement), **Tailwind Switch** (pour basculer rapidement entre les classes) et **Tailwind Fold** (pour masquer ou replier les classes longues dans l'éditeur).

2) **Outils, sites et dépôts GitHub cités** :
- **Google Chrome** : Navigateur web (mentionné pour les extensions). (Gratuit).
- **VS Code (Visual Studio Code)** : Éditeur de code source de Microsoft. (Gratuit).
- **Tailwind CSS** : Framework CSS utilitaire. (Gratuit).
- **Extension Chrome Gimli Tailwind** : Outil d'inspection et de modification des classes Tailwind directement dans le navigateur. (Gratuit).
- **Extension VS Code Gimli Tailwind** : Extension homologue pour VS Code. (Gratuit).
- **Extension VS Code Tailwind Switch** : Extension permettant de basculer/modifier facilement les classes Tailwind. (Gratuit).
- **Extension VS Code Tailwind Fold** : Extension permettant de replier visuellement les longues listes de classes CSS dans les fichiers de code. (Gratuit).

3) **Astuces concrètes et réutilisables** :
- Utiliser l'extension Gimli Tailwind pour inspecter un élément web et modifier ses marges, espacements ou flexbox directement via une interface graphique, avec un retour visuel immédiat.
- Utiliser des raccourcis clavier avec Tailwind Switch pour incrémenter ou modifier rapidement les valeurs de Tailwind (par exemple, passer d'un gap de 4 à 8 sans réécrire toute la classe).
- Activer Tailwind Fold pour nettoyer la lisibilité du code dans les fichiers `.tsx` ou `.html` en masquant les longues chaînes de classes utilitaires derrière un affichage simplifié (`tailwind...`).
