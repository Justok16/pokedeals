# Je teste GEMINI CLI (alternative gratuite à Claude Code) pour la première fois

Vidéo : https://youtu.be/vPuvcYv_K8U · durée 11:23 · résumé Gemini (gemini-flash-lite-latest, lot de 8) du 2026-10-11
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) L'idée principale est de présenter et de tester "Gemini CLI", un agent open-source en ligne de commande propulsé par Google Gemini (Gemini 2.5 Pro), qui permet de générer du code et d'interagir directement depuis le terminal, tout en comparant son intégration, ses limites gratuites et ses coûts par rapport à d'autres outils.

2) Outils, sites et dépôts cités :
- Gemini CLI : Agent open-source en ligne de commande (gratuit de base avec des limites généreuses, ou payant via l'API Gemini). Sert à générer du code et effectuer des tâches dans le terminal.
- Google Gemini (Gemini 2.5 Pro) : Modèle de langage sous-jacent (gratuit via l'interface web/CLI avec des quotas, payant à l'API).
- GitHub : Dépôt de code source (gratuit).
- Node.js / npm : Environnement (gratuit).
- Ink : Bibliothèque React (gratuite) pour créer des applications CLI interactives.
- SaveIt.now / Next.js / Svelte / SvelteKit / Vercel : Projets ou frameworks web (gratuits/payants) utilisés pour les tests d'intégration de code.

3) Astuces concrètes et réutilisables :
- Utiliser Gemini CLI pour automatiser la création de pages web ou de composants (ex. : ajouter un bouton de partage avec "copy to clipboard" dans une application Next.js/Svelte) directement depuis le terminal en décrivant le besoin en langage naturel.
- Vérifier les quotas et limites d'utilisation des API (ex. : 60 requêtes par minute, 1 000 par jour en gratuit) avant de lancer des agents autonomes à grande échelle.
- Refactoriser le code généré par l'IA pour réutiliser les composants existants au lieu de dupliquer inutilement le code.

4) Chiffres de revenus annoncés (affirmés par l'auteur) :
- Coût estimé de l'API Gemini : environ 11 $ par jour pour un usage intensif, soit environ 330 $ par mois (calculs basés sur la grille tarifaire de l'API).
