# Enfin un SaaS AI qui peut te générer une APP de A à Z

1) **Idée principale :** Test de Bolt.new, un outil d'IA conversationnelle et de développement en ligne capable de générer, exécuter, corriger et déployer des applications full-stack à partir d'un simple prompt.

2) **Outils, sites ou dépôts GitHub cités :**
- **Bolt.new (bolt.new)** : Site web / plateforme de développement propulsée par l'IA (permettant de coder, exécuter et déployer des applications web directement depuis le navigateur).
- **StackBlitz** : Entreprise créatrice de Bolt.
- **Next.js** : Framework React (open-source / gratuit).
- **Shadcn UI** : Librairie de composants UI (open-source / gratuite).
- **MDX** : Format de fichiers combinant Markdown et JSX.
- **npm** : Gestionnaire de paquets JavaScript.
- **Tailwind CSS** : Framework CSS (open-source / gratuit).
- **Tailwind Typography (Tailwind Prose)** : Plugin pour le formatage de texte en Tailwind.
- **Zod** : Librairie de validation de schémas TypeScript.
- **Vercel** : Plateforme de déploiement cloud.

3) **Astuces concrètes et réutilisables :**
- Utiliser un générateur de code par IA pour prototyper rapidement une application complète (par exemple, un blog avec Next.js et MDX) en décrivant simplement ses besoins en langage naturel.
- Laisser l'IA détecter et tenter de corriger automatiquement les erreurs de compilation ou de dépendances dans le terminal intégré.
- Installer les plugins nécessaires (comme Tailwind Typography pour le rendu des articles de blog) en demandant explicitement à l'agent IA de modifier les fichiers de configuration (`tailwind.config.js`, `package.json`, etc.).
- Utiliser le bouton de déploiement intégré pour publier l'application une fois fonctionnelle.
