# Pourquoi J’AIME NextJS (genre vraiment)

Vidéo : https://youtu.be/FcusZDiCkBA · durée 11:31 · résumé Gemini (gemini-flash-lite-latest, lot de 8) du 2026-10-18
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale :** Pourquoi **Next.js** surpasse les autres frameworks (comme Remix) pour créer des applications web rapidement, notamment grâce à son écosystème, ses Server Components et ses Server Actions.
2) **Outils, sites ou dépôts GitHub cités :**
   - **Next.js** : Framework React gratuit.
   - **Remix** : Framework React concurrent, gratuit.
   - **Prisma** : ORM gratuit pour la base de données.
   - **NextAuth** : Bibliothèque gratuite d'authentification.
   - **Next-Plausable** : Outil gratuit d'analytique.
   - **Codeline** : Plateforme de formation payante du créateur.
   - **YouCode** : Application de quiz payante/freemium du créateur.
   - **Chat2Code** : Application payante du créateur.
3) **Astuces concrètes et réutilisables :**
   - Profiter de l'écosystème riche et des documentations spécifiques à Next.js fournies par les bibliothèques tierces (Prisma, Neon, etc.).
   - Utiliser les Server Components et Server Actions pour centraliser la logique backend et frontend au même endroit sans multiplier les API routes.
   - Combiner un apprentissage par la lecture, la vidéo et la pratique (quiz/projets réels) pour progresser rapidement.
4) **Chiffres de revenus annoncés :**
   - « plusieurs milliers d'euros » gagnés grâce à 5 applications créées en moins d'un an (Affirmé par l'auteur).
   - « 29 dollars » payés par un utilisateur pour l'abonnement à Bulk Corrector (Affirmé par l'auteur).
   - « 9 dollars » payés par un utilisateur pour un pack de tokens sur Chat2Code (Affirmé par l'auteur).
