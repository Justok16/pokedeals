# Mon Nouveau SaaS coder avec l'IA en 4 Heures (tu peux parler avec ta database)

Vidéo : https://youtu.be/Sb_iG5M4wJU · durée 9:29 · résumé Gemini (gemini-flash-lite-latest, lot de 10) du 2026-10-13
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale** : Le créateur montre comment il a développé un SaaS complet nommé **Askschema** en seulement 4 heures en combinant l'intelligence artificielle (ChatGPT), l'éditeur **Cursor** et une structure de landing page pré-conçue, permettant de dialoguer naturellement avec une base de données PostgreSQL.
2) **Outils, sites ou dépôts GitHub cités** :
   - **Cursor** : Éditeur de code assisté par IA (gratuit/payant).
   - **ChatGPT** : Assistant IA pour générer du code et des requêtes SQL (gratuit/payant).
   - **NowTS (nowts.app)** : Boilerplate / modèle de démarrage pour applications (payant/gratuit non précisé).
   - **TablePlus** : Outil de gestion de base de données (gratuit/payant).
   - **Askschema (askschema.com)** : Le SaaS développé dans la vidéo (service payant avec offre gratuite et abonnement à 9 $).
   - **Mailerlynx** : Autre application du créateur mentionnée (non précisé).
3) **Astuces concrètes et réutilisables** :
   - Utiliser un boilerplate (comme NowTS) pour ne pas repartir de zéro sur la mise en place d'une landing page et de l'authentification.
   - Fournir des descriptions textuelles très précises des fonctionnalités attendues à un assistant IA (comme ChatGPT) pour obtenir rapidement la structure et les requêtes SQL nécessaires.
   - Importer le schéma JSON d'une base de données existante directement dans l'application pour permettre à l'IA de comprendre la structure des tables et de formuler des requêtes complexes en langage naturel.
4) **Chiffres de revenus annoncés** :
   - Modèle tarifaire du SaaS créé : **0 $** (plan gratuit avec limites) et **9 $ par mois** (plan Pro illimité).
