1) **Idée principale**
Présentation de **Claude Code**, un outil de développement d'Anthropic qui permet de coder et d'interagir directement avec sa base de code depuis le terminal.

2) **Outils, sites ou dépôts GitHub cités**
* **Claude Code** (accessible via `claude.com/product/cloud-code`) : Outil de terminal. Mode d'utilisation gratuit via l'API (facturé selon l'usage) ou payant via abonnement.
* **Node.js / npm / nvm** : Prérequis d'installation (Node.js version 22 recommandée).
* **Visual Studio Code (VS Code)** : Éditeur de code open source gratuit.
* **extension Claude Code pour VS Code** : Extension gratuite disponible sur le marketplace.
* **VoiceInk** : Application tierce mentionnée pour le mode vocal (version Solo à 25 $, Personal à 39 $, Extended à 49 $ en paiement unique à vie).
* **Superwhisper** : Alternative payante mentionnée (9 $ par mois ou 250 $ à vie).

3) **Astuces concrètes et réutilisables**
* Installer Node.js 22 avant d'installer Claude Code globalement via npm (`npm install -g @anthropic-ai/claud-code`).
* Choisir le mode de facturation adapté : l'utilisation par clé API (facturée à l'usage réel) ou l'abonnement mensuel (Pro à 20 $ ou Max).
* Utiliser les commandes intégrées dans le terminal ou l'extension VS Code pour lancer Claude Code (`claude`).
* Changer les modes d'interaction de l'IA : mode normal, mode plan (pour planifier avant de coder), mode thinking (pour accroître la réflexion et la qualité des tokens), ou mode "Ask before edit" (pour valider chaque modification ligne par ligne).
* Utiliser des raccourcis clavier comme `Shift + Tab` pour changer de mode rapidement, ou `Esc` pour annuler.
* Utiliser les commandes de sauvegarde (`/clear`, `/init`, `/compact`) pour gérer l'historique et les contextes de discussion.
