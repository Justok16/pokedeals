# Comment DEBUGGER ton Application NextJS avec VSCode (la méthode simple)

Vidéo : https://youtu.be/iMLE1w5MfAA · durée 9:55 · résumé Gemini (gemini-flash-lite-latest, lot de 7) du 2026-10-12
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1. **Idée principale** : Guide pratique pour déboguer le code backend (Next.js) dans VS Code sans utiliser `console.log`, en configurant et en utilisant le débogueur JavaScript intégré.

2. **Outils, sites ou dépôts GitHub cités** :
   - **VS Code** : Éditeur de code, gratuit. Utilisé pour écrire et déboguer le code.
   - **Next.js** : Framework web, gratuit. Utilisé pour l'application servant d'exemple.
   - **Resend** : Service d'envoi d'e-mails (mentionné dans l'exemple de code).
   - **Better Auth** : Bibliothèque d'authentification pour TypeScript (mentionnée sur le site `mlv.sh/now`).

3. **Astuces concrètes et réutilisables** :
   - Poser des points d'arrêt (breakpoints) dans le code en cliquant dans la marge de VS Code pour stopper l'exécution à une ligne précise.
   - Utiliser le terminal de débogage JavaScript (« JavaScript Debug Terminal ») au lieu du terminal standard pour lancer le serveur et activer l'interception automatique.
   - Utiliser le panneau « Watch » (Variables de surveillance) pour évaluer des expressions en temps réel pendant le débogage.
   - Utiliser les fonctionnalités « Step Into » et « Step Over » pour naviguer pas à pas dans l'exécution des fonctions et méthodes.
