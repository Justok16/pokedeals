# React n’est PAS une qu'une Librairie WEB

Vidéo : https://youtu.be/AASNCRrzqLE · durée 5:37 · résumé Gemini (gemini-flash-lite-latest, lot de 9) du 2026-10-18
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale :** L'intervenant explique que React n'est pas une bibliothèque front-end mais une « boîte à outils » combinée à des « renderers », ce qui lui confère une polyvalence unique (Web, 3D, mobile, CLI, etc.) et le rend incomparablement plus puissant et modulaire que d'autres technologies.
2) **Outils, sites ou dépôts GitHub cités :**
- **Awesome React Renderer** (dépôt GitHub, gratuit) : liste des différents renderers disponibles pour React.
- **React-dom** : renderer pour le Web.
- **React Canvas** : renderer pour le rendu canvas.
- **React Three Fiber** / **React Unity** : renderers 3D / jeux.
- **React Native** / **React Titanium** : pour applications mobiles.
- **Ink** : pour créer des CLI avec React.
- **React-App** : pour des applications sur PS Vita, télévision, etc.
- **React-PDF** : pour générer des fichiers PDF (gratuit/open source).
- **Remotion** : pour générer des vidéos de manière dynamique avec React (gratuit).
- **React Minecraft** : pour définir des maisons/mods Minecraft avec React (gratuit).
- **React Express** : pour créer un serveur Node.js avec React.
- **Raycast** : application native macOS (freemium) qui remplace le launcher de base.
3) **Astuces concrètes et réutilisables :**
- Utiliser l'écosystème React au-delà du Web en associant React à un renderer spécifique (PDF, vidéo, CLI, etc.).
- Créer des extensions Raycast en combinant React (la boîte à outils UI) et l'API Raycast pour automatiser des tâches (génération de QR codes, listes de tâches, intégration Slack, etc.).
