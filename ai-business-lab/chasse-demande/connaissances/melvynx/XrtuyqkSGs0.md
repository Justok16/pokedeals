# Shadcn/UI vient de sortir les Charts et c'est GAME CHANGER !

1) **Idée principale** : Le vidéaste présente l'intégration des graphiques et graphiques statistiques prêts à l'emploi de **shadcn/ui** (basés sur la bibliothèque **Recharts**), permettant d'ajouter facilement de superbes graphiques personnalisables et thématisés dans une application web React/Next.js avec un simple copier-coller.

2) **Outils, sites ou dépôts GitHub cités** :
- **shadcn/ui** (ui.shadcn.com) : Bibliothèque de composants UI pour React/Tailwind CSS (gratuite).
- **Recharts** (recharts.org) : Bibliothèque de graphiques pour React (gratuite, sur laquelle repose shadcn/ui Charts).
- **React** / **Next.js** : Frameworks web (gratuits).
- **Tailwind CSS** : Framework CSS (gratuit).
- **Google Fonts** : Service de polices d'écriture (gratuit).

3) **Astuces concrètes et réutilisables** :
- Se rendre sur la section "Charts" du site de shadcn/ui pour choisir parmi de nombreux types de graphiques (Area Chart, Bar Chart, Pie Chart, Line Chart, etc.).
- Installer les graphiques dans son projet avec la commande CLI indiquée (ex: `npx shadcn@latest add chart`).
- Copier-coller le code du composant de graphique et adapter les données (`chartData`) et la configuration (`chartConfig`).
- Configurer les variables de couleurs dans le fichier CSS global (`globals.css`) pour que les graphiques s'adaptent automatiquement au thème clair/sombre.
