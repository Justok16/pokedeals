1) **L'idée principale** : Optimiser la lisibilité de son site web pour les agents IA afin d'améliorer son référencement (SEO) et son utilisabilité par les outils modernes, en utilisant un outil de diagnostic de Vercel.

2) **Outils, sites ou dépôts cités** :
*   **is-agentic.com** (ou commande `npx is-agentic`) : Outil créé par Vercel pour noter la compatibilité d'un site avec les agents IA. (Gratuit).
*   **Claude** : Agent IA utilisé pour corriger les erreurs détectées par l'outil. (Gratuit/Payant non précisé).
*   **mlv.sh/agent** : Lien fourni par l'auteur pour accéder à l'outil et à des ressources. (Gratuit).
*   **lumail.io** : Exemple de site web cité dans la vidéo.

3) **Astuces concrètes et réutilisables** :
*   Tester son URL sur is-agentic.com pour obtenir une note sur 100 et identifier les points bloquants (ex: erreurs 404, balises Open Graph manquantes, absence de fichier llms.txt).
*   Cliquer sur "Prompt to improve" dans l'outil pour copier un prompt de correction généré automatiquement.
*   Coller ce prompt dans Claude pour qu'il corrige l'intégralité des problèmes de code d'un coup, permettant ainsi de mieux "ranker" sur Google.
