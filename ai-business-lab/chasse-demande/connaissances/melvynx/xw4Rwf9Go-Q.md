1) **Idée principale :** Cette vidéo analyse les récents changements de tarification (pricing) d'Anthropic pour Claude Code et l'impact économique de l'utilisation intensive des outils de code par IA (comme Claude Code comparé à Cursor), en posant la question de la rentabilité et de l'évolution du rôle du développeur vers celui de "manager d'agents".

2) **Outils, sites ou dépôts GitHub cités :**
* **Claude Code** (outil CLI d'Anthropic) : Outil payant (tarifs d'abonnement Pro/Max et consommation API), assistant de code en terminal.
* **Cursor** (éditeur de code IA) : Outil payant (abonnement d'environ 20$/mois), éditeur de code boosté à l'IA.
* **GitHub Copilot** (assistant IA) : Outil payant (abonnement d'environ 10$/mois), assistant de code.
* **OpenAI** / **ChatGPT** / **GPT-4** / **o3** (modèles et API d'IA) : Payant (via API/abonnements), utilisés pour la génération de texte et de code.
* **Excalidraw** (outil de schéma) : Gratuit/freemium, utilisé pour dessiner des graphiques et schémas explicatifs.
* **iiblueprint.dev** (site web mentionné) : Site de formation et ressources sur l'IA (`iiblueprint.dev`).
* **VS Code** (éditeur de code) : Gratuit, éditeur de code de référence.

3) **Astuces concrètes et réutilisables :**
* **Évaluer ses coûts d'utilisation API :** Comparer le coût des abonnements fixes (ex. 20$/mois pour Cursor ou des abonnements Claude à 100$/200$) par rapport à la consommation réelle de tokens API (qui peut s'avérer beaucoup plus élevée si l'outil tourne en arrière-plan 24h/24).
* **Arbitrer entre les outils selon le rapport coût/performance :** Noter que GitHub Copilot reste nettement moins cher (environ 10$/mois avec des requests illimitées et de l'inline) comparé à l'utilisation intensive de Claude Code ou Cursor via API pure.
* **Utiliser les agents custom (Custom Sub-agents) :** Configurer des agents spécialisés dans Claude Code (ex. `deep-research-analyst`, testeurs QA, relecteurs de code) pour automatiser des tâches complexes en parallèle et structurer le travail.
* **Maintenir le goût du code manuel :** Pour conserver le plaisir de la programmation et la maîtrise technique, continuer à coder certaines parties soi-même tout en utilisant l'IA pour la revue ou les tâches répétitives.

* **100 $** : Coût mensuel de l'abonnement personnel Claude Pro/Max (ou niveau bas de la formule Max).

* **500 $** : Marge ou coût estimé d'écart dans certains exemples de consommation intensive.

* **2 $** : Coût réel estimé des tokens dans certains scénarios optimisés par rapport aux tarifs facturés.
* **18 $** : Coût ou tarif de référence mentionné pour des volumes de tokens (ou 18$ d'API).
* **10 $** : Coût mensuel de l'abonnement GitHub Copilot.
* **20 $** : Coût mensuel de l'abonnement Cursor Pro.
* **1 000 $** : Montant de dépenses en API pour certains utilisateurs lourds de Claude Code (ou 10 000$ dans un cas extrême mentionné).
