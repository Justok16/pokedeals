# MON NOUVEAU SaaS (comment faire un BON SaaS avec l'IA, pas un AI SLOP)

Vidéo : https://youtu.be/DHApIh7H_JQ · durée 12:23 · résumé Gemini (gemini-3.5-flash-lite, lot de 8) du 2026-10-08
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1. **Idée principale :** L’auteur présente son nouveau SaaS (« ThumbForge ») entièrement codé sans écrire de lignes de code manuellement, grâce à Claude Code, un terminal et l’IA, et détaille les stratégies de monétisation ainsi que les difficultés rencontrées avec la gestion des miniatures et des crédits.
2. **Outils et dépôts GitHub :**
   * **ThumbForge** (`thumbforge.st`) : Le SaaS de l'auteur pour générer des miniatures YouTube par IA.
   * **Claude Code** : Assistant de code en ligne de commande.
   * **Perplexity** : Outil de recherche et d'analyse de données de marché.
   * **Figma** : Outil de design d'interface.
   * **Formation de l'auteur** (`mlv.sh/ai`) : Masterclass gratuite sur Claude Code.
3. **Astuces concrètes :**
   * Utiliser le workflow itératif de Claude Code pour corriger les bugs d'interface (comme le problème d'infinite scroll ou de sélection de miniatures) en lui injectant directement le code source et les rapports d'erreur.
   * Cibler une clientèle de créateurs (YouTubers) via du démarchage par e-mail (cold e-mailing) ou en ciblant des "mini-makers".
4. **Chiffres affirmés par l'auteur :**
   * Coût de l'API Cloud pour coder le SaaS : environ 50 $.
   * Coût de l'abonnement Pro du SaaS : 19 $ par mois (pour 100 crédits), ou plan Ultra à 49 $ par mois (pour 300 crédits).
   * Solde de crédits de l'auteur dans l'application : 566,9 crédits.
