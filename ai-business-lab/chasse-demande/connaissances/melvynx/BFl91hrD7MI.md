### 3) Astuces concrètes et réutilisables
*   **Choix du modèle** : Utiliser les modèles plus légers/rapides (ex. versions "Luna" ou "Light") pour les petites tâches répétitives afin d'économiser les crédits, et réserver les modèles plus puissants (ex. "Sol" ou versions Max/Pro) pour le code complexe.
*   **Utilisation du plugin Browser** : Activer le plugin de navigation web (`@browser`) pour permettre à Codex de lire et naviguer sur Internet ou sur des pages locales en temps réel (ex. lire une chaîne YouTube pour en extraire des données).
*   **Annotation visuelle et corrections** : Sur les aperçus de sites générés, utiliser l'outil d'annotation pour cibler un élément graphique précis, l'envoyer à l'IA avec un commentaire correctif, ce qui permet à l'agent de corriger le code plus efficacement grâce au retour visuel (screenshots).
*   **Installation des plugins essentiels** : Installer les plugins **Computer Use** (contrôle de l'ordinateur) et **Chrome** (extension Chrome ChatGPT pour l'interaction avec le navigateur) pour piloter le système et les navigateurs depuis le chat.
*   **Création de *Hooks* de sécurité** : Mettre en place des scripts/hooks via des prompts pour interdire l'utilisation de commandes dangereuses (ex. suppression de base de données, `rm -rf`) et forcer l'IA à proposer des alternatives sécurisées (ex. utiliser une corbeille).
*   **Gestion des fenêtres de chat (*Side Chats* et *Forks*)** : Utiliser le mode *Side Chat* pour mener des conversations parallèles sans perdre le fil principal, ou utiliser l'option *Fork* pour dupliquer un chat et explorer de nouvelles branches de code.
