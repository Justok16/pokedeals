# Mon Hack pour être Rapide avec mon Terminal

Vidéo : https://youtu.be/PzmpXf9w4Hw · durée 5:31 · résumé Gemini (gemini-flash-lite-latest, lot de 5) du 2026-10-11
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) **Idée principale** : Optimisation de la productivité du développeur dans le terminal grâce à la mise en place d'alias personnalisés, de raccourcis Git et de configurations avancées sous macOS/Linux (Zsh/Vim).

2) **Outils, sites et dépôts GitHub cités** :
- **Git** (gratuit, système de contrôle de version).
- **PNPM** (gratuit, gestionnaire de paquets JavaScript rapide).
- **Docker** (gratuit/payant, outil de conteneurisation).
- **Yarn** (gratuit, gestionnaire de paquets JavaScript).
- **Vim / Neovim** (gratuit, éditeur de texte en ligne de commande).
- **WebStorm** (payant, environnement de développement intégré).
- **VS Code** (gratuit, éditeur de code source).

3) **Astuces concrètes et réutilisables** :
- **Création d'alias dans le terminal** : Modifier le fichier de configuration du shell (`.zshrc` ou `.zshenv`) pour créer des raccourcis de commandes fréquentes (ex. `alias g = git`, `alias p = pnpm`, `alias c = git commit`).
- **Raccourcis Git avancés** : Configurer des alias globaux dans le fichier `.gitconfig` (ex. `st = status`, `co = checkout`, `com = commit -m`) pour gagner un temps précieux au quotidien.
- **Automatisation des mises à jour** : Créer des alias combinant plusieurs commandes (ex. mise à jour globale des paquets PNPM) pour enchaîner les actions en une seule frappe.
- **Configuration de VS Code** : Synchroniser le terminal et l'environnement de développement pour utiliser les mêmes raccourcis et optimiser le flux de travail.
