# Kiro, l'IDE IA d'Amazon : potentiel Cursor Killer (et gratuit)

Vidéo : https://youtu.be/BuflRsPUZwY · durée 28:20 · résumé Gemini (gemini-flash-lite-latest, lot de 8) du 2026-10-11
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) L'idée principale est de présenter et de tester "Kiro", un nouvel IDE agentique basé sur le fork de VS Code et soutenu par Amazon (lié à Anthropic/Claude), conçu pour aider les développeurs à créer des fonctionnalités complexes grâce au langage naturel, à la gestion de spécifications ("Specs") et à des "agents hooks".

2) Outils, sites et dépôts cités :
- Kiro : IDE agentique (fork VS Code), propose une version gratuite (limitée à 50 interactions/mois) et des versions payantes (Kiro Pro à 19 $/mois pour 1000 interactions, et Kiro Pro+ à 39 $/mois pour 3000 interactions). Sert à créer des applications en combinant code et langage naturel via des spécifications et des agents.
- VS Code : IDE d'origine (gratuit), utilisé pour importer des configurations.
- Claude Code / Claude Sonnet 3.7 : Modèle d'IA utilisé pour l'assistance au code et les agents (gratuit ou payant via les abonnements de l'outil).
- GitHub : Plateforme de gestion de code (gratuite/payante), utilisée pour la connexion et la gestion des issues.
- MCP (Model Context Protocol) : Système de serveurs MCP (gratuit) pour connecter des outils et des données (ex. le fetch).

3) Astuces concrètes et réutilisables :
- Utiliser un IDE agentique pour transformer des spécifications textuelles en code structuré et planifié avant de coder.
- Créer des "Specs" (cahier des charges et design) avant d'exécuter des tâches de programmation complexes.
- Importer ses extensions et configurations depuis VS Code pour transitionner rapidement.
- Configurer les "Agent Hooks" et les serveurs MCP pour automatiser des actions répétitives (comme le fetch ou l'analyse de dépôt).
