# cn() : Tous les DEVS Tailwind doivent l’utiliser (clsx + twMerge)

Vidéo : https://youtu.be/0e8C1_WA5i4 · durée 7:38 · résumé Gemini (gemini-flash-lite-latest, lot de 10) du 2026-10-15
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1) L'idée principale est d'expliquer comment fusionner des classes CSS (Tailwind) proprement dans une application grâce à l'utilisation combinée des bibliothèques clsx, tailwind-merge et d'un utilitaire personnalisé « cn ».
2)
- clsx : bibliothèque (non précisé si payant) pour fusionner des classes de manière conditionnelle (gère objets, tableaux, valeurs falsy).
- tailwind-merge : bibliothèque (non précisé si payant) pour fusionner des classes Tailwind sans conflit en supprimant les styles redondants en fonction de l'ordre.
- Utilitaire « cn » : fonction personnalisée (environ 80 lignes, combinant les deux) présentée comme solution globale pour appliquer des classes dynamiquement.
3) Astuces :
- Utiliser clsx pour gérer les conditions et les valeurs falsy (undefined, null, 0) dans les classNames.
- Utiliser tailwind-merge pour éviter qu'une classe Tailwind prioritaire mal placée ne soit écrasée par erreur.
- Combiner les deux dans une fonction « cn » pour centraliser la fusion et le nettoyage des classes CSS.
4) Chiffres : non précisé.
