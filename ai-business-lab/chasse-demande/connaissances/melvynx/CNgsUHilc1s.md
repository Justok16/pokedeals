# TailwindCSS n'a plus d'argent à cause de l'IA (ça n'a aucun sens)

Vidéo : https://youtu.be/CNgsUHilc1s · durée 12:48 · résumé Gemini (gemini-3.5-flash-lite, lot de 8) du 2026-10-08
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1. **Idée principale :** L’auteur analyse une discussion GitHub controversée sur Tailwind CSS où le créateur explique que l’optimisation de la documentation pour les LLM réduit le trafic sur le site et nuit aux revenus, tout en constatant un effondrement massif du trafic et le licenciement de 75 % de l’équipe de développement.
2. **Outils et dépôts GitHub :**
   * **Tailwind CSS** : Framework CSS.
   * **Dépôt GitHub Tailwind (pull request #2388 / issue)** : Dépôt de discussions sur Tailwind CSS.
   * **Vercel** : Plateforme d’hébergement.
   * **SimilarWeb** : Outil d'analyse de trafic.
   * **Site TailwindPlus** (`mlv.sh/fc`) : Site payant de templates et composants (120 € à 500 € par an).
3. **Astuces concrètes :**
   * Analyser l'impact de l'IA générative et de l'optimisation des documentations pour les LLM sur la viabilité économique d'un projet open source.
4. **Chiffres affirmés par l'auteur :**
   * Baisse de trafic de 40 % sur Tailwind CSS depuis le début de l'année 2023.
   * 75 % de l'équipe de développement de Tailwind CSS licenciée (3 ingénieurs sur 4).
   * Coût de l'abonnement Tailwind Plus à 120 €/an (ou version US à 500 $/mois, ou 5 000 €).
   * Chute de revenus de 80 % pour Tailwind CSS.
