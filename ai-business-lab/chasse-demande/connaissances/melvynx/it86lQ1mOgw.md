# Tutoriel JavaScript en 1 HEURE | Comprendre l'ESSENTIEL pour Débutant

- **Idée principale :** Tutoriel complet d’une heure pour débuter et maîtriser les bases de JavaScript, destiné aux débutants souhaitant apprendre ce langage incontournable du web.
- **Outils, sites ou dépôts GitHub cités :**
  - **Visual Studio Code (VS Code) :** Éditeur de code gratuit, utilisé pour écrire et exécuter du code.
  - **Node.js :** Environnement d'exécution JavaScript open-source (runtime gratuit), permettant d'exécuter JavaScript en dehors du navigateur et sur différentes machines (Windows, Linux, macOS).
  - **V8 (moteur V8) :** Moteur JavaScript open-source gratuit développé par Google (intégré notamment dans Chrome).
  - **JavaScript Core :** Runtime gratuit utilisé pour Safari.
  - **GitHub Copilot :** Outil payant d'assistance au codage (mentionné visuellement).
  - **Plateforme de formation (BeginJavaScript / Melvynx) :** Plateforme de formation payante (avec cours gratuits disponibles en description) proposant des exercices, quiz et playgrounds.
  - **Live Server (extension VS Code) :** Extension gratuite pour VS Code permettant de lancer un serveur de développement local avec rechargement automatique.
- **Astuces concrètes et réutilisables :**
  - Ouvrir la console du navigateur (clic droit > Inspect > Console) pour tester du code JavaScript instantanément (`console.log`, `alert`, `console.error`, `console.warn`).
  - Utiliser l'extension Live Server sur VS Code pour lier un fichier HTML à un fichier JS externe et voir les modifications en direct via `localhost`.
  - Distinguer les types primitifs (string, number, boolean, null, undefined, bigInt, symbol) des types de référence (object, array, function).
  - Nommer les variables en respectant la casse (Camel Case) et utiliser le mot-clé `const` pour créer une constante non modifiable, ou `let` pour une variable modifiable.
  - Utiliser l'opérateur strict `===` pour comparer à la fois la valeur et le type en JavaScript.
  - Structurer son code en séparant les fichiers HTML et JavaScript (séparation of concerns).
