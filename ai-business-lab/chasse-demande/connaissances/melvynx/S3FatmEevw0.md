# Le WEB A Changé en 2024, voici ce que tu dois savoir

Vidéo : https://youtu.be/S3FatmEevw0 · durée 12:11 · résumé Gemini (gemini-flash-lite-latest, lot de 5) du 2026-10-16
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

1. **Idée principale :**
   Cette vidéo présente les grandes tendances du développement web pour les années à venir (notamment en 2024), en expliquant pourquoi les technologies traditionnelles (comme JavaScript brut ou Bootstrap) laissent la place à des standards modernes incontournables : **TypeScript**, **Next.js**, **Tailwind CSS**, et l'utilisation intensive des assistants IA (**GitHub Copilot**). L'auteur propose également une roadmap d'apprentissage pour devenir développeur web.

2. **Outils, sites ou dépôts GitHub cités :**
   * **JavaScript / TypeScript** (Gratuit, langages de programmation) : JS est supplanté par TS dans les tendances.
   * **Zod** (Gratuit, bibliothèque de validation de schémas) : Présenté comme l'écosystème incontournable avec TypeScript.
   * **Next.js** (Gratuit, framework React) : Présenté comme le leader incontesté des frameworks web (face à Angular, Remix, SvelteKit, Nuxt).
   * **Tailwind CSS** (Gratuit, framework CSS) : Présenté comme le leader des frameworks CSS (remplaçant Bootstrap, Emotion, styled-components).
   * **GitHub Copilot** (Payant, assistant de code IA) : Présenté comme l'outil d'IA dominant utilisé par plus de 50 % des développeurs.
   * **Tabnine** (Gratuit/Payant, assistant IA) : Mentionné parmi les outils d'IA.
   * **AWS CodeWhisperer** (Gratuit/Payant, assistant IA) : Mentionné.
   * **DaisyUI, Shadcn/ui, Flowbite, HyperUI** (Gratuit, bibliothèques de composants pour Tailwind) : Citées dans l'écosystème Tailwind.

3. **Astuces concrètes et réutilisables :**
   * Apprendre en priorité **TypeScript** plutôt que JavaScript pur, car TS domine largement le marché (plus de 65 % vs 43 % ou selon les courbes de croissance présentées).
   * Suivre une roadmap structurée pour l'apprentissage du web : 1) HTML, 2) CSS, 3) Tailwind CSS, 4) JavaScript, 5) TypeScript, 6) React, 7) Next.js.
   * Intégrer l'utilisation de l'IA (comme GitHub Copilot) dans son flux de travail quotidien pour booster sa productivité, en gardant en tête la règle : « ce ne sont pas les IA qui vont remplacer les développeurs, c'est les développeurs qui utilisent l'IA qui remplaceront ceux qui ne le font pas ».
