# J'ai testé tous les AI Agents CLI qui remplace mon job de DEV

Vidéo : https://youtu.be/VArssLucDks · durée 34:39 · résumé Gemini (gemini-3.5-flash, lot de 4) du 2026-10-10
(connaissances générales, non vérifiées : toute règle fiscale ou chiffre est à contrôler à la source officielle)

**1) Idée principale**
Comparatif détaillé et classement ("Tier List") des 6 principaux outils CLI de codage assisté par IA (Claude Code, Codex, OpenCode, Droid CLI, Cursor Agent, Crush).

**2) Outils, sites ou dépôts GitHub cités**
*   **Claude Code (par Anthropic)** : Payant (abonnement Claude Pro/Max ou API) — Agent IA CLI. Classé : **S Tier**.
*   **OpenCode** : Gratuit (Open Source) — Agent IA CLI multi-modèles avec interface plein écran. Classé : **A Tier**.
*   **Droid CLI (par Factory AI)** : Gratuit (essai 20M tokens) / Payant (20 $/mois) — Agent IA CLI puissant avec gestion fine des modèles. Classé : **A Tier**.
*   **OpenAI Codex CLI** : Gratuit (outil) / Nécessite abonnement ChatGPT (20 $/mois) ou API — Agent IA CLI officiel d'OpenAI. Classé : **B Tier**.
*   **Cursor Agent** : Payant (requiert abonnement Cursor) — Version CLI de l'éditeur Cursor. Classé : **C Tier**.
*   **Crush (par Charm / Charmbracelet)** : Gratuit (Open Source, requiert clé API) — Outil CLI créé par les créateurs originaux d'OpenCode. Classé : **C Tier**.
*   **Porkbun** : Payant — Registrar de noms de domaine (cité brièvement).
*   **`AI Blueprint` (`mlv.sh/cccli`)** : Gratuit — Outil/newsletter de l'auteur pour configurer son environnement CLI IA.

**3) Astuces concrètes et réutilisables**
*   **Choix de l'outil principal** : Utiliser **Claude Code** pour bénéficier de la meilleure Expérience Développeur (DX), de tâches en arrière-plan, de sous-agents et de styles de sortie personnalisables.
*   **Alternative multi-modèles** : Choisir **OpenCode** ou **Droid CLI** si vous souhaitez utiliser vos propres clés API et basculer facilement entre divers modèles (Claude 3.5, GPT-5, GLM-4, Grok).
*   **Éviter Crush** : L'outil impose un fichier non standard propriétaire (`CRUSH.md`) au lieu de `AGENTS.md` et offre une mauvaise ergonomie/DX.
*   **Éviter Cursor Agent en CLI** : L'outil manque de fonctionnalités CLI essentielles (commandes slash, sous-agents) et force l'utilisation du forfait Cursor payant sans liberté de clés API.
