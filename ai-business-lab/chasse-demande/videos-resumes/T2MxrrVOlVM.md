### 3) Astuces concrètes et réutilisables

1. **Éviter les faux modèles locaux :**
   * Vérifiez toujours dans le menu déroulant de l'extension de votre éditeur de code le nom exact du modèle sélectionné (ex: `Claude Opus 5.5` ou `Claude Fable 5.1`), car certains tutoriels basculent sur des modèles locaux moins performants à votre insu.
2. **Installation manuelle d'une extension VSIX dans VS Code :**
   * Téléchargez le fichier `.vsix` (ex: 27,2 Mo).
   * Dans VS Code, ouvrez l'onglet **Extensions**, cliquez sur les trois petits points (`...`) en haut à droite, puis sélectionnez **"Install from VSIX..."** et choisissez le fichier téléchargé.
3. **Structure de prompt pour créer une application web complète (Vanilla JS) :**
   * **Méthode :** Demandez d'abord une vue d'ensemble de l'architecture et une liste d'étapes à valider avant la génération.
   * **Contraintes à spécifier dans le prompt :**
     * Pas de frameworks lourds : demandez du HTML5, CSS3 pur (avec variables CSS pour le mode sombre/clair) et du Vanilla JavaScript.
     * Gestion des données : imposez l'utilisation du `localStorage` pour sauvegarder les tâches et paramètres.
     * Composants visuels : demandez des éléments interactifs (ex: glisser-déposer / Drag & Drop, animations CSS, graphiques Canvas API).
4. **Prompting pour scripts de jeux (ex: Roblox / Lua) :**
   * Demandez à l'IA d'isoler chaque script et d'indiquer l'emplacement exact d'intégration dans l'arborescence de l'éditeur (ex: spécifier `ServerScriptService`, `ReplicatedStorage` ou dans les propriétés d'un objet spécifique).
