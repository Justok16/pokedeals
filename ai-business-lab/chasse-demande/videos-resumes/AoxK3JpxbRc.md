# AoxK3JpxbRc — « The Claude Code workflow that helped me win 5 Hackathons in a Row »

- Auteur : Johnathan Mo ; lien : https://youtu.be/AoxK3JpxbRc
- Envoyée par l'utilisateur le 15/10/2026 ; résumée le 15/10 par Gemini (modèles gratuits, via le relais)

### 1) Idée principale
L'auteur, Johnathan, explique comment il a remporté cinq hackathons prestigieux en utilisant un workflow optimisé basé sur des agents IA (comme Claude Code et Codex). Son approche repose sur quatre piliers : « penser à rebours », utiliser une structure d'agent (« Agent Harness »), maintenir une haute endurance (travail intensif) et réaliser des démos « live » impressionnantes pour convaincre les jurys.

### 2) Outils et sites cités
*   **Claude Code** : Outil d'IA pour le codage. Gratuit/Payant : Non précisé. Sert à accélérer le développement en automatisant l'écriture de code.
*   **Codex** : Outil d'IA utilisé pour le développement backend et la revue de code. Gratuit/Payant : Non précisé.
*   **Wispr Flow** : Outil de saisie vocale-vers-texte (Smart Voice-to-Text). Gratuit/Payant : Possède une version Pro gratuite (via le lien en description pour 1 mois). Sert à dicter des prompts 4 fois plus vite qu'à la frappe.
*   **Cosmos** : Plateforme de sauvegarde de ressources web (similaire à Pinterest). Gratuit/Payant : Non précisé. Sert à stocker des inspirations design.
*   **Superset** : IDE (Environnement de développement) pour agents IA. Gratuit/Payant : Non précisé. Permet de créer des espaces de travail avec des *git worktrees*.
*   **Supabase** : Service de base de données. Gratuit/Payant : Non précisé. Sert à connecter l'agent à une base de données.
*   **Neon** : Service de base de données MCP (*Model Context Protocol*). Gratuit/Payant : Non précisé. Sert de serveur de données pour l'agent.
*   **Stripe** : Service de paiement. Gratuit/Payant : Payant (commissions). Sert à intégrer des systèmes de paiement dans les projets.

### 3) Astuces concrètes et réutilisables
*   **Penser à rebours** : Avant de commencer à coder, visualisez la démo finale et le prix que vous voulez gagner, puis construisez votre projet en fonction de ce qui impressionnera le jury.
*   **La méthode « /interview »** : Créer un prompt (ou une skill) qui force l'IA à vous poser des questions sur votre projet avant de commencer, afin d'établir une vision claire et éviter les erreurs de développement.
*   **Standard Technical English (STE)** : Utiliser cette règle de langage pour forcer l'IA à utiliser des termes directs et techniques plutôt que du jargon flou, ce qui réduit les erreurs de l'IA.
*   **Skill « /agentation »** : Annoter directement votre interface en cours de développement pour donner du contexte visuel à l'IA et lui demander d'ajuster des éléments précis.
*   **Live Demos** : Prioriser une démonstration en direct (sans tricherie) qui montre le fonctionnement réel du produit, ce qui rassure les juges sur la faisabilité technique.
*   **Endurance** : Travailler sans dormir (ou avec très peu de sommeil) durant les 24h-36h du hackathon pour maximiser le rendu.
*   **Rationalisation des outils** : Ne pas surcharger l'agent avec trop de skills, car cela peut brider ses capacités de raisonnement.
