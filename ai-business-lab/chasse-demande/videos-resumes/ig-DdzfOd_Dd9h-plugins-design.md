Source envoyée le 30/09/2026 : https://www.instagram.com/reel/DdzfOd_Dd9h/ . Vidéo regardée par Gemini le 30/09/2026 (page « embed » d'Instagram, sans compte). Noms tels qu'affichés ; l'adresse GitHub citée par Gemini pour Awesome DESIGN.md n'est pas vérifiée.

### 1) Liste des outils / plugins / skills présentés
* **Web Design Guidelines Skill** (Vercel)
  * **Rôle :** Audite le code selon les dernières règles de design de Vercel et signale les points faibles avant le déploiement.
  * **Site / Dépôt :** Vercel (URL affichée : `vercel.com/design-guidelines`).
* **Taste Skill**
  * **Rôle :** Fournit de l'inspiration design à partir de références premium pour améliorer l'interface.
  * **Site / Dépôt :** Non précisé explicitement (mentionné comme skill/plugin).
* **Playwright CLI**
  * **Rôle :** Permet à Claude d'ouvrir un navigateur, de prendre des captures d'écran de l'interface construite et de détecter les rendus ratés ou les erreurs.
  * **Site / Dépôt :** Non précisé explicitement.
* **Awesome Design** (`Awesome DESIGN.md`)
  * **Rôle :** Fournit un système de design complet extrait des meilleurs sites (couleurs, typographie, espacements, boutons) pour guider l'IA.
  * **Site / Dépôt :** Dépôt GitHub (`github.com/v0-dev/awesome-design-md`).
* **Image to Code** (GitHub)
  * **Rôle :** Transforme une image de référence en code directement utilisable, sans perte de détails.
  * **Site / Dépôt :** GitHub (logo affiché).
