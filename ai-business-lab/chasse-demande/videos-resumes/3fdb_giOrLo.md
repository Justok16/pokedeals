### 1) Idée principale
La vidéo explique comment **supercharger ses agents IA** (tels que Claude Code, Codex, ChatGPT Work, etc.) en y installant gratuitement des **« Skills »** (compétences / workflows préconfigurés sous forme de fichiers ou dépôts GitHub). Ces compétences permettent d'automatiser des tâches professionnelles à haute valeur ajoutée (recherche de marché, création de vidéos animées, rédaction naturelle, audit de sécurité, développement logiciel et design web), offrant ainsi une base idéale pour créer des services ou produits monétisables.

### 3) Astuces concrètes et réutilisables

1. **Procédure d'installation universelle d'un Skill :**
   * Copiez l'URL GitHub du skill souhaité.
   * Dans votre agent (ex: Claude Code ou ChatGPT Work), collez le prompt :  
     `Install this skill from GitHub using the setup instructions [URL]`
2. **Exécution rapide d'un Skill :**
   * Utilisez la commande `@` ou `/` suivie du nom du skill (ex: `@last` ou `/humanizer`), ou mentionnez simplement le nom du skill dans votre requête habituelle.
3. **Sécurité préalable (Bonne pratique) :**
   * Avant d'installer un skill provenant d'un tiers, utilisez **SkillSpector** pour vous assurer qu'il ne contient pas de code malveillant ni de risque d'injection de prompt.
4. **Créer ses propres workflows monétisables :**
   * Ne vous limitez pas à utiliser un skill tel quel : vous pouvez demander à votre agent d'exécuter un skill (ex: *Last 30 Days*), d'envoyer automatiquement les résultats vers un site web ou une base de données, puis d'enregistrer l'ensemble de ce processus sous la forme d'un **nouveau skill personnalisé**.
5. **Amélioration du Design pour la création de sites/apps :**
   * **`impeccable bolder`** : Renforce la typographie et la mise en page d'un site généré par l'IA s'il paraît trop plat.
   * **`impeccable delight`** : Ajoute des micro-animations interactives (ex: animation de tampon sur un passeport) pour améliorer l'expérience utilisateur.
   * **`impeccable critique`** : Réalise un audit UX complet (ergonomie, réactivité mobile/desktop, accessibilité).
