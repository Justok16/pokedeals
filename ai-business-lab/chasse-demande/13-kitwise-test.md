## Réponse type pour le forum BigCommerce (anglais)

Règle : d'abord la solution gratuite, le lien ensuite, une seule fois par fil.

> BigCommerce doesn't have native bundles, but you can get close for free:
> create a new product for the bundle, then add a **Pick List** modifier
> (Products → Edit → Variations & Customizations → Add modifier → Pick list)
> that points to the items inside it, and set the bundle price. The catch:
> stock is not deducted from the individual items, so a kit can oversell
> when one component runs out.
>
> I'm building a small app that fixes exactly that (component stock sync,
> mix-and-match bundles). It isn't built yet — if it would help you, there's
> a waitlist here: https://digcost.github.io/kitwise/
