# Fermetures de logiciels (hors boutiques d'apps) — tour du 24/09, soir

Idée testée : quand un logiciel ferme avec des clients payants, devenir le
successeur (reprise des clients, partage de revenu avec l'éditeur) ou
l'outil de migration. Liste de départ : SunsetProof « SaaS Sunset Tracker
2025–2027 » (32 fermetures, chacune liée à l'annonce officielle), plus
recherches.

| Fermeture | Date | Qui occupe déjà la place | Verdict |
|---|---|---|---|
| Microsoft Publisher (fichiers .pub illisibles sans Publisher) | 01/10/2026 | Convertisseurs en ligne gratuits (Zamzar, FreeConvert, Aspose…), Univik ; **Publisher → Canva** : Markzware DesignMarkz | écarté (occupé) |
| Exchange Web Services (EWS) | blocage le 01/10/2026, arrêt définitif le 01/04/2027 | Chaque éditeur migre vers Microsoft Graph ; outils orphelins non mesurables de l'extérieur | écarté (non mesurable) |
| Salesforce Quip | plus de renouvellement après le 01/03/2027 | Salesforce construit sa migration vers Slack + outils d'export ; ClonePartner, NoteSmith, Folio ; scripts gratuits sur GitHub | écarté (absorption + occupé) |
| GetFeedback Direct (enquêtes dans Salesforce) | 31/12/2026 | SurveySparrow, Zonka, Formbricks publient déjà des guides de migration | écarté (occupé) |
| Atlassian OpsGenie | 05/04/2027 | Atlassian migre lui-même vers Jira Service Management | écarté (absorption) |
| Microsoft Project Online, Meta Workplace, SAP Marketing Cloud, Yammer | 2026 | l'éditeur fournit son remplaçant | écarté (absorption) |

## Conclusion

Même constat qu'avec les lois (`29-…`) : une fermeture **annoncée
publiquement** attire les concurrents et les guides de migration dans les
semaines qui suivent. Pour avoir un avantage, il faut soit un **droit de
reprise** (transfert de fiche, comme chez Atlassian), soit repérer la
fermeture **avant** qu'elle soit publique (petits éditeurs qui abandonnent
sans rien annoncer : c'est ce que détecte la mesure « aucune version depuis
le gel » sur Atlassian).
